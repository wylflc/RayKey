与 §9.3.1.2 回测所用带**同一套口径**。报告期 2026-06-30、生效日 2026-08-21｜每股 NOPAT 6.5444｜ROIC0 26.63%｜增量 ROIC -38.19%｜再投资率 72.66%｜g0 0.00% = 增量ROIC × 再投资率｜WACC 9.39%｜终值 ROIC 11.39%、g_T 3.00%｜每股净负债 3.6076｜**内在价值 52.01 元**。带 = IV × [0.90, 1.10]，**中值恰为 IV**，故 `P/V = 收盘 ÷ 中值` 与回测的 `valuation_ratio` 逐位一致。
