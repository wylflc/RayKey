## 八、现价隐含了什么

现价 2266.5亿 / 本档中枢 1182.6亿 = 1.917。**隐含年数无解**：猪价周期没有稳定的复合增速可外推。换成可证伪的说法：**现价相当于跨周期中枢盈利的 23 倍**——对一家养殖企业而言，这要求「成本优势把周期熨平」这一命题成立到前所未有的程度。可查证的量是**完全成本（元/公斤）与自繁自养出栏量**。

1. **业务与利润来源**：生猪养殖（自繁自养一体化，商品猪/仔猪/种猪）+ 屠宰肉食（2025 首次年度盈利、产能打满）+ 饲料自供。2025 营收 1,441 亿、归母 154.9 亿；**2026H1 营收 594.1 亿（−22.3%）、归母 −60.78 亿（扣非 −58.95 亿）、经营现金流 −22.2 亿（上年同期 +173.5 亿）、ROE −7.48%、毛利率 −1.6%（Q1 +5.2% → Q2 单季约 −8%）、Q2 单季归母 −48.6 亿**；H1 商品猪均价 10.4 元/kg（−28%）、6 月 9.69；总资产 1,750.6 亿、归母净资产 801.9 亿（H 股 2026-02 发行）、资产负债率 54.18%；中期不分红。
2. **护城河载体与资本复制**：完全成本曲线最左——2026-03 完全成本 11.6 元/kg（全国均值 14.1），头均亏 66 元 vs 行业自繁自养 300+，PSY 26.7→28.3，能繁母猪 362.1→311.3 万头（主动减产、停建百万头在建场、出栏均重压至 120 kg 以下）。Q1 2026 同业对照（ROE）：牧原 −1.57% / 温氏 −2.59% / 新希望 −4.68% / 天康 −2.37% / 神农 −14.1% / 巨星 −12.2% / 唐人神 −14.2% / 天邦 −35.2%——亏损最浅，载体未破坏；测试通过。**但对最优同行的差距已收窄**：温氏 2026-05 综合成本 5.9 元/斤 = 11.8 元/kg（剔跌价准备约 11.6），行业 PSY 16→25-26，公司成本下降 2026-04/05 停滞——能力锁在变薄，Q2 79→77（rubric §4.1：自"资本+时间 5-10 年可接近"段降至"同业在追，3-5 年可显著缩小"段顶部；锚 比亚迪 79 / 海天 77 / 爱美客 75）。
