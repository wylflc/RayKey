## 八、现价隐含了什么

现价 677.3亿 / 本档中枢 491.8亿 = 1.377。**但隐含年数在此无解**：一致预期 2026E→2028E 复合仅 **7.1%**，低于 r=10% 的折现率，净复利小于 1——靠增速追平差额无解。现价只能由「钼价再上一个台阶」解释。同批的锡业股份（4.6%）与电投能源（6.3%）落在同一类：**低增速资源股的可证伪量是商品价格，不是时间**。
