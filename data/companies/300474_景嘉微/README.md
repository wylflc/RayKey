## 八、现价隐含了什么

本档为净资产口径，不适用盈利倍数的年数反解。可证伪的问题很直接：**扣非何时转正**——共识 2026E 仅 0.06亿、2028E 1.42亿，即使兑现，对应现价也是 194 倍 PE。**现价隐含的是「国产 GPU 路线成功」的期权价值，而不是可核算的盈利**，本档只能给出净资产侧的下界参照。
