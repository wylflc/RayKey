## 合理价区间

**188.17 ~ 229.99**

**方法**：三阶段DDM：3年@5.0% → 5年线性衰减 → 永续 3%，r=8.5%

**推导**：E0 = FY2026E 经调整 EPS HK$12.28（第一上海 2026-05-18 经调整净利 150.5亿元 ÷ 13.32亿股 × 1.087）（每股 12.28）；分红率 35%（FY2025 派息率约 35%，轻资产、无重大资本开支需求）；ROE 77.5%（FY2025 年报 77.52%，本仓库 hong_kong_financial_indicators.csv）；终值期分红率 = 1 − 3%/77.5% = 96.1%；g1 = 5.0%（公司指引「不低于20%」，但 2026Q2 同比仅 +1.6%、环比 −16.3%，H2 面临 Labubu 高基数——指引与实测背离时取实测方向，故 g1 取 5%；单一 IP 生命周期风险不允许按指引外推三年，取一致预期窗口 3 年不外推）；现值 = 209.08（隐含 PE 17.0x），× [0.9, 1.1]（现值锚不叠加安全边际）= 188.17~229.99。**通用口径为何不成立**：ROE 77.5% 属极端高资本效率，命中 OI-005「ROE ≥20% 档 CAGR <15% 即 PEG 失效」；且 IP 潮玩的价值高度集中在存量 IP 的现金产出能力而非增长速度，PEG 会把一个 IP 生命周期问题误读成成长股定价问题。风险交叉校验：本档假设 Labubu 之后仍有可延续的 IP 矩阵；若单一 IP 收入占比持续 >40% 且无新 IP 接棒，g1 与终值均须重估——这是 L4 的核心不确定性

## 参考分理由（§5.7.4）

Q1 70：预收+高毛利+轻资产，商业模式本身现金流优良。Q2 58：IP 潮玩护城河依赖单一爆款生命周期，可复制性高、切换成本低——这是 L4 的主因，非规模问题。Q3 72：扩张纪律尚可、无高杠杆并购。Q4 68：创始人主导、执行力强，但缺乏跨周期检验。

## 跟踪指标

单季营收同比（阈值：连续两季负增长即 g1 归零）；单一 IP 收入占比（阈值 >40% 预警）；海外门店同店销售；新 IP 首年流水；存货周转天数

## 复核触发

每季经营公告与半年报；头部 IP 授权/续约变化；海外扩张节奏调整；渠道去库存迹象
