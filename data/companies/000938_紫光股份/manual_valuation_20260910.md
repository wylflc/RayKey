# 紫光股份：按现有披露手算退出情景

用户于2026-09-10明确要求现在给出手动估值。信息截止2026-09-10（北京时间），资产负债及股数基准为2026-06-30；不对其后未披露的现金变化或这段时间的价值增长机械滚算。本页是有条件的研究估算，生产模型仍为 `minority_claim_blocked`，不写入档案合理价、P/V或交易清单。

**结论：基准约14—15元/股；保守约8元，乐观约24—26元。** 约8—26元是下列情景的取整跨度，不是置信区间、全部可能结果的边界或买入价。现金回收能力尚未核实，暂不把乐观结果作为主要判断。此前固定旧EV得到的约19—22元只是股权桥诊断，不能沿用为本次估值。

**经营价值计算。** 中报利润表从收入扣成本、税金及附加、销售、管理、研发、信用减值和资产减值，加其他收益，再剔除非经常政府补助0.8983亿元及单项应收减值转回0.1924亿元，得到半年经营EBIT约27.7460亿元。财务费用、投资损益、公允价值变动、处置及营业外项目均未加入这个经营分子，汇兑及旧股权远期收益不作为经营增长。

该半年经营利润按15%的研究税率、简单乘2，对应全年NOPAT约47.17亿元。年化只检查量级，并非2026全年预测，也未消除季节性。基准取45亿元，保守40、乐观50。NOPAT不等于归母净利润。原始项目和计算数保存在下述脚本中。

增长及回报率均为手动研究假设。最近两年原取数的集团ROIC约6.82%、8.05%，2021—2023年约10.92%—13.83%；基准增量ROIC12%要求新投入效率恢复，乐观14%要求进一步改善，尚非已验证事实。每年按增长／增量回报率扣再投资，包含净资本支出和营运资金需要；不把净利润全部当现金。历史核验记录见[年度指标](../../interim/company_review_20260910/annual_metrics.csv)。

设t=1…10，`g_t = g0 + (3%−g0)×(t−1)/9`，增量回报率按相同方式从起点降至`min(起点回报率,WACC+2个百分点)`：

```text
NOPAT_t = NOPAT_(t−1) × (1 + g_t)
再投资_t = NOPAT_t × g_t / 增量回报率_t
FCFF_t = NOPAT_t − 再投资_t
终值 = NOPAT_10 × 1.03 × (1 − 3%/终值回报率) / (WACC − 3%)
EV = Σ[FCFF_t / (1+WACC)^t] + 终值 / (1+WACC)^10
```

基准第1年NOPAT48.60亿元，扣再投资32.40亿元，FCFF16.20亿元；第10年FCFF52.53亿元，合计现值791.29亿元。全部逐年数见[结果文件](../../interim/unis_manual_20260910/results.json)。

7%—8%是经营现金流折现率的研究假设，不是财报事实或生产参数修改。仓库10%为权益要求回报率，生产FCFF另按债权／权益权重计算WACC，旧紫光结果实际为5.89%。考虑营运资金占用、融资和退出的不确定性，本次采用更高WACC；其影响很大，敏感度另列，基准14—15元不是高精度结论。

**少数股权计价与去重。** 为估计存续权益及未来换股对价，需要新华三自身股权价值H。其2025全年净利润31.5149亿元，加2026上半年23.8809、减2025上半年18.5085，TTM为36.8873亿元。三档分别乘14／18／22倍，得H=516.42／663.97／811.52亿元。

倍数是研究假设。参照是9月8日披露的评估：新华三2025年底100%股权收益法价值544.62亿元，扣约定历史分红后516.00亿元；本次交易对应505.63亿元、2025年市盈率16.04倍。保守H约等于该历史评估参照，基准和乐观要求更高的持续盈利估值；该历史评估不是2026年6月底的新估值，更不保证未来换股价格。H只衡量少数权益，不与集团EV相加或减集团债务。来源：[问询回复第15—18、22—23页](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12588145&stockid=000938)，利润来自中报及[2025审计报告](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12088791&stockid=000938)。

将7.9178亿元分红现值按持股比例分配：退出部分`L_p=L×p/s=6.6267`亿元，存续部分`L_q=1.2911`亿元。按股同比例分配及将该负债用作退出前分红代理，均属手算假设，未获得逐投资者精确期限现金流。存续1.96%的价值已经包含其分红，只取`max(qH,L_q)`，不再加一遍L_q。

现金路径取得10.06%的全部后续权益，扣回购现值和退出前分红，不再永久分走这10.06%：

```text
Q = EV − 金融债务D + 超额现金 − 其他少数权益B
现金退出每股价值 = [Q − max(qH,L_q) − K − L_p] / N
基准 = [791.2924 − 291.0486 − 6.1728 − 13.0138 − 44.4610 − 6.6267]
       / 28.6008 = 15.03元
```

换股路径不用K另扣现金；先从pH中剔除退出前分红，余下`C=pH−L_p=60.1688`亿元作为换股剩余权益的对价现值。发行价若相当于摊薄后合理价值的α倍，发行给对方的股份合理价值为C/α。

```text
换股退出每股价值V = [Q − max(qH,L_q) − L_p − C/α] / N
基准α=0.8：V = [494.0709 − 13.0138 − 6.6267 − 60.1688/0.8]
                 / 28.6008 = 13.96元
```

算术核对：基准等价发行价αV=11.1667元，等价新增5.3883亿股；`(Q−qH−L_p)/(N+新增股数)`同样等于13.96元。这是把未来对价和每股价格转换为同一现值口径的示意，**不是实际发行价或新增股数预测**。假定退出前母公司可分配资金以零净现值方式留存，将时点影响吸收到等价现值；未单独预测母公司退出前派息、可转债票息和转股重置，也不是完整期权定价。

α=80%并非合同写着“内在价值八折”。实际合同以董事会决议前20／60／120日的某个股票交易均价为基准，约定80%的发行价；未来市场均价相对合理价值可以偏高或偏低。这里α将两者差异一并参数化，取60%和100%另算敏感度。未来评估H、分红及时间变化须同步更新。合同亦规定现金退出触发条件及交割后36个月的上翻安排，不是现在已锁定实际发行。来源：[投资合作协议1.2—1.6](https://paper.cnstock.com/html/2025-11/18/content_2146872.htm)及[分红安排14.1—14.7](https://paper.cnstock.com/html/2025-11/18/content_2146864.htm)。

H上升而现金路径紫光价值略降，是因为该敏感度固定集团EV，只提高对其他股东的权益计价；真实经营改善时EV也应同步提高。若改用10%直接折现FCFF，基准两条路径仅5.70／4.62元，折现口径不能含混。

公司另有上限54.10亿元、4.30亿股的融资计划，其中33.90亿元置换已支付收购款、4亿元研发设备、16.20亿元还银行贷款。截至所用披露尚在审核，不能当已发行。若做两项上限同时用足的等价情景，发行价为12.58元，按`(原权益价值+54.10)/(28.6008+4.30)`计算；换股路径将同一α定义应用于两项发行后的价值。基准现金／换股结果为14.71／13.78元，乐观为24.03／22.53元。募集资金和新增股数一起计入；置换过去的收购款不再花一次。忽略发行费用，未来研发和营运投资已由FCFF再投资覆盖，不再加项目溢价；实际金额、发行价、时点及融资对WACC的影响另待更新。来源：[募资用途二次修订稿](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12499867&stockid=000938)及中报第49页。

基准约74%的EV来自终值，乐观约81%；叠加中报经营现金流为负及库存、应收占款，**增长能否转化为现金比股权桥的小数点更重要**。可立即更新的输入是正常化经营利润、回款与库存、实际退出对价和发行价，不要求硬等若干年。本次已能手算退出情景，但不足以宣称合同期权精确定价或恢复生产带。
