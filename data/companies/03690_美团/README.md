## 合理价区间

**66.49 ~ 82.13**

**方法**：派息折现隐含PE：分红率/(r−g) = 67%/(8.5%−4.0%) = 14.8x

**推导**：锚 = 正常化经调整净利约 300亿元 ÷ 61.75亿股 × 1.087 = HK$5.28（战前 FY2024 经调整净利 437.7亿，扣即时零售规模扩大后的结构性利润率下移与骑手社保成本）（每股 5.28）；分红率 67%（可持续口径 1 − g/ROE = 1 − 4.0%/12.0%）；可持续增长 4.0%（到店稳态低个位数 + 闪购增量的混合，取 4%——戈登式里的 g 是**永续**增长率而非未来三年增速，房子判例（茅台 5%/长江电力 2.2%/神华 2%/双汇 1%）全部 ≤5%；原 8% 逼近 r=8.5%，分母只剩 0.5pp，带会被放大到现价的四倍）；ROE 12.0%（当期为负（FY2025 −14.43%，补贴战期间）；此处用正常化 ROE 12%，与正常化利润口径一致）；r = 8.5%（账户级要求回报）→ PE = 0.67/(0.085−0.040) = 14.8x；合理价 = 5.28 × 14.8 = 78.22，× 分层系数 [0.85, 1.05]（L2）= 66.49~82.13。**通用口径为何不成立**：当期 ROE 为负、利润为负，PEG 与任何以当期利润为锚的口径按 §6.5.3 C 类失效条款均不适用，必须先正常化再定价。原带「修复后合理PE 16-21x」是直接指定。⚠本档对正常化 ROE 取 12% 是假设而非实测（当期为负），是本档最弱的一环；若补贴战延续至 2027 年且经调整净利未回到 200亿以上，须改判无法估值

## 参考分理由（§5.7.4）

Q1 72：高频刚需、密度经济显著，但骑手成本刚性且补贴可被对手复制。Q2 66：即时配送网络密度与商户供给是真壁垒，然外卖战证明其可被资本强攻。Q3 62：新业务投入规模大、回报周期长。Q4 70：执行力强、组织效率高，战时应对稳健。
