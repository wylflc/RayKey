# OI-217 估值公允性检验预登记：三种 WACC 权重的 P/V 对其后回报（2026-09-25 北京时间，建带与分析之前）

## 问题

用户要求不看组合回测（持仓集中，读数取决于几只赢家买多买少），改问：哪种 WACC 权重给出的 `P/V` 更能区分各股票的高估与低估，并由其后的实际走势验证。三臂只差 WACC 的债务权重，其余为 v4.208 生产口径：

| 臂 | 开关 | WACC |
| --- | --- | --- |
| `C` | `--wacc-weights book`（生产） | 账面权益与毛有息负债加权，r = 10%，税后债务成本 |
| `W` | `--wacc-weights net`（第一候选） | 债务权重取 max(0, 有息负债 − 超额现金)，净现金即 r |
| `U` | `--wacc-weights unlevered`（第二候选） | 一律 r |

同一股票同一日恒有 `V_C ≥ V_W ≥ V_U`。`d_W = ln(PV_W / PV_C)` 只在同时有有息负债与超额现金时为正（「净现金调整」），`d_U = ln(PV_U / PV_W)` 只在净负债为正时为正（「净负债调整」）。

## 数据

- `C`、`U`：`exp_oi217u_20260925/states/{CONTROL,WU}_build/`（`C` 已逐行复现 v4.208 生产状态）。
- `W`：本目录 `build.py` 以 `exp_oi217u` 的冻结输入（除权事件表、生产命令）另建候选侧，只建 base 与银行覆盖。建前核对 5,721 个输入文件与冻结清单逐位相同。建后核对：`wacc_W = r` 的带与 `U` 带值相同，`wacc_W = wacc_C` 的带与 `C` 带值相同。
- 观测：候选侧逐日状态每只每月最后一个交易日的 `valuation_ratio`；月末 2007-01-31（新会计准则起）起，至前向窗口完整为止（行情截至 2026-08-28）。
- 前向回报：3 年与 5 年含现金分红再投的年化总回报（`moat_param_lab.total_return_index`／`forward_annualized`，与 `panel_tier_forward.py` 同式）；回归用 `y = ln(1 + R)`。
- 只取 ROIC 路径：状态所用带在三臂都是 `growth` 或 `zero_growth`。`equity_fallback` 带不用 WACC、三臂逐位相同（`C` 全市场 ok 带 206,205 条中 188,937 条），不进样本；ROIC 路径只覆盖有三大报表的 302 只（面板 253 只，另 49 只为今日分档表 1 只与其他有报表的公司）。
- 剔除：银行与保险（`divspread_names.is_divspread_financial`）；某臂「沿用旧带」的行（该臂有报告期更新、可得日不晚于当日的拒绝带，状态仍用更早的 ok 带）视为该臂无法估值。
- 共同样本：三臂同一股票同月都有非沿用、`P/V > 0` 的 ROIC 路径观测。主样本再限 `0.2 ≤ PV_C ≤ 5`；稳健性为不限区间、三个解释变量按 1%/99% 缩尾。
- 两个总体，同等地位：面板（`panel_moat_bank_v6b.csv` 在册期）与全部 ROIC 路径月份（302 只，含在册期外）。

## 读数

1. **分歧分布**：`d_W`、`d_U` 的分位数，`ln(PV_U / PV_C) ≥ 0.10` 的占比，平均分歧最大的股票。
2. **排序力**：每月截面 Spearman(P/V, 前向回报)，三臂各自与两两配对差的月均值，Newey-West t（滞后 = 前向月数）。
3. **包含检验（主读数）**：月固定效应的混合回归 `y = a_t + b·ln PV_C + g_W·d_W + g_U·d_U`。`λ_W = g_W / b`、`λ_U = g_U / b` 表示数据认可的调整比例：1 = 该臂调整恰好，0 = 调整无信息（现口径同样准），< 0 = 方向错。90% 区间取按股票整体重抽 1,000 次的分位数。稳健性：行业（证监会门类，公司索引 `industry`）× 月固定效应。
4. **分歧样本校准**：一致组 `|ln(PV_U / PV_C)| < 0.02` 拟合 `y = a_t + b·ln PV`（组内月效应）。分歧组 `ln(PV_U / PV_C) ≥ 0.15` 按三臂各自 `P/V` 代入预测，报平均残差（实际 − 预测）与 90% 区间；残差最接近 0 的臂校准最好。分歧组再分净现金型（`d_W ≥ 0.75 × 总分歧`）、净负债型（`d_U ≥ 0.75 × 总分歧`）与混合型。另列分歧组按各臂 P/V 分桶的回报中位与一致组同桶对照。
5. **拒绝名单**：`C` 可估、`U`（或 `W`）无法估值的观测，按一致组校准在 `PV_C` 处的平均残差。残差显著为负，即市场也把这些公司当作更贵，支持拒绝。
6. **个股**：面板内共同样本 3 年前向月数 ≥ 24 者，平均 `d_W` 最大的 4 只（`C` 与 `W` 分歧）与平均 `d_U` 最大的 4 只（`W` 与 `U` 分歧），加格力、长江电力（后者多数月份被 `U` 拒绝，按读数 5 的口径列）。逐年 12 月末列三臂 `P/V`、其后 3／5 年实际年化、按一致组校准的三臂预测回报，并报每只的预测平均绝对误差。

## 判定

读数 3 的 `λ`：90% 区间不含 0 且含 1 为「数据支持该调整」；含 0 不含 1 为「不支持，现口径更准」；0 和 1 都不含时按点估计报比例；都含为「不能区分」。两个总体、两个期限方向一致才作结论，否则报「证据不一致」。本检验为用户裁定的证据，不改生产。

## 已知局限

- 3／5 年窗口逐月重叠，股票×月不是独立样本，推断只用按股票重抽与 Newey-West。
- 检验的是市场其后的定价，不是现金流本身。分歧集中在重资产、高负债行业，行业与时期的系统差异可能被归到 WACC 上，行业×月效应只能部分剔除。
- 面板分档含后视；有三大报表的 302 只多为面板与今日分档表的公司，本身带幸存者偏差。窗口内退市的股票没有前向回报，高负债困境股可能因此被少计。
- 本轮之前已看过面板整体 Spearman（`pv_forward_*.txt`：三臂几乎相同），本检验的新读数是分歧维度。
