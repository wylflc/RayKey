## 臂（均对现行 `BASE`，单变量，生产缺省关闭）

| 臂 | 规则 | 取值 |
| --- | --- | --- |
| `DPs{D}` | 持仓侧 `P/V` < D 的持仓不作换仓卖出源（现有 `--swap-out-min-pv D`） | D = 0.6／0.7／0.8 |
| `DPs{D}e` | 同上，但 E1 < 0.84 的持仓不受保护 | 同上 |
| `RE{N}` | 建仓止损清仓后 N 个交易日内、候选侧 `P/V` 仍 ≤ 买入线的，再建仓的走势条件只要求收盘 > MA20（信号日与 T+1 确认同改，去掉 MA20 > MA60）；此类重入仓的止损锚取成交日 MA20，生效线 = min(锚, 当日 MA20) | N = 60／120／250 |
| `RE{N}e` | 同上，但 E1 < 0.84 的股票不放宽 | 同上 |

- E1 = 近三个财年经营现金流合计 ÷ 归母净利合计，按年报可得日取最近一行（`e1_table.csv`，口径同 §12.271）；缺失时视为不低于 0.84。
- 阈值 0.84 是 §12.271 买入区样本 E1 五分位的最低分界，由陷阱识别检验事先得出，本批不另调。
