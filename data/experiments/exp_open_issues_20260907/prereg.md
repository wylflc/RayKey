# OI-160/161/163/164 逐项复核预登记

沿用各项轨道 B、现行交易规则及标准起点。所有实验保持生产常量与 BASE 不变。面板使用 OI-165 按原入池日期修复后的版本；先核对修复前后的护栏与原 BASE 一致性。行情与估值不刷新。

先跑剔除赢家数量 K=1/3/5/10 的剂量曲线。每档从本轮 BASE 的 2011-11-01 锚点 contrib 排名前 K 统一剔除，对同剔除集 BASE 配对；10 条在册候选全部保留，不挑正读数子集。K5 复核原 A/U 结果。主读数和复利读数分别按 ±0.15pp 噪声区描述符号；某一指标同时出现正、负方向，视为第 4 款所要求的四档同向失败。失败候选停止采纳验证并报告不采纳；通过此项仅继续检验，不构成采纳。

对未被剂量检验排除的候选：换仓边际 0.10~0.20、步长0.01重扫，同时对原 BASE 与本臂0.15配对；若最佳结果仅在边缘不宣布平台。仍有可采纳平台才补信号层选择/排序/换仓方向及容差0.04/0.10/0.15、P/V分档前向、前三贡献和同族臂数。达到采纳前条件者补固定 A/U 的0/10/20/30bp成本压力；固定金额方案还核对当前账户规模。最终是否采纳交用户决定。

只用于否决的早停无需运行采纳前的其余项目；报告明确哪些未执行及原因，绝不声称未跑的检查已通过。
