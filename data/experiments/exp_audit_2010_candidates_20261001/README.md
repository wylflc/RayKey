# 2010 年前后回测买入候选核查

用户 2026-10-01：「对于 2010 年左右的市场，我印象里面回测买入候选都是一些奇怪的股票，请核实一下当时的财务数据是否正确，以及候选的低估股票是否合理。」研究核查，不改口径。

- `audit.py`：
  - 候选：时点股票库成员与月末买入区成员（`exp_oi245c_20260930/observations3.csv`）、现行 BASE（S15）2009-11～2012-06 首次建仓（`exp_oi247_20260930` 台账）、2010 年月末在买入区但不在股票库的代码、旧实验台账的早期首次建仓。
  - 财务数据：仓库摘要与年报三表对本地年报原文「主要会计数据」表（`data/raw/annual_reports/`），并查次年年报的上年比较数（重述）、公告日与带可得日。
  - 入选时估值：信号日状态与所挂的带、PE、PB、ROE，其后 3 年年化与 S15 周期贡献。
  - 首次运行流式读 2 GB 逐日状态，摘录缓存为 `extract_*.csv.gz`（不入库）；`--refresh` 重新摘录。
- 输出 `audit.json`、`audit.md`。作业：`scripts/slurm/audit2010.sbatch`。

    python3 audit.py
