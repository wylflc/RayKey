## 固定在跑数之前

- 标准先改：§8.3 增证券代码变更规则，参考表 `data/reference/a_share_code_succession.csv`（唯一实现 `scripts/code_succession.py`）：事件表按表把新码名下不晚于旧码末个交易日的事件复制到旧码；面板装配校验旧码区间不晚于旧码末日、新码区间不早于新码首日，违反即失败。
- 判定源：`verdicts_pit_moat_v6.csv` 增 `001872` 除名行（主体判定由 `000022` 承载 2004–2015，新码启用时主体已退出且未另判）。
- 状态：`000022` 两侧逐日状态与带按 §6.7 第 2/2b 步命令以 `--codes 000022` 重建并拼回生产文件（其余代码行逐字节不动，拼接前后非 000022 行哈希相同），再按第 3 步合成持仓侧。核验：在册期 2005-04-30～2016-04-30 内，与 `001872` 同一带期的行 V 相对差 ≤ 1e-3；送转因子逐日相同。
- 回测：只有输入变化，引擎与 `BASE` 参数不变。`OLD` = 修复前快照输入（面板、候选侧与持仓侧状态、事件表，哈希见 `old_inputs/SHA256SUMS`，候选侧状态哈希 2bd535c9… 与在册一致），`NEW` = 修复后生产输入。14 个标准起点，全样本／A（A = `OLD` 臂 2011-11-01 前五赢家）／U（与 A 不同时另跑），0bp（v4.188）。先验证 `OLD` 在 2011-11-01 起点逐字段复现在册 `summary_BASE20111101.csv`。
- 判定：§12.1 轨道 A 护栏——主读数与复利读数（全样本表）各自损失 ≤ 1pp，闸门（滚 5 回撤中位变深 ≤ 3pp）与否决（负窗 0→正不过半）不得触发。通过则 `NEW` 28 条全/A 路径按 OI-168 先例重登 `BASE`（同键覆盖，旧读数留 Git 与 §12.239）；不通过亦不保留错误输入，改为报用户。回测解释只依据测量结果，不因收益好坏改变机制修复。
- 不在本批：§12.241–§12.244 描述统计的重算；`001872` 2018-12-26 起是否重新判定（需 v6 判定源另行给出）。
