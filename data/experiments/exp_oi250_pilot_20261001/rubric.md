# OI-250 试点：业务属性判定口径（草案，交用户审阅）

对象：2026-09-30 候选侧池带中峰守卫生效（w > 0）的 57 只池内公司（`inputs.csv`，含 §7.3 结构性增长复核入队的 3 只）。
判定时点：2026-09-30，只用该日可得的信息。依据以仓库研究记录为主（`inputs.csv` 的护城河、复制测试、侵蚀路径、同业、
档案指标与复核触发），可补充公开常识，但不得用 2026-09-30 之后的事。每项写依据与可证伪条件。

## 四项属性

1. **定价方式**（`pricing_mode`）
   - `商品价格接受者`：主要利润来自标准化商品，售价跟随公开市场或交易所价格，公司无法独立定价。
     例如金属、煤、油气、大宗化工、钾锂、猪鸡、造纸、航运运价。
   - `差异化定价`：产品或服务有品牌、技术、规格或客户认证差异，价格由公司议定或自主定价。
     行业价格周期影响利润的也算，例如 PCB、光模块、设备。
   - 混合业务按**利润主导项**判，在依据里写明占比或主导理由。
2. **需求空间**（`demand_runway`）
   - `存量`：行业总需求增长不高于名义 GDP，或已饱和；利润增长主要靠价格或份额。
   - `结构扩张`：有可验证的长期扩张驱动，例如渗透率提升、新应用、技术替代，未来 3～5 年行业需求年增明显高于 GDP。
     须写明驱动与可证伪的量。
3. **可复制性**（`replicability`）
   - `易复制`：新进入者或同行扩产 1～2 年内即可复制产能，无认证或技术门槛。
   - `难复制`：技术、认证周期、客户绑定、牌照、资源禀赋或规模经济使新进入者短期难以复制。
     以仓库「资本复制测试」结论为主要依据。
4. **成本地位**（`cost_position`）
   - 只对商品价格接受者判：`领先`（单位成本处行业前 25%，有结构性来源，同 §5.6 H 标签核验）或 `一般`。
   - 差异化定价的填 `不适用`。

## 派生类别（`derived_class`）与峰守卫看法（`guard_view`）

| 条件 | 类别 | 峰守卫看法 |
| --- | --- | --- |
| 商品价格接受者且成本一般 | 价格周期型 | 保留：高位利润按周期中位 |
| 商品价格接受者且成本领先 | 成本领先周期型 | 保留：中位本身较高，不放宽 |
| 差异化定价、结构扩张、难复制 | 结构成长型 | 可个案放宽：经 §6.5.2.2 研究数复核 |
| 结构扩张、易复制（不论定价方式） | 可复制成长型 | 保留：扩产与竞争会侵蚀回报 |
| 差异化定价、存量 | 稳定型 | 保留：守卫作用多为消化一次性高位 |

商品价格接受者一律归周期型，需求扩张（例如锂）也不例外，在依据里注明需求面。

## 校准例（统一口径用）

| 公司 | 定价方式 | 需求空间 | 可复制性 | 成本地位 | 类别 |
| --- | --- | --- | --- | --- | --- |
| 紫金矿业 | 商品价格接受者（铜、金） | 存量（金价、铜价驱动） | 难复制（资源禀赋） | 领先 | 成本领先周期型 |
| 天齐锂业 | 商品价格接受者（锂） | 结构扩张（电动化、储能），但利润由锂价主导 | 易复制（锂资源与产能扩张快） | 一般 | 价格周期型 |
| 宁德时代 | 差异化定价 | 结构扩张（电动化、储能） | 难复制（技术、规模、客户认证） | 不适用 | 结构成长型 |
| 青岛啤酒 | 差异化定价（品牌） | 存量（啤酒总量不增） | 难复制（品牌、渠道） | 不适用 | 稳定型 |
| 中际旭创 | 差异化定价 | 结构扩张（AI 算力） | 难复制（高速光模块技术与客户认证），侵蚀：同业扩产、客户集中 | 不适用 | 结构成长型 |

## 输出（`attributes.csv`）

| 列 | 说明 |
| --- | --- |
| `security_code`、`security_name` | 同 `inputs.csv` |
| `pricing_mode`、`demand_runway`、`replicability`、`cost_position` | 四项属性 |
| `derived_class`、`guard_view` | 派生类别与峰守卫看法 |
| `evidence` | ≤ 120 字，点出所依据的仓库记录或公开事实，带年份 |
| `evidence_date` | 依据的最晚可得日，不晚于 2026-09-30 |
| `falsifier` | ≤ 60 字，改判条件，尽量写成可量的指标与阈值 |
| `confidence` | 高、中、低 |
| `note` | 可空；分歧点或与财务读数（峰守卫、量驱动）不一致之处 |
