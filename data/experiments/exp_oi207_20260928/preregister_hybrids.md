# OI-207 混合候选：预登记（2026-09-28 北京时间，计算之前）

## 背景

九种方法的读数见 `preregister.md` 与回测日志 §12.270。取舍在于：
- 现行股利利差 D0 在统一买入线下抓银行机会最好（机会占比 ÷ 基准率 2.09），但与非金融同尺时银行偏便宜：面板 3 年偏差 c = −2.6%／年。
- ROE／账面类方法在银行之间排序更好，DDM10 的 1 年期优势显著。

用户 2026-09-28 裁定再测两个混合候选。

## 候选（均由 `observations.csv` 的月末 `P/V` 派生，时点可得）

| 代号 | 构成 |
| --- | --- |
| `H1` 利差尺度校正 | `V = DPS ÷ (十年国债 + RP*)`，即 `P/V_H1 = P/V_D0 × (rf + RP*) ÷ (rf + 2%)`。RP* 在 2%～8% 间按 0.25pp 一档扫描，只用**观测月 ≤ 2016-12** 的面板 3 年样本求：取与非金融同尺回归的银行偏差 c 最接近 0 的一档。2017 年起为样本外 |
| `H2` 股利尺度 × DDM 排序 | 每月银行截面：`ln PV_H2 = 当月银行 ln PV_D0 的均值 + (ln PV_DDM10 − 当月银行 ln PV_DDM10 的均值)`。水平随股利模型，银行之间的相对高低随 DDM；两者当月都可估的银行才计入均值 |
| `H3`（参照） | `H1` 的水平 × DDM 排序，即上式把 D0 换成 H1。非用户点名，只作参照，不作候选 |

## 读数（同 `preregister.md` 的 R1～R4，另加样本外）

- **R1** 银行内部排序力：H2 的排序与 DDM10 基本相同，H1 与 D0 相同。报出以便核对。
- **R2** 与非金融同尺的偏差 c（面板与全部，3 年）：全样本、2016 年前（H1 的训练段）、2017 年起（样本外）三段分报。
- **R3** 招行、宁波对四大行个案。
- **R4** 第 13 款银行子集读数（买入线 1.0670）。
- 当前银行与保险在各候选下的 `P/V`（2026-09-28 收盘，按冻结的生产 D0 与 DDM10 状态末行推算），以及是否在买入区。

## 解读

- H1 的 RP* 是按历史结果校准出的参数，存在过拟合风险。**以 2017 年起样本外的 c 与 R4 为准**；样本外 c 仍显著偏离 0 时，不作为候选推荐。
- 读数只作裁定参考。
