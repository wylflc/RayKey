# 卖出后余仓清空阈值检验

结论：本轮没有阈值同时满足两种样本的收益不劣要求，实盘规则与回测 BASE 均保留。用户指定的 1.5 档可减少操作，但去赢家后的全期年化配对差为 −1.05pp，不满足「不影响收益再改」。1 档落在两种样本反向的裁定区间，也不在本次条件授权的自动采纳范围内。

## 范围与可复现性

- 2026-09-07 预登记轨道 B；六个阈值一次登记，未在看到结果后追加参数。此前同族 `RESTRANCHE` 为旧计量口径，本轮不跨口径比较收益。同族已试 7 臂，其中本轮 6 臂，已按 `scan_arms_index.csv` 核验。
- 当前 BASE，14 个半年起点（2009-11-01 至 2016-05-01），全样本及去赢家各一遍，共 196 条路径；实际净值末日 **2026-08-28**。手续费、融资、整手、T+1 执行与公司行动处理相同；每边额外滑点为 0bp。
- 仅在原本已触发的卖出中，按整手算完正常减档股数后，若余仓价值严格小于 N 个当日一档预算，则扩大同笔卖出至清空。一档复用引擎现行 `budget = 交易前净资产 × 5%`，不更改预算时点。包含高价股一手减持；原有整仓止损及同日买卖净额对冲规则保留。
- A = 601088／002128／000933／000651／000338。六条候选的锚点赢家顺序有所不同，集合全部相同，所以每条候选的 U = A，本轮 A 的 28 条配对路径就是对应的对称 U 检验。名单证据与判定保存在 `verification.json`。
- BASE 的全/A 共 28 行 × 44 列与上一轮 `exp_volume_trigger/sweep_stage1.txt` **逐字相同**；没有用不同基准拼接结果。输入摘要见 `input_manifest.json`。回测结束后只把 CLI 帮助的「信号日买入档位」勘误为「当日买入档位」，计算行为没有改动，最终代码摘要另记 `verification.json`。

## 操作便利性与限制

2011-11 起点的**实际净额成交**重放（截至 2026-08-28）：

| 指标 | 现行规则 | 1.5 档清空 |
| --- | ---: | ---: |
| 买入笔数 | 1,908 | 1,791 |
| 卖出笔数 | 505 | 444 |
| 卖出日末仍有小于 1.5 档余仓的票日 | 70 | 8 |
| 卖出日末仍有小于 0.5 档余仓的票日 | 28 | 3 |
| 卖出日末仍有小于 0.1 档余仓的票日 | 8 | 2 |
| 卖出日末仍剩 100 股的票日 | 3 | 2 |

卖单减少 61 笔（12.1%），小于 1.5 档的余仓事件减少 88.6%。此表从成交与送转、配股记录重建，逐日持仓只数与引擎的 3,603 个净值日逐日核对，两臂均无差异。流水只保留整数股，允许不到一股的舍入残差；描述用余仓价值按最后卖价、当日日末净资产一档折算，与引擎交易前判据的时点不同，不能反过来检验触发边界。完整事件见 `ledger_audit.json`。

**不能保证从此没有 100 股余仓。** 1.5 档剩下的 8 个小额余仓事件全部来自同日买卖对冲，包含 2 个 100 股事件（2014-06-17 600188、2025-07-18 601818）；对冲恢复了部分原拟卖出的股票。这些不是整手取整遗漏。本轮没有另外修改对冲后的净额执行规则。

全样本 14 起点的引擎卖出计数配对差中位为 −56 笔，持仓数中位没有变化；但年均换手配对差中位 **+0.89 倍**，A/U 为 +0.16 倍。少几笔单不等于少交易金额，提前清空余仓会影响后续资金分配。各阈值的全/A 表见 `convenience.csv`。锚点归因见 `attribution_RC150.txt`：66 只股票贡献改变，前三净贡献占比 57.8%，不把归因和单锚损益当作主判据。
