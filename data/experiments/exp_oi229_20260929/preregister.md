# OI-229：买入区陷阱识别（E1 之外）——预登记（2026-09-29 北京时间，跑数之前）

## 问题

OI-224 第一步（回测日志 §12.271）在 15 个时点特征里只找到 E1（近三年经营现金流 ÷ 归母净利）能识别买入区陷阱，且抓不住周期高点陷阱（海螺 2019、神华 2012、潍柴 2011）。OI-227 结案时用户说：

> 如果仍然容易买入陷阱公司，更本质的做法应该是找方法识别这些陷阱公司，而不是为了好看的回测数据改原则。

OI-229 的动作是在 E1 之外，按 OI-229 条目列出的三个方向（周期守卫之外的行业景气位置、资本开支周期、价格与利润背离）设计时点识别候选，并按 §12.1 第 13 款的答案卷预登记检验。本检验只回答「能否识别、能否在 E1 之外补充识别」，不改任何规则。

## 样本与标签

- 标签：答案卷 v1（`data/backtest/opportunity_trap_labels_v1.csv`，sha256 `f236fc1d…c53d372`）在册且有标签的股票月。定义同 §12.1 第 13 款：陷阱 = 其后 3 年年化 ≤ 0、超额 ≤ −10pp、3 年后盈利降 ≥ 20%；机会 = 3 年年化 ≥ 20%、超额 ≥ +10pp、盈利不降。
- 主样本：买入区股票月，即 v4.219 生产逐日状态（`data/processed/a_share_daily_states_adopted.csv`，sha256 `92772324…b564d6`）在答案卷月末日的 `P/V ≤ 1.0034`（现行买入线）。
- 银行与保险（`divspread_names.is_divspread_financial`）不进主样本：下列特征多数对其不适用。
- 另报全部在册月（非金融）作对照，只描述。
- 特征一律按观测日时点可得：报表可得日按 §6.3 第 2 条以法定截止日封顶；逐季面板取 `build_historical_valuation_bands.load_financials(notice_cap=True)`，三大报表取 `roic_inputs.load_statements`，价格取 `load_ohlcv` 与公司行为表合成的含分红总回报指数（答案卷同一实现）。

## 特征（跑数前定下，不增不减）

行业一律为证监会行业大类（`data/archive/pit-judgment-2026-08/f10_org_profile.json` 的 `INDUSTRYCSRC1`，3,598 家，与 OI-224 同源，现行归属回溯全历史）。

**行业统计量的时点**：季度 q 的行业统计量自该季法定截止日（一季报 4-30、半年报 8-31、三季报 10-31、年报次年 4-30）起可用；观测日取截止日 ≤ 观测日的最近一季。统计量 = 该大类当季有数的公司（至少 5 家）的中位数。「位置」= 当季值在该行业截至当季的 40 个季度（至少 20 个有值）同一统计量中的分位（≤ 当季值的占比）。

| 组 | 代号 | 特征（方向：值越大越像陷阱记 ↑，越小记 ↓） |
| --- | --- | --- |
| 行业景气位置 | C1 | 所属大类公司 ROE TTM（`roe_ttm`）中位数的位置 ↑ |
| | C2 | 所属大类公司 TTM 毛利率中位数的位置 ↑（TTM 毛利 = 本期累计毛利 + 上年年报毛利 − 上年同期累计毛利，累计毛利 = 累计毛利率 × 累计营收） |
| | C3 | 所属大类公司 TTM 营收同比中位数的位置 ↑ |
| 资本开支周期 | K1 | 公司总资产增速：最新两个相邻已可得年报的总资产同比 ↑ |
| | K2 | 行业资本开支强度：同大类估值池公司（含自身，至少 3 家有近三个财年）近三个财年资本开支合计 ÷ 折旧摊销合计 ↑ |
| | K3 | 公司资本开支扩张：近三个财年资本开支合计 ÷ 此前三个财年合计 ↑ |
| 价格与利润背离 | D1 | 12 个月模型价值变化 log(V_t ÷ V_{t−12}) = 12 个月 log 总回报 − log(P/V_t ÷ P/V_{t−12}) ↑（「因 V 跳升而便宜」） |
| | D2 | 12 个月相对回报：12 个月 log 总回报 − 同月在册股票的中位 ↓ |
| | D3 | 利润升而价格落：log(1 + 归母净利 TTM 同比，截在 [−0.9, 5]) − D2 ↑ |

- E1 按 OI-224 定义同表重算，只作 T6 的分层依据与参照，不参与判定。
- K1～K3 需要三大报表，只覆盖估值池 345 家有报表的公司；缺失的股票月在该特征读数中剔除，并报覆盖率。
- D1 需要 12 个月前同一股票有 `P/V`，D2、D3 需要 12 个月前有价格。
- 方向按财务常识与 OI-229 的假设预先写定。读数两个方向都报，但「有效」只认预定方向。S1 的方向有争议（危机错杀的机会同样可能整个行业便宜），仍按「行业整体便宜更像陷阱」预定。

## 读数

- **T1 分组**：买入区样本按特征值五等分（全样本合并分位）。每组报陷阱占比、机会占比与月数；按股票整簇自助 1,000 次，给 90% 区间。
- **T2 AUC**：陷阱对非陷阱的 AUC 与陷阱对机会的 AUC，整簇自助 90% 区间，并分 2007–2012、2013–2017、2018 年起三段。
- **T3 有效识别判据（与 OI-224 相同）**：单个特征同时满足以下三条才记「能有效识别」：
  1. 全样本陷阱对非陷阱 AUC（按预定方向）的 90% 区间下限 > 0.55；
  2. 三段 AUC 点估计都 > 0.5；
  3. 预定方向最差一组的陷阱占比 ≥ 买入区陷阱占比的 1.5 倍且区间下限 > 1.0 倍，同一组的机会占比不高于买入区机会占比（点估计）。
- **T4 组合模型**：E1 与 10 个新特征标准化、缺失填中位并加缺失标志，logistic 回归；逐年滚动样本外（检验年 Y 只用观测月 ≤ Y−4 年 12 月的样本训练）；报样本外 AUC 与最差五分之一的陷阱、机会占比，按 T3 同一判据判定。
- **T5 具名陷阱**：答案卷具名陷阱首次进买入区当月的各特征值与所处五分位，标出落在最差一组的特征。
- **T6 E1 之外的增量**：主样本中 E1 不在最差五分之一（E1 ≥ 主样本 E1 的 20% 分位，或 E1 缺失）的子样本上，逐特征报 AUC 与整簇自助 90% 区间、最差一组陷阱与机会占比。**「在 E1 之外补充识别」= 通过 T3，且 T6 的 AUC 区间下限 > 0.5。**
- **T7 周期类子样本**：答案卷 `tag` 为 H周期、F资源的买入区月份上逐特征报 AUC（只描述）。
- **全部在册月对照**：T1、T2 在全部非金融在册月上另报一遍，只描述。

## 结论如何使用

- 有特征通过 T3 且 T6：据此另拟「陷阱识别」候选规则（过滤、加深折价或只作复核提示），按 §12.1 预登记策略层读数后交用户裁定。
- 只通过 T3、不过 T6：说明与 E1 重叠，报用户，不另拟规则。
- 都不通过：如实报用户，由用户裁定 OI-229 是否继续换方向或结案。

## 已知局限

- 10 个特征同时检验，存在多重比较；T3 须三段同向，用以部分控制。
- 答案卷只到 3 年前向窗口完整的月份（至 2023 年前后），最近三年没有标签。
- 行业归属用现行大类回溯全历史；行业统计量的公司集合随上市、退市变化。
- 逐季面板有东财原位改写重述值的问题（OI-214／OI-225），行业统计量用现行值，不追溯重述前版本。
- K2 的同行只限估值池内公司，小行业常不足 3 家。
- 陷阱集中在少数股票（OI-224：21 只中宇通 42 个月、海螺 22、电投 21、潍柴 19），整簇自助区间会较宽。
