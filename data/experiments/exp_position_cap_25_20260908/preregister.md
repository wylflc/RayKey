# 单股买入上限 25% 对照预登记

登记日期：2026-09-08（北京时间）；轨道 B，用户指定的收益敏感度实验。

问题：当前策略单股买入上限由 60% 改为 25% 后，历史净复合收益如何变化？分母为净资产；只限制买入金额，被动超限不强制卖出。现有 `--position-cap` 实现此语义，生产规则保持原值。

设计：当前 `sweep_backtest_configs.BASE` 对照 25%，另取 20%／30% 两个邻档。除 `--position-cap` 外不变更策略参数、融资、费税、执行时点、股票池或估值；各臂使用同一份现有历史缓存，不在本轮刷新或重建。正式逐日状态与宇宙路径由 BASE 读取。运行前记录输入哈希与行情末端，运行后验证未变；此前检查：296 个面板代码中 155 份行情止于 2026-08-07、140 份止于 2026-08-28、1 份退市股止于 2018-12-20，不能称为截至登记日的完整最新行情。

标准起点集读取 `DEFAULT_STARTS`（14 个半年起点）；计量 m2。全样本及固定剔除 BASE 2011-11-01 前五赢家的 A 集同时报告。25% 臂另按自身与 BASE 的前五赢家并集 U 做对称压力测试；若 U=A，直接复用同集合结果并登记等价性。

主比较为全期 CAGR 的逐起点配对差中位，并报告滚动五年中位／P25、两个长跑起点、非重叠五年块、逐年收益与标准报告全部附表。附报平均仓位、持仓数、换手和尾部以解释资金分配变化；不以职业经理人产品约束否决本次用户指定实验。不得把两个水平中位数之差写成配对效应；全部历史差值不作未来增益点预测。

本轮新增候选 3 臂：PC20SEP08、PC25SEP08、PC30SEP08。旧纪元其他单票上限实验不与当前读数拼接。本轮不是生产采纳流程，不重扫换仓边际或更改现行交易规则。

复现入口：`scripts/slurm/position_cap_25_20260908.sbatch`；完整标准报告落 `report_full_A.txt`，25% 并集报告落 `report_U.txt`，逐起点摘要、输入清单、校验结果保留在本目录。

## 整手边界补充登记（原扫描运行中，未读取收益结果）

代码核查发现：`amount` 按单股上限余量截断后，`lots_n <= 0` 的一手兜底仍可能买入一手，绕过上限余量。因此原 `--position-cap 0.25` 只能代表既有实现。

补充实验在独立包装器中，遇 `一手金额 > 上限剩余额度` 时跳过买入，位置在消费比例冷却计数器之前；不改卖出路径，也不改生产引擎。严格 20%／25%／30% 三臂与原 BASE 对比；另加严格 60% 隔离整手修复的路径影响。新增 4 臂，本轮两批合计 7 个候选名。25% 严格臂另核 U 集。最终主要回答采用严格 25% 的结果，同时披露原实现读数与两者差别。
