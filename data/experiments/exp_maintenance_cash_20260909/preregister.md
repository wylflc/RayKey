# 维持性现金占用补充模型：预登记（2026-09-09）

用户要求尝试补充估值模型并测试效果。轨道 B：这是现有近似的研究扩展，不能把未经识别的维持性开支称作已证实的计算错误。生产开关为零，实验不改名单、生产估值、交易参数或 BASE。

## 估计量与边界

仅适用非金融 ROIC 路径，使用建带当日已披露且经过重述版本选择、主体重置截断的同一年度历史窗口。设各年 NOPAT 为 P，投入资本为 IC，收入为 S，净再投资 N = CapEx − D&A + ΔWC。营运资金的应收/应付组优先取 `NOTE_ACCOUNTS_RECE` / `NOTE_ACCOUNTS_PAYABLE` 合计，合计缺失才加明细；不得将合计与明细重复求和。

1. 每个连续年度区间用此前可用年度 `IC/S` 的中位 K，估计扩张投入额度 `G = max(S_t − S_{t−1}, 0) × K`；年度现金残差 `H = N − G`。没有新增收入时 G=0；固定周转资金不重复扣，费用化研发不再扣。
2. 至少三个连续年度区间；各区间 P>0、前后收入>0、前期 IC>0，现金流表 CapEx、折旧项与经营营运资金字段可核验。缺任何必要项则代理不可算，沿用原带并写明缺失，不能视为零现金占用。并表年化区间不做估计。
3. 至少三分之二区间 H>0，且 `ΣH>0`，才认为有持续残差。基础占用率 `m0 = ΣH / ΣP`，否则为0；保留负残差参与合计，以冲销一次性存货/应收占用的后续回收。研究占用率 `m = weight × m0`，不把50%设作上限。
4. 这是“增长解释之外的持续净现金占用”代理，**并非真实维持性资本开支的观测**。项目建设滞后、并购、收入涨价、存量资本低效、现金字段聚合误差都可能影响它。历史回报不用于拟合代理参数；三档结果都报告。

## 与折现衔接

原引擎所需留存 `b_old = ((1+g)R_t/R_next −1)/R_t`。当 m>0 时使用 `b = max(b_old, g/R_next + m)`；当 m=0 时严格保留原计算。这样已有 ROIC 衰减所隐含的额外投入与新增代理取较大者，避免两次扣同一维持负担。每年 FCFF = P × (1−b)。触发原留存上限时，增长同时受原资本约束与 `g ≤ R_next × (上限−m)` 约束；终值现金比例为 `1−g_T/R_T−m`。

原零增长路径的锚改为 `P×(1−m)/WACC`，再走同一净负债和少数股东桥。增长路径的终值现金比例非正时判原增长假设不可估，不直接跳到零增长估值；m≥1 或修正导致原有效带拒绝时标记现金拒绝事件，自该事件生效起禁用旧带，直到更新报告恢复可估。原本就拒绝的未修正带不额外改变。

跑组合前的边界修订：最初拟在增长现金不足时退零增长，合成算例 NOPAT100/ROIC20%→12%/g5%→3%/r10% 中 m=.749 得1.58，而退零增长 m=.75 得250，违反负担单调性。取消该回退。停止最初建带作业26488479及依赖回测26488549后重建；修订只依据合成经济边界，未读取任何候选组合收益。

敏感度两侧同样带入 m；不把当前实际股息或未来回购另扣一次。代理在预测期保持不变是本轮的压力假设，不自动视作长期事实。

## 预先固定的实验

- 原 BASE 保留原营运资金计数、weight=0。另设 WCREPSEP09 控制：只修正营运资金合计/明细重计（`--wc-aggregation reported`），weight=0、换仓边际0.15；该数据修正按轨道 A 记录（工作流 §6.3 第5条同一披露口径）。模型三档weight=0.5/1.0/1.5均用 reported，分别测试换仓边际0.14/0.15/0.16，共9模型组合；中心档为 weight=1、margin=0.15。合计10候选，另报现金模型相对WCREP的配对差，不能把修数据的效果归给现金代理。除本表参数外全部读 `sweep_backtest_configs.BASE`；当前 OI-167 整手行为在所有臂保持一致，防止夹带修复。
- 每档按 `align_buy_line` 的同一在册合格面重解买入线（四位小数）；换仓边际不随买入线缩放。另报原阈值下覆盖与合格比例，区分整体标度与排序变化。
- 使用当前 v6b 时点面板与14个标准起点、m2计量。先检查行情末端，记录输入哈希。实验使用相同缓存，不把结果称为截至9月9日的完整市场回测。
- 按面板与当前核心池/既有锚点代码并集重建两侧；weight=0 的逐日输入必须与生产文件相同代码子集逐位一致，否则停止并调查。正式 BASE 来自扫描器，其它费用、整手、融资、复权、执行延迟均同式。
- 全样本、剔除 BASE 五赢家 A、各候选与 BASE 五赢家并集 U 同报标准指标和逐起点配对差；排序按全期 CAGR 配对差，采纳条件按工作流 §12。报告本轮3个模型候选、9个模型/边际组合，不能当成独立样本。
- 本轮先做机制算例、当前公司解释、既有26个历史锚点排序检查，再跑组合。锚点有事后选择偏差，仅作诊断。若没有候选通过初步收益与风险条件，停止追加调参并如实结案；若通过，也需按 §12 补齐采纳前检查，不能凭一个收益数字替换生产。

## 检查项

相同利润且零增长下50%/90%持续占用应分别只分配50%/10%；普通经营成本不重复扣；按资本强度扩张不触发额外罚项；营运资金先占后还不产生永久负担；单年大额开支不触发持续规则；缺字段/缺年/未来披露/并表年化不冒充可算；默认0与旧实现兼容；合计与明细不重计且合计缺失正确回退；已有ROIC衰减投入不重复扣；终值无现金时不返回乐观旧带；源文件不变。
