## 客观口径（`labels.py`，阈值在 `THRESHOLDS`）

- **观测**：回测宇宙 `panel_moat_bank_v6b.csv` 在册期内，每只股票每月最后一个交易日；2007-01～2023-08（其后 3 年回报可得）。共 228 只、17,616 个股票月。
- **其后回报**：3 年含分红再投年化总回报，与公允性检验同一实现。
- **超额**：3 年年化减去同月在册股票的中位，用来剔除整体牛熊。
- **盈利变化**：观测日与 3 年、5 年后各自已公告的最新归母净利 TTM 之比。
- **分类**：
  - **机会**：3 年年化 ≥ 20%，超额 ≥ +10pp，且 3 年或 5 年后盈利不低于当时。占股票月 21.6%。
  - **陷阱**：3 年年化 ≤ 0，超额 ≤ −10pp，且 3 年后盈利降 ≥ 20%。占 8.2%。
  - **估值扩张**：涨幅同机会，但盈利 3 年、5 年后都更低。占 0.8%。
  - **一般**：其余。占 69.5%。
- **市盈率**：常规市盈率 = 月末市值 ÷ 归母净利 TTM。股本取 `a_share_share_changes.csv`，缺的 85 只补取到 `share_changes_extra.csv`，不动生产表。
- **用途**：只用于从候选中区分「当时看起来便宜」的陷阱与高估值崩塌，不进分类。

## 读数（定稿后实现）

同一答案卷，对任一估值口径或策略臂，在对齐后的买入线（在册合格面）下计：

- **机会捕捉率**：机会月与机会段中被判进买入区的比例。
- **买入区陷阱占比**：买入区月份中陷阱月的比例。
- **陷阱踩中率**：陷阱段中曾被判进买入区的比例。
- 每项按股票整簇自助给区间，分年份、分类型列示。
- 具名案例逐只报：段内进买入区的月份占比、首次进入月，以及回测中是否实际持有及其盈亏贡献。
