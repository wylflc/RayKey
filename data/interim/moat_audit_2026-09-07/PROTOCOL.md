# 关注池护城河逐家审核协议（2026-09-07）

目的：用户裁定「关注池里的公司必须具备真实的护城河」。对 `worth_attention` 全部 214 家逐家复核
`attention_class` 是否仍成立——不是重打四维分数，而是核验**资本复制测试**这一条决定名单归属的断言。

## 1. 判定标准（照录工作流 §5.4，不得放宽）

`worth_attention` = 优势持久、难以被资金快速复制，且已转化为**定价权、成本优势、客户锁定、网络效应、稀缺资源或超额回报**之一。
`boundary_pending` = 证据不足；或可判断但当前没有足够持久优势。

共同规则：①先做资本复制测试，**存疑不进 worth_attention**；②股价、估值、市值、主题热度、短期盈利不影响判断；
③公司平庸但行业并非结构性绝望 → boundary_pending 而非 garbage；⑤同业对比要看差异化位置，「不如第一名」不等于被全面覆盖；
⑥行业增长放缓本身不是排除项，只有壁垒载体被破坏才影响。

行业特殊口径：规制基础设施／普通银行／牌照业务 → 只有不可复制性**已持续转化为高于同业的回报**才留；
银行与保险 → 只留系统重要性代表与十年 franchise 最优者；商品与资源 → 须同时有稀缺/配额、成本曲线、规模/储量三项；
资本密集周期制造 → 结构整合、技术、规模或准入壁垒已使替代客观困难才留，景气不算壁垒；
客户集中 → 结构性单一买方须有长认证、准入锁定和稳定长期 ROE。

资本复制测试的统一问句（rubric §4.1）：**资金充足的新进入者要越过它，需要多少买不到的要素 + 多少压不掉的时间？**
载体硬度自上而下：法律锁（绝密配方、牌照、配额）> 物理锁（坝址、矿权、窖池）> 认证锁（型号定型、适航、JEDEC）> 能力锁（技术代差、规模成本）> 品牌渠道锁。
只有品牌渠道锁且同业 3~5 年可追上的，属「可被资本较快复制」。

已知偏差（rubric §10.3）：上一轮把「份额小」「细分市场小」「不如第一名」当成无护城河，系统性偏严。
本轮方向相反，要防的是**假阳性**——写得像护城河、实际只是行业景气或阶段性份额。两种偏差都不许。

## 2. 每家必做四步

1. **载体**：点名护城河载体属于六项中的哪一项，并给**可指事实**（份额与排名、牌照/配额/储量、认证周期、成本位置、客户复购/切换成本），注明来源。写不出可指事实 = 载体不成立。
2. **资本复制测试**：pass / doubtful / fail。fail 与 doubtful 都不留在关注池。
3. **回报持续性**（`quant_evidence.csv` 逐行给出）：FY2015-2025 加权 ROE 中位／最低／≥15% 年数、门类内分位中位、毛利率首末五年、归母 CAGR、经营现金流÷净利中位。
   护城河若真实，十年回报应持续高于同业；若回报平庸，须能指出**结构性原因**（重资产周期低谷、管制定价、投入期），否则载体存疑。
   注意分位是证监会门类（制造业 2000 家）粗尺，只作参考，不作否决。
4. **同业锚**：与至少一家同业或 rubric 锚点对照，说明差异化位置。`docs/peer-group-calibration/` 有行业校准文档时先读。

## 3. 证据来源与顺序

1. 仓库既有：批次输入 JSON 里的分层表字段（moat_summary／capital_replicability／peer_comparison／q2_erosion_paths／evidence_note／evidence_sources）、
   `data/interim/moat_audit_2026-09-07/quant_evidence.csv`、`data/companies/<代码>_<名称>/README.md`（估值档案，看业务与跟踪指标段）、
   `docs/peer-group-calibration/*.md`、`data/archive/completed-queues/evidence_review_log.md`（上一轮外部取证结果，grep 公司名）。
2. 外部取证（WebSearch／WebFetch）：**只在判定悬于某个事实时检索**，优先年报／交易所公告／监管文书／行业协会／权威研报，聚合站只作线索。每家 1~3 次检索，记 URL。
3. 既有分层表的文字**不是证据**，是待核验的断言；不得因为表里写着「测试通过」就照抄。

## 4. 输出（JSONL，每家一行，字段齐全）

```json
{"security_code":"000651","security_name":"格力电器","quality_tier":"L2",
 "carrier":["品牌定价权","成本优势"],
 "carrier_fact":"家用空调内销份额与美的并列第一梯队（≈30%），压缩机自供；FY2015-2025 ROE 中位 25%、门类分位 90+",
 "replication_test":"pass",
 "quant_support":"yes",
 "quant_note":"ROE 中位 x、最低 y、≥15% 共 n 年；毛利首末五年 a→b",
 "peer_anchor":"对照美的：盈利率更高、增长更弱",
 "erosion":"medium","erosion_path":"单品类依赖、渠道改革、治理",
 "verdict":"维持",
 "confidence":"high",
 "reason":"≤120 字，说清载体与事实",
 "sources":["data/...","https://..."],
 "evidence_status":"external_verified|repo_only|model_knowledge"}
```

`verdict` 三选一：`维持`（载体成立、复制测试 pass、回报持续或有结构性解释）／`降 boundary_pending`（复制测试 doubtful 或 fail、载体被证伪、或回报平庸且无硬载体）／
`待外部取证`（判定悬于一个本轮未能核实的事实，`reason` 里写明是哪个事实）。
`erosion` 只在 verdict=维持 时用于提示；侵蚀路径成立须具体、非行业普遍风险、中/高概率有事实依据。
`confidence` 反映证据强度，不反映倾向。每家 `reason` 限 120 字，禁止印象式的「较差」「一般」。
