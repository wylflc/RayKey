- **OI-044｜缺陷**（现行 DCF 判定金融股九成交易日便宜、成长股仅 6%，2026-08-13 登记）：2017-05 起、各类型在册日中 `P/V ≤ 0.90` 的占比为**金融 90.0%／资源 35.6%／制造 10.7%／消费 9.7%／成长 5.9%／公用 4.9%**（全部 51.0%，§12.29.2）。**这是「策略偏向银行股与资源股」的直接成因**，也是成长股子池装不下钱的成因——不是一档买得太小，是绝大多数日子没有合格标的（实测把买入线由 0.90 放宽到 1.60 可将成长池仓位由 21% 推到 42%，但年化转为 **−1.47%**、滚 3 年回撤 34.5%）。**已排除的一个解释**：不是 `roe0` 不准——现行 `trend_aware_roe` 五年中位对未来三年 ROE 的 IC 为 **+0.736**，全市场神经网络仅 +0.680（§12.29.4）。**2026-08-13 已查明**（§12.30.3）：由 `PB=(ROE−g)/(COE−g)` 反解，**银行的市场隐含 COE 全期中位 17.0%**（2011 年起长期 16.5%~22.6%），非银行仅 7.7%，而模型对 L2 一律用 `r=10%`——用 10% 折现一门市场要求 17% 的生意，数学上必然恒判便宜。同一 ROE 档内市场只给银行三到四折 PB（−60%~−77%），与「杠杆放大的 ROE 应当打折」一致。**但按 J 类口径重定价救不回收益**：固定 COE 13/15/17/20%、滚动同业隐含 COE、滚动自身 PB 中位六个版本，最好的（COE 17%）只有 +0.57pp（19/36），其余为负——合格面确实被摊平（银行 87.5%→66.6%、成长 4.1%→12.1%），但年化不动。**2026-08-13 §12.35 补测（决定性）**：受控 A/B——同一个护城河池、同一套参数，唯一差别是银行怎么估值：DCF 定价 **+0.30pp（15/23）**，股利折现 `V=近12月每股分红÷(十年国债+2%)` **+5.93pp（23/23）**，**单变量值 +5.63pp**。但逐笔核对显示银行在合并池里只贡献 **0.4%** 盈亏、只成交 2 只——**它的作用是不再挤占容量，不是自己赚钱**。同时确认成长侧一分未松：补进药明康德/中际旭创/新易盛/康龙化成/中航高科/东方电缆六家后，**六家合计成交 3 笔、赚 1.7 万**；中际旭创入池 1,036 个交易日 **P/V 中位 6.59、历史最低 1.91**，买入线放到 1.78 仍 0 天合格。机理：锚 `roe0=近五年 ROE 中位`，中际旭创 2024-04-30 可得的五年中位为 **10.3%**，而其 2024/2025 实际 ROE 为 31.2%/43.8%——**锚差三到四倍**。五年中位是为躲顺周期陷阱而设（§12.27.1 证明胜过 ttm），代价就是永远认不出正在变强的公司。**这是全部剩余瓶颈所在。待办**：把 §6.5.7.1 的同业隐含 COE 口径落到批量历史带（现在只作用于 J 类逐票建档），这是 OI-045 第 3 条的前置。§6.5.7.1 已注明 A 股银行长期以 PB<1 交易、隐含 COE 显著高于教科书 ERP，但该注记只作用于 J 类逐票建档，未作用于批量历史带。

- **OI-042｜缺陷**（东财 `notice_date` 对 1998-2015 报告期系统性偏移约一年，2026-08-11 登记）：**年报公告日的中位滞后在 1998-2009 为 456~473 天、2013-2015 为 451~456 天，而 2016 年起为正常的 113 天**；1998-2009 有 91~95% 的行滞后超过 400 天。判例 600104：2001／2002／2003 年报的 `notice_date` 分别记为 2003-03-26／2004-03-03／2005-02-05——**每期填的都是次年年报的公告日**。全库 176,750 个年报行中 **33.2%（58,616 行）晚于法定披露截止日**，被封顶后中位提前 **352 天**、P90 提前 668 天。**两处影响，方向相反**：①**对时点判定是前视**——若不修正，「as-of 2002」的截断日会落在 2004-03，等于多看一年信息，故 `build_judgment_input.py` 已落地 `available_at = min(记录公告日, 法定截止日)`（年报次年 4/30、一季报当年 4/30、半年报 8/31、三季报 10/31），**封顶不引入前视**（按法规该日数据必然已公开），只纠正偏移；②**对现行建带流水线是滞后不是前视**——`build_historical_valuation_bands.py` 的 `available_at = max(各期公告日)` 会让 1998-2015 的带晚生效约一年，**结果偏保守、不构成前视**，但它使早期回测年份运行在明显更陈旧的基本面上，与 2016 年后不同口径，**跨期比较因此不对等**。**处置**：判定侧已修；建带侧未改（改动会重算全部历史带并可能改变 §12 全部长跑读数），须单独评估——**评估前，§12 中 2016 年以前的读数须知道它们带着约一年的基本面滞后**。同源缺陷：`fetch_a_share_report_disclosures.py` 用的是同一个 `RPT_LICO_FN_CPD` 的 `NOTICE_DATE`，同样受影响。

- **OI-041｜缺陷**（`incremental_roe` 的 ΔEPS 可能被二次折算，2026-08-11 登记）：`build_historical_valuation_bands.py:518-527` 计算 `ΔEPS/ΔBPS` 时对旧期同时做 `eps_old / factor` 与 `bps_old / factor`。但实测**东财 `basic_eps` 在部分期已按后续送转折算过**（160 个公司-年抽样中与新浪「加权每股收益」相符 86.6%，不符的多为送转期；判例 002369·2010 东财 0.37 = 新浪摊薄 0.7395 ÷ 2，对应 2011-05 的 10转10），而 `bps` 不折算。**对已折算的期再除一次 `factor`，会把 `eps_old` 压得过小、令 `ΔEPS` 与 `incremental_roe` 偏高。** 影响面：该列标注为「只报不用」，**不进入估值**，故不影响任何带与回测结果；但 `build_historical_valuation_bands.py:757` 记录的建模动机「ΔEPS/ΔBPS 实测中位 13.2% 低于建模 roe0 16.1%」**是基于这个可能偏高的统计量得出的**——若真偏高，则真实中位更低、该动机反而更强，方向不逆转。**处置**：不急修；重跑该统计量时须先按公司-期判断 `basic_eps` 是否已折算（判据：与新浪「加权每股收益」比对），再决定是否除 `factor`。
