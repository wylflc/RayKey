# 质量分层 v2（L1-L5 评分制）方案设计与需求分析

- **状态**：设计中，**未实施**。本文件不是标准；标准只存在于 `docs/000_Ashare_workflow.md`（§15）。
- **发起**：2026-07-30，用户提出把 L1-L4 分层改为 L1-L5 评分制分层，并同步重制买入准入尺度。
- **本轮范围**：需求分析 + 现状盘点 + 冲突识别 + 方案选项 + 影响评估 + 待决清单。不改任何标准文件、不改数据。

---

## 1. 用户需求原述

分层由 L1-L4 改为 L1-L5，以护城河强度评分定档：

| 档 | 描述 | 分数 |
| --- | --- | --- |
| L1 | 极强，几乎不可颠覆的护城河 | 95~100 |
| L2 | 很强，很难颠覆的护城河 | 90~95 |
| L3 | 优秀，比较牢固的护城河 | 80~90 |
| L4 | 良好，比较稳固的护城河 | 70~80 |
| L5 | 及格，有一定的护城河 | 60~70 |

`worth_attention` 列表统一视为 60 分及格分以上。同时要求重新细化各档的可买标准（原「L1 较高估可买」这类尺度需按 5 档重新分配）。

## 2. 现状盘点

### 2.1 现行分层（§5.7）

| 档 | 现行语义 | 现行可买尺度（§6.2.1） |
| --- | --- | --- |
| L1 | 顶级核心候选，极强护城河 | 低估/较低估/中性/较高估可买 |
| L2 | 准核心候选，护城河明确但有折扣 | 低估/较低估/中性可买（较高估 watch_only） |
| L3 | 战术观察，护城河**不足以**进核心层 | 低估/较低估可买（中性 watch_only） |
| L4 | 零仓观察，护城河强度/证据质量**不足**进前三层 | 仅低估可买、不加仓 |
| **L5** | **不是保留档**——判为「不再值得长期关注」，`attention_class` 由 `worth_attention` 降为 `boundary_pending` | 不建仓 |

### 2.2 现行不存在质量评分

A 股分层目前**没有任何数值分**，`quality_tier` 由逐票判断直接给出。
`docs/moat-scoring-rubric.md` 有一套 0-100 七维加权评分，但其 scope 说明（2026-07-08，依 ADR-0006）已把 A 股撤出，现仅服务港股/美股全覆盖打分脚本。

### 2.3 现行分布（`a_share_watchlist_quality_tiers.csv`，261 家）

| 档 | 家数 | 占比 |
| ---: | ---: | ---: |
| L1 | 24 | 9.2% |
| L2 | 158 | **60.5%** |
| L3 | 67 | 25.7% |
| L4 | 12 | 4.6% |

`attention_class` 全域：`worth_attention` 261 / `boundary_pending` 5337 / `garbage` 55。

§5.7.1 要求「整体应呈金字塔形」，当前实际是**头重脚轻的菱形**——L2 独占六成。这是本次改版必须解决的存量问题，也是分数带落地后冲击最大的地方。

## 3. 冲突识别（必须先解决，否则无法动工）

### C-1 L5 语义碰撞（阻断级）

现行 L5 = **剔除标记**，用户提案 L5 = **及格保留档**。同一个符号两个相反含义，不能并存。

| 方案 | 做法 | 评估 |
| --- | --- | --- |
| **A1（建议）** | **退役「L5 = 剔除」这个用法**，剔除完全由 `attention_class = boundary_pending` 表达 | ADR-0005 已确立 `attention_class` 与 `quality_tier` 分离；用一个质量档去表达「不再关注」本就越界。§5.8 步骤 9 现行写法实际也是「降级为 boundary_pending」，L5 只是个多余的中间说法。退役后语义反而更干净 |
| A2 | 剔除档改名 L6 / NR | 可行但多一个无信息量的符号 |
| A3 | 保留 L5=剔除，及格档叫 L4b | 命名混乱，否决 |

### C-2 分数带边界重叠与噪声敏感（技术级）

- 95 / 90 / 80 / 70 同时属于相邻两档。需改为半开区间：L1 ≥95；L2 [90,95)；L3 [80,90)；L4 [70,80)；L5 [60,70)；<60 出 `worth_attention`。
- L1/L2 带宽仅 5 分，而七维加权下**单一维度差 20 分 × 28% 权重 = 5.6 分**，足以跨整档。需要配套：分数留 2 位小数、**档界 ±1 分内强制锚点双重对照并留痕**（§5.7.1 规则 6），防止 94.8 / 95.1 这种打分噪声直接决定买入资格。

### C-3 「护城河强度分」还是「公司综合质量分」（需求澄清级，影响最大）

用户五档的文字定义**全部是护城河强度陈述**（极强/很强/优秀/良好/及格的**护城河**）。但现成的七维 rubric 是**综合质量分**，其中行业前景 14% + 治理 6% 共 20% 权重与护城河强弱无关，却能把一条不可颠覆的护城河拖下档。

用现行 v0.4 权重（护城河 28% / 技术壁垒 24% / 市场地位 14% / 行业前景 14% / 商业模式 8% / 经营质量 6% / 治理 6%）试算：

| 公司 | 各维示意分 | 加权总分 | 落档 |
| --- | --- | ---: | --- |
| 贵州茅台 | 护城河 98、技术壁垒 90、市场地位 98、商业模式 95、经营质量 98、行业前景 **70**、治理 85 | **91.14** | 新 L2 |
| 宁德时代 | 护城河 88、技术壁垒 92、市场地位 95、商业模式 78、经营质量 85、行业前景 85、治理 80 | **88.06** | 新 L3 |

**结论：按现行权重，A 股几乎无人能到 95 分，新 L1 会是空档**，而全池最强锚点茅台只能进 L2。这与用户「L1 = 极强、几乎不可颠覆」的语义不符——茅台正是该定义的典型。

| 方案 | 做法 | 评估 |
| --- | --- | --- |
| **甲（建议）** | **定档分 = 护城河强度分**：由护城河、技术/工艺壁垒、市场地位与不可替代性重构并归一到 100；行业前景、商业模式、经营质量、治理**改为扣分项与一票否决项**，只能压档不能抬档 | 最贴合用户五档文字定义。行业下行不降质量档，本就是 §5.7.1 规则 1 的既有立场（茅台判例：「行业增长走弱只记入估值与仓位备注，不降质量档」）。该方案让规则与分数首次自洽 |
| 乙 | 保留七维加权，分数带整体下移（L1≥90 / L2 85-90 / L3 78-85 / L4 70-78 / L5 60-70） | 改动最小，但违背用户给出的分数直觉，且把「行业景气」偷偷混进护城河档位，重蹈 §5.7.1 规则 8 警告的「短期利润爆发≠更强护城河」 |
| 丙 | 双轨：护城河分定档 + 综合质量分作为降档触发 | 信息最全但要维护两套分，执行成本高 |

### C-4 与 ADR-0006 的关系（需新 ADR）

ADR-0006 把评分从 A 股撤下，撤的是**用脚本自动分做 round-1 三类初筛**；其决策 6 明确写着「Deep annual-report and research reading is **deferred to L1–L5 tiering**」。因此**在分层层引入评分不与 ADR-0006 冲突**，冲突的是拿关键词自动分当证据。

但仍需一条新 ADR 记录「重新在分层层引入评分」，并写死两条边界：
1. 分数**必须由证据驱动的逐票人工评分**产生，不得由聚合站简介/关键词脚本生成（v0.3 校准注记已承认关键词打分是 A 股高分人口虚高的机械成因）。
2. 分数带**不是配额**。ADR-0006 决策 3「There is no numeric target; the count follows from the standard」继续有效；金字塔形状只作校准自检，不作强制分配。

### C-5 60 分线与资本复制测试的一致性

ADR-0006 规定 `worth_attention` 的门槛是**资本复制测试通过**，不是分数。用户提出 `worth_attention` ⟺ ≥60 分，等于新增第二道门槛。两者必须机械自洽，否则会出现「资本复制测试没过但算了 62 分」的裂缝。

**建议规则**：资本复制测试不通过的，护城河维度**上限 55 分**，加权后自然低于 60 线。这样两个门槛是同一件事的两种表述，而非并列的两个标准。

## 4. 准入矩阵重制（用户 2026-07-30 指定：三态矩阵）

### 4.1 用户指定的思路

矩阵由**单态（可买 / 不可买）升级为三态**，每个「层级 × 估值档」格子给出三种状态之一：

| 状态 | 含义 |
| --- | --- |
| **可买** | 过矩阵，具备买入资格（仍须过 §8.13 入场阶段与 §10 闸门） |
| **可持有** | 不可新建仓、不可加仓，但已持仓不因此卖出 |
| **提醒卖出** | 触发 §14 估值卖出通道的提醒（提醒，非强制指令） |

用户给的两行锚点：

- **L1**：低估/较低估/中性 = 可买；较高估 = 可持有；高估 = 提醒卖出
- **L2**：低估/较低估 = 可买；中性 = 可持有；较高估、高估 = 提醒卖出

**这是本次改版的架构性变化**：现行 §6.2.1 是纯买入准入，执行说明第 1 条明写「矩阵是买入准入，不是卖出指令」。三态矩阵让它第一次同时管买入端与持有端，该条必须重写。原 E1/E2/E3 三个平移方案全部作废。

相对现行标准，这是**双重收紧**：L1 由「较高估可买（需上修/催化）」收到「较高估仅可持有」，L2 由「中性可买」收到「中性仅可持有」——每一档的可买上限都下移一档。与已定的 D-4「接受收缩」一致。

### 4.2 「以此类推」的两处撞墙

估值阶梯只有五级（低估→较低估→中性→较高估→高估）。严格逐档平移到 L3 就把两侧都用尽了：

| 层级 | 严格平移的结果 | 问题 |
| --- | --- | --- |
| L3 | 可买=低估；可持有=较低估；提醒卖出=中性及以上 | 尚可 |
| L4 | 可买=无；可持有=低估；提醒卖出=较低估及以上 | **对低估的持仓提醒卖出**，荒谬 |
| L5 | 可买=无；可持有=无；提醒卖出=全部 | 完全退化 |

因此两侧都必须设地板：

- **卖出侧地板（建议直接采用）**：提醒卖出**只在较高估、高估两档触发，不再随层级继续下移**。理由是这与现行 §14 估值卖出通道的既有触发点（较高估 + 留底≥建仓金额）完全一致——层级决定的只是「L1 是否享受宽限到高估才提醒」，而不是把提醒扩散到便宜的档位。
- **买入侧地板（待决 D-3a）**：可买上限跌到「仅低估」之后如何区分 L3/L4/L5，见下。

### 4.3 三态矩阵草案

| 层级 | 分数 | 可买 | 可持有（不可买/不可加仓） | 提醒卖出 | 池内层 | 所需右侧入场阶段（§8.13） |
| --- | --- | --- | --- | --- | --- | --- |
| L1 | ≥95 | 低估 / 较低估 / 中性 | 较高估 | 高估 | 核心 | 低估=一段；较低估=二段；中性=三段 |
| L2 | [90,95) | 低估 / 较低估 | 中性 | 较高估 / 高估 | 核心 | 低估=一段；较低估=二段 |
| L3 | [80,90) | 低估 | 较低估 / 中性 | 较高估 / 高估 | 核心 | 低估=二段 |
| L4 | [70,80) | 低估（须有明确战术理由兑现路径，不加仓） | 较低估 / 中性 | 较高估 / 高估 | 战术 | 低估=三段 |
| L5 | [60,70) | **待决（D-3a）** | 低估 / 较低估 / 中性 | 较高估 / 高估 | 战术 | 待决 |

设计要点：

1. **L3/L4/L5 的可买档位都压在「仅低估」**，无法再靠可买档位区分，差别只能落在**入场阶段、战术理由要求、加仓权限、是否强制过 §10 闸门**上。
2. **核心层/战术层切分线由 L1/L2 | L3/L4 改为 L1/L2/L3 | L4/L5**，与新语义（L3 仍是「比较牢固的护城河」）一致。
3. 保留 §6.2.1 其余执行说明：战术层须先过 §10 人工闸门、事件通道关闭（可见不可买）、价格自动定档双向不限幅、分层或档位变化后重跑池物化即自动重算。

### 4.4 与 §14 卖出规则的咬合（必须先厘清，否则会与已退役机制打架）

现行卖出通道共四条（v1.12，v1.19 细化趋势卖出）：止损（割肉价 Tier-0）、硬证伪、**估值卖出（较高估 + 留底≥建仓金额）**、趋势卖出（分态）。

三态矩阵的「提醒卖出」列**不是新增第五条通道**，而是把既有的估值卖出通道改成**按质量档分级触发**：

| | 现行 | 三态矩阵后 |
| --- | --- | --- |
| L1 | 较高估即触发估值卖出 | **放宽到高估才提醒**（好公司容忍更多估值拉伸） |
| L2-L5 | 较高估即触发 | 不变 |

必须显式保留、不得被新矩阵覆盖的三项：

1. **留底 ≥ 建仓金额**——估值卖出不清仓，保留底仓。
2. **个人体系 §12 盈利后减仓与十倍股保护**——§12.3 在 >+500% 明确「停止机械卖出，改用趋势和 thesis 保护」，10 倍时 thesis 未破保留永久底仓。
3. **提醒 ≠ 指令**——v1.20/v1.21 已连续撤销两类「只可能因股价上涨触发」的机械警告（止损网格 6%/8%N、单笔风险持仓监控版），理由是大赢家被逐日警告会制造恐慌并促成过早卖出。估值卖出通道本身在那两次撤销中被保留，因此本列**在既有边界内**；但落地时必须写死它是提醒而非机械减仓指令，否则等于把刚撤销的失败模式换个名字装回来。

## 5. 遗留问题：旧 L3/L4 携带的「战术理由」要求往哪放

旧 L3 的定义里绑了一条硬要求（§5.7.1 规则 4）：**必须至少有一个明确的战术关注理由**（行业催化、右侧触发候选、周期拐点、局部瓶颈、差异化技术、股东回报催化、有据可查的困境反转路径），理由只是「公司不错」则降 L4。

新体系是**纯护城河强度的一维尺子**，「有没有战术理由」与护城河强弱正交，无处安放。三个选项：

1. 作为**独立布尔字段**（`tactical_thesis` + 理由）保留，只对战术层（新 L4/L5）作买入前置——最贴近现状，建议。
2. 并入买入矩阵的「常备可买档位」条件文字（草案 4.2 的 L4 行已这样写）。
3. 取消——不建议，这会让战术层退化成「低分也能买」的口子。

## 6. 影响评估

### 6.1 分布迁移（本次改版最大的实际后果）

新 L2 = 90-95 分「很难颠覆」，按任何严肃口径都属 elite 区间。**现有 158 家 L2 不可能都留在 L2**。预期迁移方向：

- 现 L1 的 24 家：少数留新 L1/L2，多数落新 L3
- 现 L2 的 158 家：**绝大多数落新 L3/L4/L5**，其中一部分打分 <60 直接出 `worth_attention` → `boundary_pending`
- 现 L3/L4 的 79 家：多数落新 L5，部分出池

参考金字塔形状（**校准自检用，非配额**）：L1 ≤3%、L2 ~8%、L3 ~25%、L4 ~35%、L5 ~29%。偏离参考形状不算错误，但必须能逐票解释。

**这意味着改版后可买名单会明显收缩**，尤其是「中性档可买」的公司数量。是否接受这个收缩，是本方案最需要用户先确认的一件事——它比矩阵怎么排更影响实际操作。

### 6.2 执行成本

261 家 × 逐票证据驱动评分。ADR-0006 要求年报/公告/研报级证据，不得用聚合站简介。这是本轮最大的工作量，需要分批与锚点先行（见 §7）。

### 6.3 新增风险：分数漂移

引入分数后会出现新的失效模式——**为了让某只股票可买而微调分数**。质量分与 §6.2.1.6 的价格自动定档性质不同，不应每日变动。建议写死：

- 质量分**只在 §7.2 质量复核时变更，且变更必须有新证据**；
- 「无新证据的分数调整」纳入 §15.1 拦截清单，与 R1-R7 红线同构处理。
