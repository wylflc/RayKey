# A 股质量评分细则

本文件提供四维评分方法。评分对象、名单迁移、定档阈值、参考分公式及交易边界统一读取 [工作流程](000_Ashare_workflow.md)。当前公司分数与证据读取 `data/processed/a_share_watchlist_quality_tiers.csv`。

## 1. 评分步骤

1. 先按工作流程完成名单判断。
2. 提取决定质量的经营事实，分别给出四维分数、理由和来源。
3. 选当前分层表中的同业或同类载体锚点，核对证据后比较；不直接沿用历史行业笔记的分数和名单。
4. 按工作流程定档并计算参考分，写入唯一分层表与决策日志。

## 4. 四个维度

| 维度 | 评分内容 |
| --- | --- |
| Q1 生意模式质量 | 已实现的需求重复性、交易条件、利润率、维持性资本开支、价格趋势、客户议价力与现金转化 |
| Q2 护城河强度与持久性 | 难以购买的要素、不能压缩的建立时间、优势覆盖的利润比例、绕过路径及侵蚀趋势 |
| Q3 资本配置与股东回报 | 留存利润的再投资效率、资本纪律与现金返还；分别注明再投资、返还或混合路径 |
| Q4 管理层与企业文化 | 诚信、执行能力、治理、激励与股东利益一致性 |

Q1 记录已实现的经济结构，Q2 记录维持该结构的竞争屏障。利润率和现金流使用跨周期结构，不用单期景气或股价替代。

四维分段：95–100 极致；90–94 卓越；80–89 优秀；70–79 良好；60–69 及格；低于 60 为实质缺陷。

### 4.1 Q2 锚点比较

逐项比较资金充足的新进入者需要取得的要素和建立能力的时间，定到整数分。以下分段用于寻找可比载体，最终分数须以同业回报、替代难度及具体证据支持：

| 分段 | 载体特征 |
| --- | --- |
| 95–97 | 物理唯一、长期权利及相互强化的稀缺要素 |
| 88–92 | 法定仿制限制与难以再造的资源结合 |
| 84–87 | 独占或物理稀缺，但存在替代、规制或关联约束 |
| 81–83 | 长认证、型号定型、受限牌照或难以再造的产业集群 |
| 78–80 | 资源、技术与规模积累，资本加时间约 5–10 年可接近 |
| 74–77 | 品牌、渠道、规模与工艺积累，同业约 3–5 年可显著缩小差距 |
| 70 及以下 | 优势较易复制，须核对是否仍存在持久载体 |

核查优势能否转化为定价权、成本、客户关系或超额回报；不能仅按载体名称赋分。有竞争对手、份额不是第一或市场较小，都不能单独证明优势不存在。

### 4.2 报表可信度

`credibility_deduction` 填 0–15 的非负扣分值，由参考分公式减去。核查现金流与利润长期背离、应收/库存/商誉异常、负债与现金流错配、资本开支兑现及会计政策。每项扣分写证据；治理事项按工作流程处理名单。

## 6. 旗标与复核

| 字段或旗标 | 记录要求 |
| --- | --- |
| `replication_fail` | 写明复制测试失败的载体与证据，先复核名单归属，再按工作流程处理分层 |
| `erosion_path` | 写路径、概率、影响及事实依据；成立条件读取工作流程 |
| `dominated` | 给出更强同业逐项对照和不可替代利基检查 |
| `short_board` | 标明对应维度与缺陷 |
| `strategic_asset` | 记录战略角色、证据及已计入的维度；定档仍按工作流程 |
| `governance_open_issue` | 记录尚未澄清事项及核验触发 |
| `special_advantage_check` | 检查特殊治理、战略角色、章程承诺与事实标准等载体，注明结论及计入维度 |

核验决定原档位的具体断言，并记录 `evidence_status`、`evidence_sources` 和 `evidence_note`。区分外部新证核验与仅对既有记录作逻辑复检；缺外部证据时不得标记为已验证。

## 8. 输出字段与战术理由

```text
quality_tier / tier_reason
quality_score
q1_business_model_score / q1_reason
q2_moat_score / q2_moat_type / q2_erosion_paths
q3_capital_allocation_score / q3_reason
q4_management_score / q4_reason
credibility_deduction / flags / special_advantage_check
tactical_thesis
score_version / scored_at / evidence_status / evidence_sources / evidence_note
```

L3 的 `tactical_thesis` 写明确的条件式理由：兑现事件、可核验里程碑、证据来源与失效条件。无理由时如实写明。买入闸门读取工作流程 §9.3，不由本细则新增。
