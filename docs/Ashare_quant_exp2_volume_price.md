# 实验 B：无选股、无估值——纯量价信号的前瞻收益与随机抽样持有组合

> 登记日 2026-08-22。**研究性质**：不替代现行策略，只回答"不看公司质量、不看估值，只凭某个量价组合买入、持有固定天数（或挂单止盈/到期退出），
> 能得到什么量级的收益"。数据集、口径、已试信号与结果全部记录在本文件；**后续新的量价组合按 §7 追加**（在 `vp_signal_lab.py` 的 `SIGNALS` 登记一个函数即可）。

## 1. 问题与边界

用户给的判据："出现某个量价组合后，股票在 3/5/20/60 天内的上涨概率超过 50%，或至少曾经上涨了 x%；例如放量上涨后 5/10/20 天平均涨幅 ≥ 2%，
则对全市场出现该特征的股票随机买 10/20 只、20 天后卖出——一年 10 次信号即 20% 年化"。

本实验把它拆成两层可证伪的量：

1. **事件研究**：对每个信号（股票, 信号日 T）计算 T+1 收盘买入后 H ∈ {3,5,10,20,60} 天的前瞻收益分布——均值、中位、胜率、≥2%/≥5% 概率、
   **同日市场基准**（全部可交易股票等权同期收益）与**超额**，以及**最大有利偏移 MFE**（持有期内最高价曾达到 +2/3/5/10% 的概率，对应"挂单卖出"能否成交）。
2. **组合模拟**：H 个滚动档位，每日把到期档位资金重新投入当日信号股中随机 K 只（等权、整手、含费），持有 H 日到期卖出；
   可选"目标价挂单"：持有期内最高价触及入场价×(1+x) 即按目标价卖出，否则到期卖。**安慰剂** = 同一机制、不看信号随机买。多随机种子报分布。

## 2. 数据集与口径

| 项 | 取值 |
| --- | --- |
| 行情 | `data/raw/ohlcv/`：5,572 只 A 股（含已退市）不复权日线，载入 2003-01-02~2026-08-07（5,729 个交易日），样本起点 2005-01-04 |
| 复权 | 按 `a_share_corporate_actions.csv`（现金分红＋送转）把价格折到末日口径：除权日前价格 × 除权参考价÷前收盘，参考价 = (前收盘 − 每股现金)÷(1+送转比)；成交量反向乘 (1+送转比)。**收益率、均线都在折算序列上算＝含分红再投资的总收益** |
| 入场 | 信号日 T 收盘出信号，**T+1 收盘买入**（与回测引擎 `--exec-delay 1 --exec-price close` 同基；`--entry open` 可改 T+1 开盘）；T+1 一字板（最高=最低）或封板涨停（涨幅 ≥9.5% 且收于最高）视为买不进、剔除；T+1 停牌剔除 |
| 出场 | T+1+H 收盘；停牌/退市用此前最近一个收盘（退市股按末个收盘平仓，与回测协议一致）；超出样本末日按末日收盘截尾 |
| 样本资格 | 上市满 250 个交易日；`--universe` 可给实验 A 的股票库面板（`cap_top300.csv` 等）限定成分 |
| 市场基准 | 同日全部可交易股票等权的同期前瞻收益；超额 = 个股前瞻收益 − 同日基准（剔除牛熊背景，只看信号的截面信息） |
| 费用（组合模拟） | 佣金万一（最低 5 元）、过户费 0.001% 双边、印花税 0.05% 单边卖出（与回测 `--fee-preset user` 同）；本金 300 万 |
| 工具 | `scripts/experimental/vp_signal_lab.py`（numpy；本机 `python3.11`），产物在 `data/processed/experiments/exp_b/` |

## 3. 信号登记（`SIGNALS`）

| 名称 | 定义（均在复权序列上；均量缺省取**前一日止**的 n 日均量，不含当日） | 族 |
| --- | --- | --- |
| `vol_up(r,k,n=20)` | 当日涨幅 ≥ r 且成交量 ≥ k×前 n 日均量且收阳 | 放量上涨 |
| `vol_up_trend(r,k)` | `vol_up` 且 收盘 > MA20 > MA60 | 放量上涨·多头背景 |
| `bull_align(fast,mid,slow)` | 收盘 > MA_fast > MA_mid > MA_slow | 多头排列 |
| `ma_pullback(ma,tol=0.01,slow=60)` | MA_ma > MA_slow，最低 ≤ MA_ma×(1+tol)，收盘 ≥ MA_ma，收阳，前日收盘在 MA 上 | 多头回踩均线 |
| `low_vol_pullback(ma=20,k=0.6)` | MA20 > MA60，收盘在 MA20 ±2% 内，成交量 ≤ k×前 20 日均量 | 多头缩量回调 |
| `breakout(n,k)` | 收盘 > 前 n 日最高价，成交量 ≥ k×前 20 日均量 | 放量突破 |
| `limit_up(r=0.095)` | 当日涨幅 ≥ r | 涨停 |
| `gap_up(g)` | 开盘 ≥ 前收×(1+g)，收阳且收盘 > 前收 | 跳空高开 |
| `golden_cross(fast,slow)` | MA_fast 当日上穿 MA_slow | 均线金叉 |
| `three_up(n=3)` | 连续 n 阳且成交量逐日放大 | 连阳放量 |
| `vol_down(r,k)` | 当日跌幅 ≤ r 且成交量 ≥ k×均量 | 放量下跌（反转族） |
| `drawdown_rebound(n,dd,up)` | 前 n 日累计跌幅 ≤ dd，当日涨幅 ≥ up 且收阳 | 急跌首阳（反转族） |
| `oversold_ma(ma,dev)` | 收盘 ÷ MA_ma − 1 ≤ dev | 超跌（反转族） |
| `n_down(n)` | 连续 n 日收跌 | 连阴（反转族） |
| `any()` | 全部可交易股票日 | 安慰剂 |

### 4.1 趋势/突破族（首轮 12 个信号）

| 信号 | N | H=5 均值 / 超额 | H=10 均值 / 超额 | **H=20 均值 / 超额 / 胜率** | 曾≥5%(20d) | 逐年超额(H20)为正 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `any`（安慰剂＝市场） | 14,243,884 | +0.31 / 0 | +0.64 / 0 | **+1.31 / 0 / 50.0%** | 64.2% | 9/22 |
| `vol_up(0.05,2)` 放量上涨 | 236,634 | −0.49 / −0.89 | −0.13 / −1.14 | **+0.44 / −1.55 / 44.7%** | 68.4% | **0/22** |
| `vol_up(0.03,1.5)` | 681,661 | +0.01 / −0.53 | +0.49 / −0.65 | +1.22 / −0.91 / 48.0% | 69.1% | 0/22 |
| `vol_up_trend(0.05,2)` | 108,487 | −0.65 / −0.99 | −0.48 / −1.33 | −0.16 / −1.73 / 41.9% | 68.9% | 1/22 |
| `bull_align(20,60,120)` 多头排列 | 1,760,406 | +0.19 / −0.10 | +0.39 / −0.16 | +0.60 / −0.27 / 45.9% | 67.2% | 9/22 |
| `ma_pullback(20)` 回踩 MA20 | 477,188 | +0.04 / −0.12 | +0.20 / −0.15 | +0.51 / −0.27 / 46.0% | 63.0% | 5/22 |
| `breakout(60,1.5)` 放量突破 60 日 | 233,382 | −0.28 / −0.71 | +0.29 / −0.85 | +1.01 / −1.11 / 46.4% | 69.7% | 2/22 |
| `breakout(20,1.5)` | 485,394 | −0.07 / −0.55 | +0.49 / −0.62 | +1.21 / −0.81 / 48.2% | 68.2% | 2/22 |
| `limit_up(0.095)` 涨停 | 186,578 | −0.80 / −1.26 | −0.74 / −1.72 | **−0.76 / −2.56 / 42.2%** | 71.2% | 0/22 |
| `gap_up(0.03)` 跳空 | 95,164 | −0.52 / −0.91 | −0.28 / −1.13 | +0.14 / −1.61 / 44.3% | 69.7% | 1/22 |
| `golden_cross(20,60)` 金叉 | 120,380 | +0.32 / −0.11 | +0.63 / −0.14 | +1.19 / −0.09 / 47.7% | 63.4% | 8/22 |
| `three_up(3)` 三连阳放量 | 405,709 | +0.19 / −0.21 | +0.88 / −0.14 | +1.83 / −0.27 / 51.3% | 68.5% | 4/22 |

（收益为百分比；"超额"= 减同日全市场等权；完整列见 CSV。）

读法：
* **全市场随机买入、持有 20 天的平均收益就是 +1.31%、胜率 50%**（2005 起含三轮牛市）。用户设想的"信号后 20 天平均 ≥2%"在首轮
  12 个趋势/突破类信号里**没有一个达到**——最高的三连阳 +1.83%、`vol_up(0.03,1.5)` +1.22%，而且它们的"高"来自**信号扎堆出现在牛市里**
  （信号日的市场均值 2.1% > 全样本 1.31%）：剔除同日市场后**全部为负超额**，放量上涨/涨停/跳空的超额在 22 个年份里几乎没有一年为正。
* "曾经上涨 x%"的概率与信号基本无关：20 天内曾 ≥2% 约 82~85%、曾 ≥5% 约 63~71%（安慰剂 64%），这是波动率不是信号；涨停股 MFE 略高（71%）
  但终点收益最差（−0.76%）——**"挂单 +x% 卖出"赚的是波动，亏的是没触及那部分的回撤**，净值由 §5 的目标价组合模拟回答。
* 均线族（多头排列、回踩、金叉）接近零超额（−0.1~−0.3%），胜率 46~48%，**没有信息但也没有伤害**；
  "放量"类（放量上涨、突破、涨停、跳空）一致为负——A 股短期**反转**效应压过动量，与学术文献一致。

### 4.2 反转族（`event_all_reversal.csv`）

| 信号 | N | H=5 均值 / 超额 | H=10 均值 / 超额 | **H=20 均值 / 超额 / 胜率** | H=60 均值 / 超额 | 曾≥5%(20d) | 逐年超额(H20)为正 | 逐年胜率>50% |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| `oversold_ma(20,−10%)` 收盘低于 MA20 一成 | 798,963 | +0.94 / +0.37 | +1.90 / +0.64 | **+4.67 / +1.25 / 60.2%** | +7.05 / +1.20 | 74.5% | **21/22** | **20/22** |
| `drawdown_rebound(5,−8%,+2%)` 急跌首阳 | 306,421 | +0.53 / +0.11 | +1.10 / +0.21 | +2.98 / +0.45 / 55.0% | +5.28 / +0.07 | 73.4% | 18/22 | 16/22 |
| `n_down(5)` 五连阴 | 300,894 | +0.92 / +0.07 | +0.89 / −0.00 | +2.15 / +0.16 / 52.0% | +4.56 / +0.40 | 65.1% | 14/22 | 13/22 |
| `vol_down(−5%,2)` 放量下跌 | 71,756 | +0.41 / −0.43 | +1.05 / −0.65 | +2.34 / −0.85 / 51.5% | +3.01 / −1.46 | 68.4% | 3/22 | 13/22 |
| `low_vol_pullback(20,0.6)` 多头缩量回调 | 406,765 | +0.01 / +0.03 | +0.15 / +0.03 | +0.39 / +0.07 / 45.2% | +3.24 / +0.13 | 58.6% | 13/22 | 7/22 |

读法：
* **唯一稳定为正的是"超跌"**（收盘低于 MA20 达 10%）：20 天均值 +4.67%、中位 +3.55%、胜率 60%，剔同日市场后 **+1.25%、22 个年份里 21 年为正**，
  5/10/60 天同号；它达到了用户"20 天平均 ≥2%"的门槛——但两点要先说清：①它的信号日集中在下跌市（信号日的市场同期均值 +3.42% 是**反弹**，
  全样本只 +1.31%），剔除后的截面信息是 +1.25%；②超额胜率只有 49%，均值由右尾拉起，不是"多数能赚"。
* 急跌首阳 +0.45% 超额（18/22 年为正）方向相同、力度一半；五连阴接近零；放量下跌反而为负（放量的方向本身是负信息，与 §4.1 放量上涨一致）。
* 组合层面能否把 +1.25%/20 天的截面信息变成年化，取决于信号在**时间上的分布**（熊市扎堆、牛市稀少）与随机抽样的方差——见 §5。
