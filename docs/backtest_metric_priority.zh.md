# 回测指标的参考优先级与当前基准核对

分析日期：2026-09-05。目标按「未来可持续的实盘净复合年化收益」理解，收益含分红、扣融资与执行成本，净值剔除外部出入金；这里的「真实」指实际可实现，不指扣通胀后的实际购买力收益。本次为指标解释与既有结果复核，不构成生产规则修订。

**建议：用净复合收益排序，用样本外与扰动检验判断收益证据是否可信，用亏损和融资尾部约束能否持续执行。不要把所有指标等权投票，也不另造未经验证的综合分。**

**审核后澄清（2026-09-05）**：排序与采纳分开。滚5中位继续与全期CAGR构成现行并列采纳门槛，不能因下表将它归入「持有期稳定性」就降为纯参考；复利更高而滚5不满足现行门槛的候选仍被拦下。Fable审核的逐项取舍及最终实施建议见[审核与最终方案](backtest_metric_review_plan.zh.md)。

一个指标是否准确衡量目标，与它是否能预测未来，是两件事。CAGR准确回答过去资金复利了多少；历史CAGR最大不保证未来最大。没有任何单一历史指标在本项目中被验证为当前策略族未来收益的可靠预测器。

**优先看什么**

| 优先级与用途 | 建议读数 | 如何参考 |
| --- | --- | --- |
| 最高证据优先级 | 冻结规则后的真实／模拟前向净CAGR，或严格按时间隔离的样本外净CAGR | 所有选股、估值、调参只用当时可得信息；测试段不能参与选择，重复看完再调参的测试段转为研究样本。样本外仍受市场变化和样本长度限制。 |
| 现有历史表的主要排序量 | 全期净CAGR逐起点配对差中位；并看两条预定长跑 | 与复利目标直接一致。候选与BASE使用相同起点、终点、融资和成本。全样本、剔除A分别报告，候选另核并集U。 |
| 持有期稳定性及采纳门槛 | 滚动5年CAGR中位与P25 | 滚5中位保留并列采纳门槛角色；P25判断较差持有窗口。P25是历史窗口分位，不是未来收益的75%保证下界；重叠窗口不是独立样本。 |
| 持续执行的约束 | 滚5回撤中位，加跨起点最深MDD、实际最差5年CAGR、最低担保比例与强平次数 | 中位数描述通常路径，极端值揭示会被中位数抹掉的损失。回撤小不自动代表未来CAGR高，但融资强平和被迫中断会影响实际复利。 |
| 收益可迁移性 | 邻近参数平台、非重叠时段的配对增益、去赢家A／U、贡献集中度、执行成本压力 | 核对多出来的钱是否依赖单点参数、单只股票、单个行情阶段或理想成交。剔除赢家是条件压力情景，不是未来股票分布，更不是未来收益下限。 |

仅为阅读和研究建议；正式采纳流程仍以[工作流](000_Ashare_workflow.md)为准。现行回撤闸门表达风险取舍，不能把「通过某个回撤阈值」解释成「统计上未来CAGR更高」。在可执行性和风险约束都满足后，更低回撤或更高Sharpe不应自动压过净复利证据。

**哪些读数可以放在次要位置**

- Sharpe／Calmar：适合解释收益与波动／回撤的关系，不是本目标的第一排序量。跨策略可调整杠杆、要比较相同风险预算时，标准Sharpe更有用；本策略有融资成本、仓位与强平约束，不能只按比率外推可实现CAGR。
- 逐年收益中位、交易胜率、盈亏比：没有完整组合路径、资金占用与再投资信息，不能替代复利。2011锚点交易胜率仅32.84%，但报表全期年化36.09%，已经说明单独追求胜率会偏离目标。
- 换手：看它造成多少实际成本，不单独奖励低换手。年均换手7.01是引擎的买卖成交额合计口径，不应未经换算当成7.01次完整往返。
- 正号起点数、滚10中位、多组高度相似的比率：只补充描述，不能把重复信息累加为多份独立证据。
- 互不重叠5年块中位：比重叠窗口更方便观察行情阶段，但中位数不等于各块链乘后的年化；本批每起点只有2～3块，跨起点仍共享市场历史，且前端不足5年的部分被舍弃。

**本项目已经做过的预测力检验**

[回测日志§12.157](Ashare_backtest_log.md)在旧W=1基准与五个增速腿剂量臂上，用截止时点之前的读数预测其后5年实现值。全期CAGR、滚5中位、滚5P25的臂间增益符号一致率分别为29.0%、30.5%、35.4%；MAE分别为12.91、13.89、12.03pp，均大于恒预测增益为0的9.67pp。六臂未来排序的平均Spearman相关为负。该检验未包括Sharpe，且不是当前基准重跑；只能说明这段历史、这个家族没有测出正向预测传递，不能声称所有指标永远无效，更不能据此反向选最差者。

[§12.169](Ashare_backtest_log.md)另测得：历史扫描的起点间配对差相关约0.95，有效样本量估算约1.0～1.1；「14个起点都更好」不能读作14次独立验证。反复测试后只展示赢家会抬高估计表现，DSR研究正是针对多重测试选择与非正态收益作调整；DSR本身也不是未来CAGR预测器。[Bailey与López de Prado原文](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

当前基准没有在本次核查资料中提供可认定为完全隔离于调参过程的长期样本外收益记录，亦没有据此计算可信的未来年化区间。历史时点股票池、时间分段复查、去赢家和最近数据补跑各有价值，但都不能自动替代这项证据。

**高读数下被汇总隐藏的事实**

1. 常规表的滚5「最差11.51%／8.03%」其实是14个最差值再取中位；实际全局最差是−6.11%／−17.47%。「负窗占比中位0」同样不等于不存在5年亏损。全样本最差窗口来自2010-11起点，剔除A最差来自2009-11起点。
2. 全样本跨起点最深MDD达82.00%（2014-11起点）。2011锚点2015-06-09至2016-02-03下跌74.52%，到2018-02-02才收复此前峰值，峰值至恢复969个日历日；从谷底恢复需约292.42%涨幅。历史强平0次不代表未来不会强平。
3. 全样本最大单票市值／净资产的日度中位，再对起点取中位，为65.0%；日度P90再取起点中位为88.7%，前三只合计为145.2%。买入上限限制继续加仓，不阻止价格波动使权重被动越线。去赢家并未消除融资与集中风险。
4. 2011锚点非重叠块只有2016-07-29～2021-07-30（45.21%）和2021-07-30～2026-07-31（72.07%），两块中位58.64%；2011-11到2016-07的前端不满5年未入块，2015～2016的深回撤因此不在这两块内。61.48%的全起点块中位不能直接作未来年化水平。

**实现口径与实盘差距**

- BASE已包含预设佣金、印花税、过户费、股息税、融资年利率3.5%、整手、T+1尾盘价、缺价跳过。代码没有滑点／市场冲击／成交量参与率模型，因此应称「已计模型内成本」，不能称「所有真实成本已经计足」。收盘价成交的模拟也没有完整建模涨跌停无法成交和实际融资可得性。交易成本会随订单规模、股票与时点变化，应以用户实际交易规模校验；[AQR的实际成交研究](https://www.aqr.com/Insights/Research/Working-Paper/Trading-Costs)支持这一点，但其海外市场成本参数不能直接套用A股。
- [引擎`summarize`](../scripts/backtest_valuation_strategy.py)的全期年数为净值行数÷244，滚动窗口则按实际日历年数。2011锚点2011-11-01～2026-08-28共3603条净值，报表36.09%；同一期末资产按实际日历年数重算为35.93%。这是同一路径的年化尺度差异，本次保留在册口径以便核对。
- 引擎Sharpe为`(CAGR − rf) / 年化波动`；标准Sharpe使用同期超额简单收益的均值与标准差。[Sharpe本人定义](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)。表中0.87／1.01不能直接与其他系统的标准Sharpe或常见阈值比较，也不能直接送入DSR计算。

**以后比较方案的简明读法**

先检查数据和成交假设、完全隔离的验证期是否足够；按现行双门槛核对全样本及去赢家的全期CAGR与滚5中位，合格候选再以同期间净CAGR配对增益排序；接着看滚5P25及实际最差亏损、融资尾部是否还能接受；最后判断增益能否跨邻近参数、不同市场阶段和成本扰动保留。只有Sharpe、胜率、逐年中位或若干重叠指标改善，不足以支持替换。净收益、稳定性、尾部表现矛盾时，应明确收益证据与风险取舍，不按改善项数量投票。

最值得增加的验证是：冻结当前规则和后续比较办法，积累未参与调参的前向净值及成交偏差；对现有历史补真实执行压力与分期归因。继续增加高度相关的指标，不能弥补独立证据不足。

**复核入口**

从仓库根目录运行以下分钟内的只读核对；不重跑回测、不读取百万行状态文件：

```bash
python3 - <<'PY'
import csv
import hashlib
import json
import statistics as st
import sys
from pathlib import Path
sys.path.insert(0, 'scripts')
import sweep_backtest_configs as sw
p = Path('data/processed/experiments/exp_trough_guard_review')
m = json.loads((p / 'manifest.json').read_text())
assert sw.BASE == m['base'] and sw.DEFAULT_STARTS == m['starts']
assert hashlib.sha256(Path('scripts/backtest_valuation_strategy.py').read_bytes()).hexdigest() == m['engine_sha256']
for suffix in ('', 'ex5'):
    rows = []
    for start in sw.DEFAULT_STARTS:
        f = p / 'summaries' / ('summary_BASE' + start.replace('-', '') + suffix + '.csv')
        with f.open() as fh:
            rows.append(next(csv.DictReader(fh)))
    print(suffix or 'full', 'n=', len(rows))
    for key in ('年化', '最大回撤', '滚动5年年化中位', '滚动5年年化P25',
                '滚动5年年化最差', '滚动5年回撤中位', '滚动5年为负的窗口占比',
                '平均仓位', '最低担保比例', '强平次数'):
        vals = [float(r[key]) for r in rows]
        print(key, 'median=', st.median(vals), 'min=', min(vals), 'max=', max(vals))
    print('有五年亏损的起点数=', sum(float(r['滚动5年为负的窗口占比']) > 0 for r in rows))
PY
```

2011锚点回撤恢复、日历CAGR及非重叠块由同实验`artifacts/*_trough_BASE_equity.csv`逐日净值复算；净值CSV保留小数导致与summary极微小浮点差异，不影响本文两位小数。历史预测力检验只复核原日志与实现，本次没有重跑旧策略家族。
