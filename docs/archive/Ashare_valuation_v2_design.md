## 1. 结论摘要

诊断分两层，**第二层比第一层严重得多**：

1. **类型学层**：现行 A-G 七类的**分类轴不唯一**（混了盈利路径、资产回报、产业位置三个轴），导致标签不可判定，C 类沦为兜底桶（105/261 = 40%）。有五种公司在七类中都没有可算的模型：成本曲线周期型、金融资本型、稳态现金分配型、管线/研发资产型、订阅/递延收入型。

2. **建带层（阻断级）**：**全池 261 行中 132 行（50.6%）的合理价区间不是任何模型算出来的，而是由已判定的档位反推的**——其中 119 行可以精确复算为 `固定系数 × 估值当日现价`。这使 §6.2.1.6 的"价格自动定档"成为**循环定义**：档 → 带 → 档，估值模型从未进入。波及面：当前 86 个可买行中 43 个（50.0%）、17 只持仓中 10 只。

结论：**先修建带方向，再修类型学**。类型再细，只要"锚点不足可按档位标准带换算"这个后门还在，新类型同样会退化成反推。

## 3. 缺陷识别

### D-1 建带与定档互为因果（阻断级）

§6.6 步骤 8：带 = 该股按对应策略模型处于"中性"档的价格带。
§6.2.1.6：档 = f(现价, 带)。

两条合起来要求 `带 = 模型(锚定量)`、`档 = g(现价, 带)`，因果单向。但步骤 8 结尾的后门——"锚点数据不足时按档位标准带换算"——引入了 `带 = h(档)`，于是：

```
档 = g(现价, h(档))
```

模型从等式中消失。对这 132 行，"价格自动定档"退化为**现价对估值当日现价的涨跌幅判定**：涨过 12%（中性档带顶 1.12×）即"较高估"，涨过 34.4%（1.2×1.12）即"高估"。它是一条动量带，不是估值带。

### D-2 反推带把成本锚重新装回卖出规则（与 v1.27 直接抵触）

§14 估值卖出的减仓梯台阶 = {M, H, 1.2H, 1.44H}，全部由 `fair_price_low/high` 导出。对反推带持仓，这四级台阶实际是"估值当日现价的 1.0 / 1.12 / 1.34 / 1.61 倍"。

v1.27 刚刚**废止"留底 ≥ 建仓金额"**，理由写得很明确：*"它是卖出规则中最后一个成本锚定约束，与「卖出只由估值决定、与盈亏无关」直接抵触"*。反推带从后门把同一个东西装了回来——而且覆盖 10/17 只持仓，比被废止的留底原则影响更广。这是本次诊断中最需要优先处置的一条。

### D-3 §6.6 总表的"不适用"格与价格定档冲突

总表中 B/E/F/G 四类的"较高估"列写"不适用"。但 §6.2.1.6 规定档位由现价对带的位置每日自动重定，价格落在 `(带顶, 1.2×带顶]` 即"较高估"——**任何类型都可达**。

当日实测：**9 家公司正处在其策略模型宣称"不适用"的档位**（F 类 5 家、E 类 2 家、G 类 2 家）。而"较高估"在 §6.2.1 矩阵中对 L2/L3 直接触发提醒卖出——**一个"不适用"的格子正在产生真实的卖出提醒**。

根因：总表的档位阈值（PEG ≤0.7、市值 ≤ bull×60% 等）与 §6.2.1.6 的价格规则是**同一个变量的两套定义**，从未声明哪个优先。

### D-4 自洽性检验对反推行天然通过（检验失效）

§6.6 步骤 8 要求"区间必须与所定档位自洽"。全池实测违反率仅 1.9%（5/261）——**看似很好，实则无意义**：反推行是按档位系数构造的，构造上必然自洽。这项检验对最需要检验的 132 行零鉴别力，只对 129 行模型带真正生效。

### D-5 分类轴不唯一 → C 成为兜底桶

现行七类混了三个轴：

| 轴 | 类型 |
| --- | --- |
| 盈利路径 | A 稳定复利 / C 成长 / E 修复 |
| 资产与回报 | B 清算价值 / G 现金回报 |
| 产业位置 | D 瓶颈环节 / F 资源垄断 |

同一家公司可以同时落在三个轴上（如宁德时代既是瓶颈环节又是成长），标签不可判定，执行者只能凭直觉挑一个。凡是"在增长、但不明显是瓶颈"的一律进 C——C 因此吃下 40%，其中包含创新药、SaaS、券商、CXO、血制品等模型完全不同的公司。

### D-6 标签 ≠ 实际所用模型 ≠ 建带方式（三者可各说各话）

判例（`valuation_reason` 记录的实际推理 vs `strategy_tag` vs `fair_price_basis`）：

## 4. 方案

### 4.1 第一原则：分类轴统一为"锚定量"

**类型 = 这家公司的价值主要由哪一个可计量的量决定。** 锚定量决定模型，模型决定带。该轴天然互斥、可判定，且直接服务于唯一目的——**选出建带公式**。

标签不再承担"这是什么风格的股票"的表达功能（那是 `moat_summary` 与 `valuation_reason` 的事）。

### 4.2 类型表（**最终为 11 个主标签** + 2 个通用校验方法）

保留 A/C/D/E，重定义 F，新增 H/J/K/M/N，**用户追加 P 在手订单兑现型**（造船、大型工程承包、军工总装、长周期设备；池内判例：中国船舶、中材国际、中航高科），B/G 由主标签降为通用校验方法。P 的锚定量为 `backlog_annual_profit = 在手订单收入 × 归一化净利率 ÷ 兑现年数`，只计已签约、价格与数量确定的部分，带 = `× 合理PE × [0.80, 1.00]`；排期 < 2 年不适用，改判 D 或 H。生效定义见工作流 §6.5.2。

| 代码 | 类型 | 锚定量 | 中性带公式 |
| --- | --- | --- | --- |
| **A** | 现金流复利型 | 归一化自由现金流 | 使 `FCF收益率 + 保守增长 + 股息/回购` 落在 6%-8% 的价格区间（现行口径不变） |
| **C** | GARP 成长型 | 前瞻归母 + 可防守增速 g | `归母 × (PEG 1.0~1.5) × g / 股本` |
| **D** | 产业链爆发/关键瓶颈型 | 未来 2-3 年正常化归母 | `正常化归母 × 合理PE × [80%, 100%]` |
| **E** | 落难白马型 | 修复后正常化归母 | `正常化归母 × (历史中枢PE × [70%,100%]) × [85%,100%]` |
| **F** | **资源 NAV 型**（收窄） | 中枢商品价下的资源 NAV | `NAV × [85%, 100%]` |
| **H** | **成本曲线周期型**（新） | 跨周期中枢 EBITDA 或中枢归母 | `中枢盈利 × 中枢倍数 × [85%, 100%]`；成本曲线分位前 25% 取上沿 |
| **J** | **金融资本型**（新） | 可持续 ROE、每股净资产 BVPS | `BVPS × [(ROE−g)/(COE−g)] × [90%, 110%]` |
| **K** | **稳态现金分配型**（新） | 可持续每股分配现金 DPS | Gordon：`DPS/(r−g)`，带 = `× [90%, 110%]` |
| **M** | **管线/研发资产型**（新） | 商业化归一化归母 + 管线 rNPV | SOTP：`(商业化归母×PE + Σ rNPV) × [80%, 100%]` |
| **N** | **订阅/递延收入型**（新） | 收入 × 归一化经营利润率（EPV） | `EPV利润 × 成熟期PE × [85%, 100%]` |
| ~~B~~ | 清算价值 → **通用下限校验**（已决） | 保守清算价值 | 不单独定带；作为所有类型的**带下沿硬地板**（带下沿低于清算价值时以清算价值为准并留痕） |
| ~~G~~ | 股东回报 → **通用回报校验** | 股息率 + 回购注销率 | 不单独定带；作为 A/H/J/K 的**交叉校验**（总回报率低于要求回报即带上沿封顶） |

**F/H 划分判据（唯一）**：是否存在可独立计量的储量/资源资产、可算出 NAV。有 → F；无，价值由成本曲线位置与中枢价差决定 → H。混合型（如神火、厦门钨业、电投能源）按分部 SOTP，以利润占比最大的分部定主标签，另一分部在 `anchor_basis` 中单列。

**为什么 B/G 降级而不是删除**：两者的**方法**有价值（清算地板、回报率上限），但作为**主标签**它们的入选标准与所用模型自相矛盾（§3 D-7），且 B 已是空集、G 的 9/10 行是反推带。降为校验方法后，其约束力反而扩展到全部 10 类。

### 4.3 建带卡：所有类型统一的五槽

每一票的建带必须能填满下表五槽，**任一槽为空即判"无法估值"**，不得取得买入资格。这是"换 agent 也只能填表、不能自由发挥"的载体。

| 槽 | 字段 | 说明 |
| --- | --- | --- |
| 1 | `anchor_metric` | 锚定量名称，**枚举值**，由类型唯一决定 |
| 2 | `anchor_value` + `anchor_scope` + `anchor_basis` | 取值、口径（`market_cap`/`per_share`）、来源（必须引用 §6.6.1 台账行，不得引用临时检索结果） |
| 3 | `multiple_or_rate` + `multiple_source` | 倍数或折现率，及其来源枚举（见 §4.5） |
| 4 | `band_low_coef` / `band_high_coef` | 中性带上下沿系数，**由 §4.2 类型表给定，不得自选** |
| 5 | `band_sensitivity` + `band_fragile` | 敏感度带与脆弱标记（见 §4.6） |

复算恒等式（脚本可验，容差 ±2%）：

```text
fair_price_high = anchor_value × multiple_or_rate × band_high_coef ÷ (shares_out if anchor_scope=market_cap else 1)
fair_price_low  = anchor_value × multiple_or_rate × band_low_coef  ÷ (shares_out if anchor_scope=market_cap else 1)
```

新增字段：`anchor_metric`、`anchor_value`、`anchor_scope`、`anchor_basis`、`multiple_or_rate`、`multiple_source`、`band_low_coef`、`band_high_coef`、`shares_out`、`band_derivation`、`band_sensitivity`、`band_fragile`。`fair_price_basis` 保留为人读摘要，**不再是口径载体**。

### 4.4 关闭后门，并写死因果方向

1. **删除** §6.6 步骤 8 的"锚点数据不足时按档位标准带换算"。替换为：**锚点数据不足 → 判"无法估值" → `pool_layer = excluded`**。
2. **新增分工恒等式**（与 §6.2.1.6 的"价格改档、证据改带"并列）：

   ```text
   带 = 模型(锚定量, 倍数)      ← 只由 §7 复核修改
   档 = 位置(现价, 带)          ← 每日自动
   任何时候不得由档反推带。
   ```
3. **§6.6 总表的档位阈值降级为"倍数取值参考"**，不再是定档规则。定档由 §6.2.1.6 唯一承担。此举同时消除 D-3：五个档位对所有类型一律可达，"不适用"格全部删除。

### 4.5 参数取值必须落在成文区间（吸收 OI-001）

| 参数 | 取值来源优先级 | 允许区间 | 越界处置 |
| --- | --- | --- | --- |
| 合理 PE | ① 自身 5 年 PE 中位（要求期间业务结构未质变、盈利为正且非周期顶）② 同业中位（≥3 家可比，去极值）③ 由要求回报反解 `PE = 1/(r−g)` | 不得超出自身 5 年 PE 的 [25%, 75%] 分位 | 越界须写理由并强制 `band_fragile = true` |
| 周期中枢盈利 | **跨完整周期窗口年均值**（含下行年，A 股一般 5-7 年）为首选 | 窗口不完整而改用"峰值 × 比例"时，比例限 [40%, 70%]，且强制输出 ±15pp 敏感度 | 同上 |
| 峰值盈利输入 | — | **不得低于最近一个已披露季度的年化运行率**（OI-001 判例：美光、SK 海力士） | 硬拦截，须重取 |
| COE（J/K 用） | 10Y 国债收益率 + 股权风险溢价 | 风险溢价 5.5%-7.0%（银行取上限侧） | 越界须写理由 |
| 折现率 r（K 用） | 10Y 国债 + 资产风险溢价 | 受监管长久期资产 3.0%-4.5% | 同上 |
| 永续增长 g | 不得高于名义 GDP 增速假设 | ≤ 3.5% | 硬拦截 |
| rNPV 成功概率（M 用） | 按临床阶段查表 | I 期 10% / II 期 20% / III 期 50% / 报产 85% / 已获批 100%（**初始校准，按 §12 回放修订**） | 偏离须逐项写理由 |
| 归一化经营利润率（N 用） | 同业成熟期中位，或公司自身历史峰值利润率 × [70%, 100%] | — | 须写可达性论证 |
| 合约锁定 vs 现货收入 | **必须拆分并分别给倍数**（OI-001 第 2 条） | — | 未拆分即 `band_fragile = true` |

### 4.6 敏感度强制输出

`band_sensitivity`：记录锚定量 ±15%（或倍数 ±20%，取影响更大者）对应的带与档位。若在该扰动下档位跨越 **≥2 档**，置 `band_fragile = true`。

脆弱标记的后果（提案，需用户确认严格度）：该票在 §6.2.1 矩阵中**按低一档质量层级处理**（L1 按 L2、L2 按 L3、L3 不可买），直至锚点精度改善。理由：参数脆弱的结论不应享受与稳健结论相同的安全边际要求。

### 4.7 脚本校验（长期一致性的真正抓手）

文字规范会随执行者漂移，能长期约束的是**"字段必须填 + 脚本能复算 + 复算不过不给买入资格"**。

新增 `scripts/validate_valuation_bands.py`，池物化（§6.7）**前置强制运行**，校验六项：

1. 五槽非空；
2. `anchor_metric` 与 `strategy_tag` 的映射合法（类型表唯一对应）；
3. `band_low_coef`/`band_high_coef` 等于类型表规定值；
4. 复算带与入库带偏差 ≤2%；
5. `multiple_or_rate` 落在 §4.5 允许区间；
6. `band_derivation ≠ fallback`。

任一不过 → 该行不得物化为可买（降为 `excluded` 或按迁移规则降为可持有），并进入 `data/interim/valuation_rebuild_queue.csv`。校验结果写入决策日志。

## 6A. 实施中的一处方案修正：未过校验行必须分两档

落地写脚本时发现原方案 §5.1 的「反推带降为可持有」若直接实现为「校验不过即降可持有」，会把 **261 行全部**降为可持有——因为 v1.28 之前**没有任何一行**有建带卡字段。这会让迁移清单失去优先级意义，也远超用户 Q3 的决定范围（用户决定针对的是 132 行反推带，不是全池）。

因此实施时把未过校验分成两档，判据是**带本身是不是模型带**：

| 档 | 判据 | 处置 | 首次校验行数 |
| --- | --- | --- | ---: |
| `rebuild_required` | `band_derivation = fallback`、已退役标签、带系数不符、复算偏差 >2%、参数越界——**带本身不是模型带** | 降为「可持有」，不触发提醒卖出 | **133**（持仓 10 / 当前可买 38 / 其余 85） |
| `backfill_due` | 带是模型带，仅**建带卡字段尚未回填** | 限期登记义务，**买入资格不变**，未补齐禁止加仓 | **128**（持仓 7 / 当前可买 37 / 其余 84） |

这不是对用户决定的放宽，而是把它**精确化**：用户要切断的是「用假带批准买入」，不是「用真带但没填新表格」。该区分与本仓库已有的两次判例同源——v1.25（割肉价登记时滞不作合规判据，实测补定间隔 0-1 个交易日）与 v1.26（证据日兜底防伪欠账，伪欠账会淹没真实欠账）：**登记时滞不是要素缺失**。

`rebuild_required` 为 133 而非 132，多出的一行是苏泊尔——带是模型带，但标签 G 已在本版降为校验方法，需按 §6.5.0 重贴。
