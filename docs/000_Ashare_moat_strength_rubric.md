## 1. 结构性结论（历轮校准的证据，约束后续修订）

1. **护城河本身是一维指标。** 复制门槛/持久性/地位/宽度/深度任意两两相关 0.86-0.96，给它们分权重是自欺。护城河作为单一维度（Q2），持久性以带内方向修正的形式并入。
2. **优质程度是多维的。** 换成生意模式/护城河/资本配置/管理层四个侧面后平均绝对相关降至 ~0.42，且存在真实公司在一维高另一维低（长电：Q2 97/Q1 76；宁德：Q3 84/Q1 74；海大：Q4 82/Q1 58）。侧面相关是正常的，同一概念换名才是缺陷。
3. **维度命名会系统性污染打分。**「持久性」放在 0-100 好坏标尺上与门槛共线（0.93），改为带符号趋势后降至 0.56；「成长与资本再配置」中的「成长」把现金奶牛长电锚到 62 分。命名必须中性于路径。
4. **加权平均压缩顶部是事实，但解法在定档不在打分。** 用加成把分数推高属于测量污染；顶部区分度由定档阶段按分布与定性闸门解决。
5. **调整项的存在性检验**：一个调整项必须携带维度不含的信息，否则删除。卓越加成（维度分的函数）删除；特殊优势（与 Q2 问句同义）并入 Q2；报表可信度扣分（为「报表是真的」这一前提定价）保留。

## 2. 评分对象与硬约束

0. **打分与定档解耦（2026-07-30 用户指令）**：评分阶段只输出分数、理由与旗标，**不输出档位**；档位线、及格线、短板阈值全部属于定档阶段，待代表性样本分布明确后另定。打分时不得参照任何期望档位反推分数。
1. 只对 `attention_class = worth_attention` 的公司评分。
2. **当前股价、估值、市值、指数权重、流动性、当前行业景气度、当前盈利周期位置，不进入任何维度。** 涉及利润率、现金流的判断一律用**穿越周期的结构属性**，不用 TTM 水平。行业只以「结构性质量/结构性空间」形式进入 Q1/Q3。
3. **逐票人工评分、证据驱动**：年报/公告/问询与监管文书/投资者关系材料/权威研报。聚合站简介只作线索。**禁止关键词脚本自动打分**。
4. 每个维度、每项扣分、每个旗标都必须写理由与来源；无理由视为无效。
5. **分数带不是配额**（ADR-0006 决策 3）。金字塔形状只作定档阶段的校准自检。

## 3. 四个维度（合计 100%）

| 维度 | 权重 | 核心问句 |
| --- | ---: | --- |
| **Q1 生意模式质量** | 28% | 这家公司**已实现的赚钱方式**，其经济学结构好不好？ |
| **Q2 护城河强度与持久性** | 34% | 这套经济学结构**凭什么守得住**？门槛多难越、在变宽还是被填平？ |
| **Q3 资本配置与股东回报** | 20% | 公司把每一块留存利润变成了多少股东价值？ |
| **Q4 管理层与企业文化** | 18% | 掌舵的人诚实吗、有能力吗、和股东站在一起吗？ |

### 3.1 Q1 与 Q2 的因果边界（本细则最重要的一条定义）

- **Q1 测「果」**——公司已实现的经济学结构，全部可在报表与经营数据中观察：需求是否重复发生、预收还是应收、毛利结构、资本开支强度（维持竞争地位需要多少持续投入）、单价长期趋势（通缩还是提价）、客户集中与议价力、周期敏感度、现金转化。
- **Q2 测「因」**——守住这套结构的屏障：载体无关（品牌/产区/牌照/技术/工艺/认证/网络效应/切换成本/规模/生态/特殊治理结构/战略角色一视同仁），评强度（不可买的要素 + 不可压缩的时间）、覆盖度（保护多大比例的利润）、与方向（未来 2-3 年侵蚀路径的概率与影响；变宽取带内上沿、被填平取下沿、中/高概率明确侵蚀路径降一带并记旗标）。
- **判例**：宁德时代「垄断了新能源车中价值量最大的电池模块」——垄断地位计入 Q2（84）；Q1 只看其已实现结构：经营现金流长期大于净利润、对整车厂占款为负营运资本（加分项），但单价逐年通缩、维持地位需持续千亿级资本开支、客户集中且强势（减分项）→ 74。同为龙头，茅台 Q1=98（先款后货、零应收、91% 毛利、几乎零维持性资本开支）——**生意与生意不同，这正是本维度要测的**。
- **备选定义（未采用，留给用户裁决）**：若 Q1 改为包含公司已获得的竞争位置（段永平口径的公司级商业模式），宁德 Q1 可至 85 上下，但 Q1/Q2 相关性将回升至 ~0.9，重演共线。

### 3.2 Q3 资本配置与股东回报（更名自「成长与资本再配置」）

**更名理由**：「成长」一词把打分锚定到「有没有增长空间」，导致对资本返还型公司的系统性错杀（长江电力初打 62 判例）。本维度与增长无关，只与**留存资本的去向与效率**有关，两条平行路径等价：

- **再投资路径**：存在高回报的再投资机会且历史再投回报被验证（增量 ROIC、并购成败记录、扩产纪律）。
- **返还路径**：缺乏高回报机会时，通过分红承诺与兑现、回购注销高效返还，不囤积现金、不低回报造帝国。

**扣分情形（两条路径共用）**：现金长期低收益闲置、多元化并购毁灭价值、下行周期逆势高资本开支且回报未验证、增发摊薄无对价。

### 3.3 Q4 管理层与企业文化

诚信与披露记录、对中小股东的历史行为、承诺兑现率、激励与股权结构的一致性、关键人依赖与接班安排、企业文化的跨周期一致性。**与 Q3 的边界**：Q3 看资本配置的**客观结果**（数字），Q4 看**人的行为与取向**（定性）。

### 3.4 周期股、成长股、爆发股

不设单独通道：成长/爆发股的空间与份额路径在 Q3 再投资路径表达，但低门槛增长会被 Q1/Q2 诚实压低；周期股的商品化生意在 Q1 诚实低分，真实的资源禀赋/成本曲线优势由 Q2 承担；周期定价问题留在估值层策略标签 F，不在质量层补偿。

## 5. 报表可信度与财务脆弱性扣分（0 ~ −15，只扣不加）

**存在理由**：Q1-Q4 全部建立在「报表是真的、资产负债表撑得住」这一前提上；本项为该前提定价。它不是质量维度，**可信度不能与质量互相平均**——96 分护城河不应能抵消可疑报表，故必须独立、单向。与 Q4 的边界：Q4 判断人的能力与取向（定性），本项是账面可机械核验的红旗（定量绊线，防叙事俘获）。

| 红旗 | 扣分参考 |
| --- | ---: |
| 经营现金流长期显著低于净利润（剔除合理的成长性营运资本占用） | −3 ~ −8 |
| 应收/存货/商誉相对收入异常膨胀 | −2 ~ −6 |
| 有息负债结构与现金流错配（与商业模式匹配的公用事业型长债不扣） | −2 ~ −6 |
| 资本开支长期不兑现为收入或回报 | −2 ~ −5 |
| 会计政策变更、非经常性损益占比高、复杂关联交易 | −3 ~ −10 |

干净的报表 = 0 分（本分，不加分）。坐实的造假/资金占用/审计异常不在此列——按 §5.4.7 判 `garbage`。

## 6. 旗标（定档阶段使用，打分阶段只记录）

| 旗标 | 记录内容 | 定档阶段的预期用法（待定） |
| --- | --- | --- |
| `replication_fail` | 资本复制测试不通过 | 出 `worth_attention`（继承 ADR-0006，与分数无关） |
| `short_board` | Q1 或 Q2 <60 | 不得进入前二档（阈值待定档时确认） |
| `dominated` | 被更强同行全面覆盖且无不可替代利基 | 压至低档 |
| `erosion_path` | 2-3 年内中/高概率可见侵蚀路径（写明路径/概率/影响） | 顶档一票否决 |
| `special_advantage_check` | **强制字段**：是否存在非标准载体的难复制优势（特殊治理/战略角色/章程承诺/事实标准），计入了哪个维度 | 防漏检；替代已删除的特殊优势加分通道 |
| `governance_open_issue` | 治理/披露存在未澄清事项 | 压档 |

- **均值 76.2 / 中位数 77.0 / 极差 89.58-64.08**。
