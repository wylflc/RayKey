## 1. 两个输出，两种职能

分级产出**两个互不替代的东西**：

| 输出 | 性质 | 职能 |
| --- | --- | --- |
| **质量档**（L1 强 / L2 中 / L3 弱护城河） | **硬闸门** | 决定买入/持有/卖出提醒的严格程度（三态矩阵） |
| **参考分**（0-100 四维合成） | **展示项，非规则** | 档**内**排序，供用户判断建仓档位与所需安全边际 |

分开的理由是两者需要相反的数学性质：**定档需要分离度**（把不同类的公司拉开），**档内排序需要平滑序**（在同类中给出连续次序）。用同一个数兼任两职，正是 v0.4 失败的原因（§2.2）。

## 2. 为什么是三档、为什么档由规则定而非分数定

### 2.1 三档是唯一与估值阶梯自洽的档数

估值阶梯有五级（低估 → 较低估 → 中性 → 较高估 → 高估）。三档 ×（可买 / 可持有 / 提醒卖出）恰好铺满，无需任何技巧。v0.4 的五档方案曾被迫发明"奇偶交替缓冲档"——奇数档给缓冲、偶数档直接跳到卖出提醒——**那个技巧存在本身就是档数与阶梯不匹配的信号**。

### 2.2 合成分定档在全样本上被证伪

261 家全池打分后（v0.4 四维加权），三项实测：

| 发现 | 证据 |
| --- | --- |
| **断层划线不成立** | 相邻分差 >2 的间隙全部在头部 4 家与尾部 7 家；主体 245 家最大间隙仅 **0.90**。42 家锚点上看到的"书架与断层"是稀疏采样假象 |
| **平均必然抹掉区分度** | Q1 σ=7.30、Q2 σ=6.20，而**四维合成 σ=5.16——低于它自己任何一个主维度**。根因：Q1 与 Q2 秩相关仅 **+0.178（近乎独立）**，平均近独立变量朝 σ/√n 收缩 |
| **短板封顶零生效** | Q1 或 Q2 <60 的 26 家，加权分本就全部 ≤69；60-69 的 134 家本就全部 ≤79。封顶与算术结果完全重合 |

「再好的公司也一定有某方面短板」这一直觉，其数学形式就是第二条：**短板与长板在加权平均中互相抵消**。

### 2.3 总体本身没有天然分组

改用 Q2 单维定档确实更能区分（≥1 分的间隙由 8 个增至 22 个，最大间隙 4.3→8.0），但 Q2 的众数仍堆在 70-75（112 家，43%），任何三分线都切出 57-64% 的中间档。**261 家全部通过严格的 worth_attention 初筛，在任何指标上都是连续谱。** 向数据要"明确的质量区分"是在要它没有的东西——区分必须来自**规则的定义**，不能来自分数的分布。

### 2.4 金字塔要求退役

旧 §5.7.1 要求分层呈金字塔形，理由是"上层是稀缺关注名额"。**D-21 已把名单进出交给独立的 attention 扫描**，分级不再配给任何东西，只设定严格度。**因此金字塔要求是前 D-21 设计的遗留物，随本次重构退役。** 中间档占多数不是缺陷——多数公司本就该拿默认严格度。

## 3. 质量档（硬闸门）

### 3.1 定档规则

档由**定性规则**判定，Q1/Q2 分数是规则的可核验载体（阈值来自 §4.1 阶梯与实测密度谷底，非拍脑袋）：

| 档 | 判定 |
| --- | --- |
| **L1 强护城河** | 满足任一通道，**且**无中/高概率可见侵蚀路径：<br>**通道A 护城河型**：Q2 ≥ 82 且 Q1 ≥ 66<br>**通道B 生意模式型**：Q1 ≥ 80 且 Q2 ≥ 78 |
| **L2 中护城河** | 资本复制测试通过，但存在可见侵蚀路径、明确同业竞争，或未过 L1 任一通道 |
| **L3 弱护城河** | 任一成立（充分条件）：Q2 < 66（护城河已被证明可被资本攻破）/ Q1 < 60（生意模式塌陷）/ 被更强同行全面覆盖且无不可替代利基 |

**必要与充分是不对称的**——这是本规则的核心结构：

- **L1 用 AND**：护城河强是**必要条件**。生意模式再好，护城河不足也不入 L1。
- **L3 用 OR**：任一维度塌陷即**充分**降档。
- 对应「可以有短板，但不能有致命伤」。

**为什么通道B 不能用 OR、且门槛必须 ≥78**（实测判例）：若允许「Q1 高即入 L1」，会纳入分众传媒(Q2=70)、洋河股份(70)、爱尔眼科(70)、东鹏饮料(70)——这些公司的护城河**已被判例证明可攻破**（新潮攻击分众点位、汾酒赶超洋河、华厦普瑞追赶爱尔）。**海天味业是决定门槛高度的活判例**：Q1=85（复购+渠道预收+高毛利，生意经济学确实优秀）但 Q2=77，零添加事件中份额实际流向千禾——若门槛设在 76，海天恰好会在事件前被放进 L1（中性可买、只在高估才提醒卖出）。**好生意没壁垒 = 需要更多安全边际，不是更少。**

**Q1 作地板而非权重**：护城河再强，生意模式不足则不入 L1。判例——盐湖股份 Q2=84 但 Q1=64、北方稀土 Q2=86 但 Q1=60、中芯国际 Q2=84 但 Q1=55。

**旗标是第三个输入**：定档用 Q1、Q2、旗标三者，而二维散点图只能显示前两个。宁德时代（Q1=74, Q2=82）落在通道A 区域内却判 L2，原因是 `erosion_path(中)`——固态路线与客户二供。读图时须记得这一维不可见（notebook 图⑥ 已用橙圈标出）。侵蚀概率按 `erosion_path(...)` 内的标注解析，**只有中/高概率排除 L1**；注意 `erosion_path(低端,中)` 这类标注中「低端」指市场档次而非概率。

### 3.2 为什么 Q2 主导、Q3/Q4 移出定档

按目的反推：**什么性质配得上"少要一点安全边际"？** 答案是内在价值不被侵蚀的把握——即护城河持久性（Q2）。据此：

- **Q3 资本配置**是**回报驱动**而非**安全驱动**，移交估值层作再投资假设（与 D-15「成长性归估值」同一逻辑）。
- **Q4 管理层与文化**是执行风险，转为旗标与参考分成分，不单独定档。
- **Q1 生意模式**作地板，不作权重。

四个维度全部保留打分（见 §4），只是**只有 Q2 与 Q1 参与定档**。

## 4. 四个维度（打分口径不变）

| 维度 | 核心问句 |
| --- | --- |
| **Q1 生意模式质量** | 这家公司**已实现的赚钱方式**，其经济学结构好不好？（需求可否重复、预收还是应收、毛利结构、维持竞争地位所需的资本开支强度、单价长期趋势、客户议价力、现金转化） |
| **Q2 护城河强度与持久性** | 这套结构**凭什么守得住**？门槛多难越（不可买的要素 + 不可压缩的时间，**载体无关**）、覆盖多大比例的利润、能否被绕过；以及**这条河在变宽还是被填平** |
| **Q3 资本配置与股东回报** | 公司把每一块留存利润变成了多少股东价值？再投资路径与返还路径等价 |
| **Q4 管理层与企业文化** | 掌舵的人诚实吗、有能力吗、和股东站在一起吗？ |

**Q1/Q2 的因果边界**：Q1 测「果」（报表可观察的已实现结构），Q2 测「因」（守住它的屏障）。判例：宁德时代"垄断了价值量最大的电池模块"计入 Q2=84；Q1 只看已实现结构（现金流大于净利、对整车厂负营运资本，但单价通缩、千亿维持性开支、客户强势）=74。该边界使 Q1⊥Q2（ρ=0.178），是两者能分别承担地板与主判据的前提。

**维度分档锚点**（四维共用）：95-100 极致（市场中定义级）｜90-94 卓越｜80-89 优秀｜70-79 良好｜60-69 及格｜<60 构成实质缺陷。

### 4.1 Q2 载体硬度阶梯（1 分粒度，锚点比较法）

Q2 是定档主判据，必须能稳定区分到 1 分。用**锚点比较**而非绝对打分：不问「这家值多少分」，而问**「和 X 比，谁的门槛更难越」**——统一的比较问句是「资金充足的新进入者要越过它，需要多少**买不到的要素** + 多少**压不掉的时间**」。

| 分段 | 载体性质 | 锚点 |
| --- | --- | --- |
| **95-97** | 标的物物理唯一且法律永续 | 长江电力 97（三峡坝址，物理上无第二个）｜贵州茅台 96（产区+品牌+基酒三重互相强化） |
| **88-92** | 法定禁止仿制 + 标的物不可再造 | 片仔癀 90（国家绝密配方=法律禁止仿制，叠加天然麝香配额） |
| **84-87** | 法定独占/物理稀缺，但有替代路径、受管制削弱或关联绑定 | 五粮液 87、北方稀土 86（配额制但量价受集团调节）、国电南瑞 85（技术锁极硬但客户即控股股东）、中国神华 84、小商品城 84 |
| **81-83** | 长认证周期的型号定型 / 法定牌照 / 不可再造的产业集群 | 中航光电 83（型号定型后换供应商需重做适航）、云南白药 83（保密配方，低于绝密一级）、天坛生物 82（浆站牌照法定管制）、澜起科技 81（JEDEC 标准参与） |
| **78-80** | 资源禀赋·技术代差·份额领先，资本+时间 5-10 年可接近 | 陕西煤业 80、菲利华 80、比亚迪 79（垂直一体化属「能力」非法律或物理锁）、恒生电子 79（客户切换成本） |
| **74-77** | 品牌·渠道·规模·工艺积累，同业在追，3-5 年可显著缩小 | 海天味业 77（已被零添加事件证明可攻击）、金山办公 77（信创政策承担主要保护）、爱美客 75 |
| **<70** | 可被资本较快复制 | 分众传媒 70（点位已被新潮买过一轮） |

**判断次序**：先定载体属于哪一段（法律锁 > 物理锁 > 认证锁 > 能力锁 > 品牌渠道锁），再在段内与锚点两两比较定 1 分位次。

> **2026-07-31 精度修复**：初版打分 98% 落在偶数分，Q2=80 处堆积 14 家、78 处 32 家——**候选档位线恰好落在人为堆积的峰上**，压线公司的命运会由取整噪声决定。按本阶梯对 Q2 ∈ [76,88] 的 89 家重打后，偶数分占比降至 85%，密度谷底移到 **82-83**（各 3、4 家压线），通道A 的线因此定在 82。Q2 < 76 的 170 家远离该线，本轮未重打。

**报表可信度扣分（0 ~ −15，只扣不加）**：Q1-Q4 建立在"报表是真的"这一前提上，本项为该前提定价——经营现金流长期显著低于净利润、应收/存货/商誉异常膨胀、有息负债与现金流错配、资本开支长期不兑现、会计政策粉饰迹象。干净报表 = 0（本分，不加分）。坐实的造假/资金占用按 §5.4.7 判 `garbage`。

## 5. 参考分（展示项）

**参考分 = Q1×0.25 + Q2×0.40 + Q3×0.20 + Q4×0.15 − 报表可信度扣分。**

即 v0.4 的四维合成分原样保留。它在定档岗位上因方差收缩而失败（§2.2），但**档内排序正是它胜任的工作**——需要的恰恰是用上全部信息的平滑序。

**用途与边界**：

- **用途**：同档内排序，供用户判断建仓档位（重仓/轻仓）与所需安全边际的深浅。同属 L1，**茅台 90.2 与国电南瑞 74.5 相差 15.7 分**——两者护城河都够 L1（一个是产区+品牌+基酒三重，一个是电网调度事实标准），但生意模式、资本配置与治理差距明显，建仓速度与安全边际理应不同。这正是参考分要保住的信息。
- **边界（硬性）**：参考分**不是规则**。§13 明确规定单票建仓金额由用户逐票决定，系统只提供事实、不代为定档；本项同样只作展示，**不得据此自动assign仓位档、不得据此改变矩阵资格、不得据此发出买卖指令**。它是用户判断的输入，不是判断本身。

档内跨度（261 家实测）：L1 74.5-90.2 跨 15.7（σ 4.26）｜L2 62.3-80.0 跨 17.7（σ 3.22）｜L3 48.7-70.2 跨 21.5（σ 5.11）。三档各自都有足够的档内区分度。

## 6. 旗标

| 旗标 | 记录内容 |
| --- | --- |
| `replication_fail` | 资本复制测试不通过 → 直接判 L3。**只记录，不裁决名单归属**（D-21）——是否移出 `worth_attention` 由独立的 attention 扫描决定 |
| `erosion_path` | 2-3 年内可见侵蚀路径（写明路径/概率/影响）。中/高概率即排除 L1 |
| `dominated` | 被更强同行全面覆盖且无不可替代利基 → 直接判 L3 |
| `short_board` | Q1 或 Q2 塌陷（<60），或 Q1 地板不满足 |
| `strategic_asset` | 国家战略不可替代角色，需求/生存/资金被政策承保。允许**书面化 anchor_override**（档位可高于规则所示，理由与对照留痕）；分数与规则判定本身不因此调整 |
| `governance_open_issue` | 治理/披露存在未澄清事项 |
| `special_advantage_check` | **强制字段**：是否存在非标准载体的难复制优势（特殊治理/战略角色/章程承诺/事实标准），计入了哪个维度。防漏检，不产生独立加分 |

## 7. 评分对象与硬约束

1. 只对 `attention_class = worth_attention` 的公司评分。
2. **评级不改变名单归属**（D-21）：本流程只输出档位与分数，不移出 attention list。
3. **打分无下界**（D-19）：允许任意客观低分，不向任何及格线锚定。
4. **当前股价、估值、市值、指数权重、流动性、当前行业景气度、当前盈利周期位置，不进入任何维度。** 利润率与现金流判断一律用穿越周期的结构属性。行业只以"这门生意的结构性质量"（Q1）与"结构性空间"（Q3）形式进入，不以景气度形式进入。
5. **逐票人工评分、证据驱动**：年报/公告/问询与监管文书/投资者关系材料/权威研报。聚合站简介只作线索。**禁止关键词脚本自动打分**。
6. 每个维度、每项扣分、每个旗标、每次定档都必须写理由与来源。
7. **档与分数只在质量复核时凭新证据变更**，不得随价格或买入意愿变动。「无新证据的调分/调档」纳入 §15.1 拦截清单。

### 10.6 规则修订：生意模式塌陷「降一档不越档」（2026-07-31 用户决定）

原 L3 触发为 `Q2<66 或 Q1<60 或 dominated`。`Q1<60` 这一支会把**护城河很强、生意模式很差**的公司直接降两档到 L3——中芯国际 Q2=84、天齐锂业 Q2=80、牧原股份 Q2=78 都在其中。用户判断：**生意模式确实有影响，但直接降两档过重。**

修订后：

| 档 | 判定 |
| --- | --- |
| **L3** | `dominated` **或** `Q2<66`（护城河本身弱）**或**（`Q1<60` **且** `Q2<72`，即护城河仅及格又无经济学可倚仗） |
| **L2** | `Q1<60` 但 `Q2≥72` —— **护城河强到足以倚仗，生意模式塌陷降一档不越档** |

原则：**L3 = 没有任何一项足够强可倚仗。** 护城河强（Q2≥72）本身就是可倚仗项，不应因另一维塌陷而被判为「弱护城河」。这同时修掉了上一轮记录的档名语义问题——L3 现在真的只装「护城河弱」的公司。

改档 6 家（全部 L3→L2）：中芯国际(55/84)、天齐锂业(58/80)、牧原股份(52/78)、盛合晶微(58/74)、寒武纪(55/74)、中兴通讯(58/72)。

**关于档内排名**：中芯国际改判 L2 后参考分 66.85，在 L2 中排后段而非前段。这不是缺陷——参考分回答的是「建仓速度与所需安全边际」，而 ROIC 2.17%、折旧年增三成的生意确实不复利资本，理应要求更多安全边际。**若让参考分也由护城河主导，它就与档位重复，正是前几轮花大力气消除的冗余。** 战略考量的正确载体是 `strategic_asset` 旗标（与参考分并列展示），不是抬高分数。

### 10.7 证据复核协议

`evidence_status` 三态：`calibration_model_knowledge`（当前全部）→ `evidence_verified` / `evidence_disputed`。

复核**不是重打全部四维**，而是核验**决定档位的那几条断言**：

- **L1（16 家）**：①资本复制测试是否真的"行业公认级"通过 ②是否真的无中/高概率侵蚀路径。任一被证据推翻即降 L2。
- **L3（36 家）**：降档触发（Q2<66 / Q1<60 / dominated）是否被证据支持。
- **L2（209 家）**：默认严格度，不改变买卖行为，**低优先级**；仅当复核 L1/L3 时发现邻近公司明显错档才顺带处理。

证据标准按 §7 第 5 条。每家复核后写 `evidence_sources`（URL 或公告文号）与结论；与原判不一致的必须写明分歧点。
