- **内部版本**：v0.5（2026-07-31，三档重构）。

## 1. 两个输出，两种职能

分级产出**两个互不替代的东西**：

| 输出 | 性质 | 职能 |
| --- | --- | --- |
| **质量档**（L1 强 / L2 中 / L3 弱护城河） | **硬闸门** | 决定买入/持有/卖出提醒的严格程度（三态矩阵） |
| **参考分**（0-100 四维合成） | **展示项，非规则** | 档**内**排序，供用户判断建仓档位与所需安全边际 |

分开的理由是两者需要相反的数学性质：**定档需要分离度**（把不同类的公司拉开），**档内排序需要平滑序**（在同类中给出连续次序）。用同一个数兼任两职，正是 v0.4 失败的原因（§2.2）。

---

## 2. 为什么是三档、为什么档由规则定而非分数定

### 2.1 三档是唯一与估值阶梯自洽的档数

估值阶梯有五级（低估 → 较低估 → 中性 → 较高估 → 高估）。三档 ×（可买 / 可持有 / 提醒卖出）恰好铺满，无需任何技巧。v0.4 的五档方案曾被迫发明"奇偶交替缓冲档"——奇数档给缓冲、偶数档直接跳到卖出提醒——**那个技巧存在本身就是档数与阶梯不匹配的信号**。

### 2.2 合成分定档在全样本上被证伪

261 家全池打分后（v0.4 四维加权），三项实测：

| 发现 | 证据 |
| --- | --- |
| **断层划线不成立** | 相邻分差 >2 的间隙全部在头部 4 家与尾部 7 家；主体 245 家最大间隙仅 **0.90**。42 家锚点上看到的"书架与断层"是稀疏采样假象 |
| **平均必然抹掉区分度** | Q1 σ=7.30、Q2 σ=6.20，而**四维合成 σ=5.16——低于它自己任何一个主维度**。根因：Q1 与 Q2 秩相关仅 **+0.178（近乎独立）**，平均近独立变量朝 σ/√n 收缩 |
| **短板封顶零生效** | Q1 或 Q2 <60 的 26 家，加权分本就全部 ≤69；60-69 的 134 家本就全部 ≤79。封顶与算术结果完全重合 |

「再好的公司也一定有某方面短板」这一直觉，其数学形式就是第二条：**短板与长板在加权平均中互相抵消**。

### 2.3 总体本身没有天然分组

改用 Q2 单维定档确实更能区分（≥1 分的间隙由 8 个增至 22 个，最大间隙 4.3→8.0），但 Q2 的众数仍堆在 70-75（112 家，43%），任何三分线都切出 57-64% 的中间档。**261 家全部通过严格的 worth_attention 初筛，在任何指标上都是连续谱。** 向数据要"明确的质量区分"是在要它没有的东西——区分必须来自**规则的定义**，不能来自分数的分布。

### 2.4 金字塔要求退役

旧 §5.7.1 要求分层呈金字塔形，理由是"上层是稀缺关注名额"。**D-21 已把名单进出交给独立的 attention 扫描**，分级不再配给任何东西，只设定严格度。**因此金字塔要求是前 D-21 设计的遗留物，随本次重构退役。** 中间档占多数不是缺陷——多数公司本就该拿默认严格度。

## 3. 质量档（硬闸门）

### 3.1 定档规则

档由**定性规则**判定，分数只作支持证据：

| 档 | 判定 |
| --- | --- |
| **L1 强护城河** | 三条同时成立：①资本复制测试**完全通过**（行业公认级，非分析师主观判断）②未来 2-3 年**无可见侵蚀路径**（中/高概率的路径即不满足）③**生意模式不塌陷**（Q1 地板） |
| **L2 中护城河** | 资本复制测试通过，但存在可见侵蚀路径或明确的同业竞争压力 |
| **L3 弱护城河** | 任一成立：资本复制测试不通过 / 被更强同行全面覆盖且无不可替代利基（Dominance Rejection Test）/ 护城河已被证明可被资本攻破 |

**Q1 作地板而非权重**：护城河再强，若生意模式本身塌陷则不入 L1。判例——中芯国际 Q2=85 但 Q1=55、北方稀土 Q2=86 但 Q1=60，两家均因生意模式（全球最重资本开支且非全球赢家 / 配额制下量价受控）被挡在 L1 外。

**分数作为一致性检查**（不是判据，偏离须书面说明）：L1 通常 Q2 ≥80 且 Q1 ≥62；L3 通常 Q2 <66，或带 `short_board`/`dominated` 旗标。

### 3.2 为什么 Q2 主导、Q3/Q4 移出定档

按目的反推：**什么性质配得上"少要一点安全边际"？** 答案是内在价值不被侵蚀的把握——即护城河持久性（Q2）。据此：

- **Q3 资本配置**是**回报驱动**而非**安全驱动**，移交估值层作再投资假设（与 D-15「成长性归估值」同一逻辑）。
- **Q4 管理层与文化**是执行风险，转为旗标与参考分成分，不单独定档。
- **Q1 生意模式**作地板，不作权重。

四个维度全部保留打分（见 §4），只是**只有 Q2 与 Q1 参与定档**。

## 4. 四个维度（打分口径不变）

| 维度 | 核心问句 |
| --- | --- |
| **Q1 生意模式质量** | 这家公司**已实现的赚钱方式**，其经济学结构好不好？（需求可否重复、预收还是应收、毛利结构、维持竞争地位所需的资本开支强度、单价长期趋势、客户议价力、现金转化） |
| **Q2 护城河强度与持久性** | 这套结构**凭什么守得住**？门槛多难越（不可买的要素 + 不可压缩的时间，**载体无关**）、覆盖多大比例的利润、能否被绕过；以及**这条河在变宽还是被填平** |
| **Q3 资本配置与股东回报** | 公司把每一块留存利润变成了多少股东价值？再投资路径与返还路径等价 |
| **Q4 管理层与企业文化** | 掌舵的人诚实吗、有能力吗、和股东站在一起吗？ |

**Q1/Q2 的因果边界**：Q1 测「果」（报表可观察的已实现结构），Q2 测「因」（守住它的屏障）。判例：宁德时代"垄断了价值量最大的电池模块"计入 Q2=84；Q1 只看已实现结构（现金流大于净利、对整车厂负营运资本，但单价通缩、千亿维持性开支、客户强势）=74。该边界使 Q1⊥Q2（ρ=0.178），是两者能分别承担地板与主判据的前提。

**维度分档锚点**（四维共用）：95-100 极致（市场中定义级）｜90-94 卓越｜80-89 优秀｜70-79 良好｜60-69 及格｜<60 构成实质缺陷。

**报表可信度扣分（0 ~ −15，只扣不加）**：Q1-Q4 建立在"报表是真的"这一前提上，本项为该前提定价——经营现金流长期显著低于净利润、应收/存货/商誉异常膨胀、有息负债与现金流错配、资本开支长期不兑现、会计政策粉饰迹象。干净报表 = 0（本分，不加分）。坐实的造假/资金占用按 §5.4.7 判 `garbage`。

## 5. 参考分（展示项）

**参考分 = Q1×0.25 + Q2×0.40 + Q3×0.20 + Q4×0.15 − 报表可信度扣分。**

即 v0.4 的四维合成分原样保留。它在定档岗位上因方差收缩而失败（§2.2），但**档内排序正是它胜任的工作**——需要的恰恰是用上全部信息的平滑序。

**用途与边界**：

- **用途**：同档内排序，供用户判断建仓档位（重仓/轻仓）与所需安全边际的深浅。同属 L1，茅台 90.2 与盐湖股份 73.1 相差 17.1 分，这个差异是真实且应当被看见的。
- **边界（硬性）**：参考分**不是规则**。§13 明确规定单票建仓金额由用户逐票决定，系统只提供事实、不代为定档；本项同样只作展示，**不得据此自动assign仓位档、不得据此改变矩阵资格、不得据此发出买卖指令**。它是用户判断的输入，不是判断本身。

档内跨度（261 家实测）：L1 71.3-90.2（σ 4.09）｜L2 62.4-80.4（σ 3.26）｜L3 48.7-70.2（σ 5.20）。

## 6. 旗标

| 旗标 | 记录内容 |
| --- | --- |
| `replication_fail` | 资本复制测试不通过 → 直接判 L3。**只记录，不裁决名单归属**（D-21）——是否移出 `worth_attention` 由独立的 attention 扫描决定 |
| `erosion_path` | 2-3 年内可见侵蚀路径（写明路径/概率/影响）。中/高概率即排除 L1 |
| `dominated` | 被更强同行全面覆盖且无不可替代利基 → 直接判 L3 |
| `short_board` | Q1 或 Q2 塌陷（<60），或 Q1 地板不满足 |
| `strategic_asset` | 国家战略不可替代角色，需求/生存/资金被政策承保。允许**书面化 anchor_override**（档位可高于规则所示，理由与对照留痕）；分数与规则判定本身不因此调整 |
| `governance_open_issue` | 治理/披露存在未澄清事项 |
| `special_advantage_check` | **强制字段**：是否存在非标准载体的难复制优势（特殊治理/战略角色/章程承诺/事实标准），计入了哪个维度。防漏检，不产生独立加分 |

## 7. 评分对象与硬约束

1. 只对 `attention_class = worth_attention` 的公司评分。
2. **评级不改变名单归属**（D-21）：本流程只输出档位与分数，不移出 attention list。
3. **打分无下界**（D-19）：允许任意客观低分，不向任何及格线锚定。
4. **当前股价、估值、市值、指数权重、流动性、当前行业景气度、当前盈利周期位置，不进入任何维度。** 利润率与现金流判断一律用穿越周期的结构属性。行业只以"这门生意的结构性质量"（Q1）与"结构性空间"（Q3）形式进入，不以景气度形式进入。
5. **逐票人工评分、证据驱动**：年报/公告/问询与监管文书/投资者关系材料/权威研报。聚合站简介只作线索。**禁止关键词脚本自动打分**。
6. 每个维度、每项扣分、每个旗标、每次定档都必须写理由与来源。
7. **档与分数只在质量复核时凭新证据变更**，不得随价格或买入意愿变动。「无新证据的调分/调档」纳入 §15.1 拦截清单。
