## 1. 结构性结论（历轮校准的证据，约束后续修订）

1. **护城河本身是一维指标。** 复制门槛/持久性/地位/宽度/深度任意两两相关 0.86-0.96。护城河作为单一维度（Q2），持久性以带内方向修正并入。
2. **优质程度是多维的。** 生意模式/护城河/资本配置/管理层四侧面平均绝对相关 ~0.42，且存在真实公司在一维高另一维低。侧面相关是正常的，同一概念换名才是缺陷。
3. **维度命名会系统性污染打分。**「持久性」平行打分与门槛共线 0.93，改带符号趋势后降至 0.56；「成长」把长江电力 Q3 锚到 62。命名必须中性于路径。
4. **加权平均压缩顶部是事实，但解法在定档不在打分。** 分数是测量，档位是决策。
5. **调整项存在性检验**：必须携带维度不含的信息。卓越加成（维度分的函数）删除；特殊优势（与 Q2 问句同义）并入 Q2；可信度扣分（为「报表是真的」定价）保留。
6. **排序对权重稳健，结构对档位线敏感。** 34%→40% 的 Q2 权重变化不改变顶部/尾部/书架的成员构成，只微调书架内次序。

## 2. 评分对象与硬约束

0. **打分与定档解耦（2026-07-30 用户指令）**：评分阶段只输出分数、理由与旗标，不输出档位；档位线、及格线、短板阈值属于定档阶段。打分时不得参照期望档位反推分数。
0.5 **打分无下界（2026-07-31 用户指令）**：分数是无约束的客观测量——`worth_attention` 名单内的公司也允许打出任意低分（30 分亦可），不得向「及格线 60」锚定。
0.6 **评级不改变名单归属（2026-07-31 用户指令，D-21）**：评级流程**只输出档位，不移出 attention list**。L5 是保留档而非剔除档；名单的进出由**独立的 attention 扫描**负责。低分或命中旗标只作为该扫描的输入线索，不在本流程内执行剔除。
1. 只对 `attention_class = worth_attention` 的公司评分。
2. **当前股价、估值、市值、指数权重、流动性、当前行业景气度、当前盈利周期位置，不进入任何维度。** 利润率与现金流判断一律用穿越周期的结构属性，不用 TTM 水平。
3. **逐票人工评分、证据驱动**：年报/公告/问询与监管文书/投资者关系材料/权威研报；聚合站简介只作线索；禁止关键词脚本自动打分。
4. 每个维度、每项扣分、每个旗标都必须写理由与来源。
5. **分数带不是配额**（ADR-0006 决策 3）。

## 3. 四个维度（权重 2026-07-30 用户裁决后定为 25/40/20/15）

| 维度 | 权重 | 核心问句 |
| --- | ---: | --- |
| **Q1 生意模式质量** | 25% | 这家公司**已实现的赚钱方式**，其经济学结构好不好？ |
| **Q2 护城河强度与持久性** | **40%** | 这套经济学结构**凭什么守得住**？门槛多难越、在变宽还是被填平？ |
| **Q3 资本配置与股东回报** | 20% | 公司把每一块留存利润变成了多少股东价值？ |
| **Q4 管理层与企业文化** | 15% | 掌舵的人诚实吗、有能力吗、和股东站在一起吗？ |

**权重理由（v0.4 调整）**：本标准从护城河单因子演化而来，护城河仍是论点存活率的第一预测因子，Q2 应当支配（40%）而非与 Q1 接近平分（v0.3 的 34/28）；Q4 取最小权重符合「烂生意会赢过好管理」的排序。**上限约束**：Q2 不得超过 ~50%，否则退化回已被证伪的 v0.1 单因子。稳定性验证见 §1 第 6 条。

### 3.1 Q1 与 Q2 的因果边界（2026-07-30 用户确认，D-10 关闭）

- **Q1 测「果」**——已实现的经济学结构，报表可观察：需求是否重复、预收还是应收、毛利结构、维持性资本开支强度、单价长期趋势、客户集中与议价力、周期敏感度、现金转化。
- **Q2 测「因」**——守住结构的屏障，载体无关：品牌/产区/牌照/技术/工艺/认证/网络效应/切换成本/规模/生态/特殊治理结构/**战略角色**。评强度（不可买要素+不可压缩时间）、覆盖度、方向（侵蚀路径概率与影响；变宽取带内上沿、被填平取下沿、中/高概率明确侵蚀降一带并记旗标）。
- **判例**：宁德时代——垄断地位计入 Q2（84）；Q1 只看结构（现金流大于净利、负营运资本 vs 单价通缩、千亿维持性开支、强势客户）→74。茅台 Q1=98（先款后货/零应收/91% 毛利/近零维持开支）。**生意与生意不同，正是本维度要测的。**
- 备选口径（Q1 含已获竞争位置，段永平式公司级模式）已否决：会使 Q1/Q2 共线回升至 ~0.9。

### 3.2 Q3 资本配置与股东回报

与增长无关，只与**留存资本的去向与效率**有关，两条平行路径等价：**再投资路径**（存在高回报再投机会且历史再投回报被验证）；**返还路径**（缺乏机会时通过分红承诺与兑现、回购注销高效返还）。扣分情形：现金长期低效闲置、多元化毁灭价值、下行周期逆势高开支且回报未验证、增发摊薄无对价。

### 3.3 Q4 管理层与企业文化

诚信与披露记录、对中小股东的历史行为、承诺兑现率、激励一致性、关键人依赖与接班、文化跨周期一致性。与 Q3 边界：Q3 看资本配置的客观结果（数字），Q4 看人的行为与取向（定性）。

### 3.4 周期股、成长股、爆发股

不设单独通道：成长/爆发股的空间与份额路径在 Q3 再投资路径表达，低门槛增长被 Q1/Q2 诚实压低；周期股商品化生意在 Q1 诚实低分，资源禀赋/成本曲线优势由 Q2 承担；周期定价留在估值层策略标签 F。

### 3.5 成长性的归属（2026-07-30 用户裁决）

**增速归估值，跑道归质量。**

- 质量层只收 **Q3 再投资路径**：可按高回报再投的空间（跑道 × 回报率），公司层面的慢变结构事实。
- **行业增长率、未来 2-3 年增速预期、渗透率斜率，一律归估值层**——PEG 的 g、D 档 bull case 本就在为其定价。

三个理由：

1. **防双重计分**：增长若既抬质量档（放宽可买授权）又抬合理价带，成长股被奖励两次。
2. **快慢变量分离**：质量分是慢变量（仅凭新证据变更）；增速预期是最不可靠的快变量——OI-001 判例：2026 存储一致预期数月内偏差 25%~51%。快变量不得进入慢变量。
3. **与 §5.7.1 规则 1 对称**：「行业增长走弱不降质量档」已是既有原则，反向「行业火热不抬质量档」必须同样成立。

### 3.6 维度准入检验（增维的裁决规则，2026-07-30 设立）

新维度必须同时满足三条：①**独立信息**——存在真实公司在该维度与现有维度显著分化；②**普适性**——对池内多数公司有意义；③**性质合格**——是质量水平，不是有效性前提（→扣分项）、不是价格量（→估值层）、不是行为约束（→旗标）。

已审查候选（全部不设维）：

| 候选 | 信息已在 | 落选原因 |
| --- | --- | --- |
| 成长性/行业增长率 | Q3 跑道 + 估值层 | §3.5 三理由 |
| 盈利可预测性/确定性 | Q1（复购、周期敏感）+ Q2（地位稳定） | 无独立来源，必然共线 |
| 市场地位/竞争格局 | Q2 | v0.1 已证相关 0.87 |
| 财务质量 | 扣分项 | 有效性前提，不得与质量平均 |
| 治理 | Q4 + `governance_open_issue` | 管理层行为的子集 |
| 战略意义 | Q2 载体 + `strategic_asset` 旗标 | 适用面 <5%，设维对其余公司是纯噪声 |
| 规模/抗风险 | Q1 结构 + 脆弱性扣分 | 两头已覆盖 |
| 估值/便宜程度 | 永不进入 | 质量与价格分离是第一原则 |

## 5. 报表可信度与财务脆弱性扣分（0 ~ −15，只扣不加）

Q1-Q4 建立在「报表是真的、资产负债表撑得住」的前提上；本项为该前提定价。可信度不能与质量互相平均，故独立、单向。与 Q4 边界：Q4 判断人（定性），本项是账面可机械核验的红旗（定量绊线，防叙事俘获）。

| 红旗 | 扣分参考 |
| --- | ---: |
| 经营现金流长期显著低于净利润（剔除合理成长性占用） | −3 ~ −8 |
| 应收/存货/商誉相对收入异常膨胀 | −2 ~ −6 |
| 有息负债结构与现金流错配（公用事业型匹配长债不扣） | −2 ~ −6 |
| 资本开支长期不兑现为收入或回报 | −2 ~ −5 |
| 会计政策变更、非经常性损益占比高、复杂关联交易 | −3 ~ −10 |

干净报表 = 0（本分不加分）。坐实造假/资金占用/审计异常按 §5.4.7 判 `garbage`。

## 6. 旗标（定档阶段使用，打分阶段只记录）

| 旗标 | 记录内容 | 定档阶段的预期用法（待定） |
| --- | --- | --- |
| `replication_fail` | 资本复制测试不通过 | **只记录，不裁决名单归属**（D-21）——是否移出 `worth_attention` 由独立的 attention 扫描决定，评级流程无权改变名单 |
| `short_board` | Q1 或 Q2 <60 | 不得进前二档（阈值定档时确认） |
| `dominated` | 被更强同行全面覆盖且无不可替代利基 | 压至低档 |
| `erosion_path` | 2-3 年内中/高概率可见侵蚀路径（路径/概率/影响） | 顶档一票否决 |
| `strategic_asset` | **战略资产（2026-07-30 新增）**：国家战略不可替代角色，需求/生存/资金被政策承保 | 允许**书面化 anchor_override**——档位可高于分数所示，理由与对照留痕；分数本身不因此调整 |
| `special_advantage_check` | 强制字段：是否存在非标准载体的难复制优势、计入了哪个维度 | 防漏检 |
| `governance_open_issue` | 治理/披露未澄清事项 | 压档 |

**`strategic_asset` 的设计边界**：战略意义在投资意义上兑现为需求承保、生存承保、垄断位置三件事，**这三件全部在 Q2 载体内计分**（中芯国际 Q2 由 80 重校至 85 即此）；分数之外的战略考量（组合层面愿意为战略资产保留观察/持仓资格）通过本旗标在**定档决策层**显式生效。测量与决策分离，两边都留痕。

## 9.4 全池 261 家打分完成（2026-07-31）

全部 worth_attention 公司已按 v0.4 口径打分，物化为 `data/processed/a_share_quality_scores_v2.csv`（14 个同业批次 B1-B14 + anchor）。**性质仍为模型知识口径校准，正式落库前须按 §2 逐票证据复核。**

**分布**：n=261，均值 70.66，中位数 71.10，**σ 仅 5.16**，极差 90.15-48.70。分位数 P25=67.6 / P50=71.1 / P75=73.8——**中间 50% 只跨 6.2 分**。

### 9.4.1 三个方法级发现（推翻了 §9.3 的划线依据）

**① 断层划线在全样本上不成立。** 相邻分数差 >2 的间隙**全部位于头部 4 家与尾部 7 家**；主体（62-78 分区间，约 245 家）最大间隙仅 **0.90**。§9.3 在 42 家锚点样本上观察到的"书架与断层"是**稀疏采样的假象**——样本一密集，断层即消失。任何一条线都必然落在密集簇中间。

**② 压缩不是聚合方式造成的，是总体本身就密集。** 加权平均把 σ 从 5.88（四维 σ 均值）压到 5.16，**只压缩了 12%**；改用几何平均得到 σ 5.19，几乎无差别。也就是说 §1.3 担心的"加权平均压扁顶部"在此**不是主因**——真实原因是这 261 家全部通过了严格的 worth_attention 初筛，**本来就是一个同质化群体**。

**③ §6 的短板封顶一次都没生效。** Q1 或 Q2 <60 的 26 家，加权分**本就全部 ≤69**；Q1 或 Q2 在 60-69 的 134 家，本就全部 ≤79。封顶规则与算术结果完全重合，形同虚设——它想做的事（惩罚单维塌陷）加权平均已经顺带做掉了一部分，但做得**不够**（见下）。

### 9.4.3 唯一真正拉开分布的机制：短板惩罚

在同一批维度分上测试聚合方式，只有**短板惩罚**改变了离散度：

| 聚合方式 | σ | 极差 |
| --- | ---: | --- |
| 加权平均（现行） | 5.16 | 48.7 - 90.2 |
| 几何平均 | 5.19 | 48.6 - 89.7 |
| **加权平均 × min(1, 最低维/70)** | **9.11** | 27.9 - 90.2 |

它不只是数学上有效，**在原则上也正是本细则 §1.3 已确立的立场**（价值投资要的是"有极致长板、且无致命短板"，不是均衡的中庸）。§6 的二元封顶是这条原则的粗糙实现且已被证明零生效；连续的短板因子是它的正确形式。

受影响最大的公司也印证了方向：京东方A 51.1→27.9（最低维 Q1=40）、TCL科技 54.3→31.4、牧原股份 64.9→47.2（Q1=52）、中芯国际 67.2→52.4（Q1=55）。**顶部完全不受影响**（茅台、长电、五粮液、泸州老窖、福耀、北华、金山办公次序不变），因为它们没有塌陷维度——这正是短板惩罚应有的行为。
