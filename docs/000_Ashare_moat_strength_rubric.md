# A 股公司优质程度评分细则（分层 v2 定档用）

- **状态**：设计中，**未生效**。生效前标准仍为 `docs/000_Ashare_workflow.md` §5.7/§5.7.1。
- **用途**：为分层 v2（L1-L5）提供**唯一定档依据**。设计背景与三态矩阵见 `docs/000_Ashare_tiering_v2_design.md`。
- **与 `docs/moat-scoring-rubric.md` 的关系**：那份是港股/美股全覆盖用的七维综合分，继续服务 `run_hong_kong_full_coverage_scoring.py` / `run_us_full_coverage_scoring.py`，本文件不取代它，两者不可互相换算。
- **口径演进**：本文件初稿（2026-07-30）曾按"纯护城河强度分"设计，经校准证伪后改为**公司优质程度多维分**，理由见 §1。

## 1. 三次校准得到的结构性结论

### 1.1 护城河本身只是一维，多维护城河模型是幻觉

以 7 家试算样本检验维度间相关性：

| 结构 | 相关系数 |
| --- | ---: |
| 复制门槛 vs 持久性 | **0.929** |
| 复制门槛 vs 市场地位 | **0.867** |
| 深度 vs 宽度（改版尝试） | **0.962** |

三者近乎共线，**给它们分配不同权重是自欺**——实际只有一个因子在起作用。护城河应当作为**单一维度**处理。

唯一有效的拆分是把**持久性由平行的水平分降级为带符号的趋势调整**（相关性由 0.929 降至 0.559）：深度是水平量、持久性是变化率，前者问"有多强"、后者问"在变强还是变弱"。若两者都放在 0-100 的好坏标尺上，打分者必然锚定同一个整体印象。本细则据此把持久性并入护城河维度内部，作为方向修正。

### 1.2 优质程度是多维的

改用优质程度的不同侧面（生意模式、护城河、成长与资本再配置、管理层与文化）后，**平均绝对相关降至 0.42**。判据是"是否存在真实公司在一个维度高、另一个维度低"，样本中确实存在：长江电力护城河极强而生意模式受管制、宁德时代成长空间大而生意模式重资产、海大集团管理层口碑好而生意模式门槛低。**侧面之间的相关是正常的，同一概念换名才是缺陷。**

样本中出现 Q1 生意模式与 Q5 管理层 **-0.39** 的负相关，与巴菲特的经典观察方向一致：好生意不需要好管理，烂生意才要靠管理硬撑。这说明管理层维度携带独立信息。

### 1.3 纯加权平均会重演「胖中间」，必须加非线性项

5 维加权后，7 家样本中有 4 家挤在同一档（76-84）。加权平均在数学上就是让长板与短板互相抵消，结果是"茅台式的极致"和"样样 80 分"得到同一个分数——**这正是当前 L2 占 61% 的病根在新尺子上换形式复发**。

而本体系所依据的价值投资传统（巴菲特后期、芒格、段永平）要的是**有极致长板、且无致命短板**，不是均衡的中庸。因此聚合方式必须是「加权分 + 卓越加成 − 脆弱性扣分 + 封顶」，不能是纯加权平均。

### 1.4 财务维度作为正向加权是重复计分

财务质量与生意模式相关 0.89（重定义后仍 0.89）——好生意必然表现为好财务。作为正向加权维度它只是生意模式的影子。但**反向信息是独立且关键的**：一门好生意配一张脏报表，是真实且致命的情形。因此财务改为**单向扣分项**：干净是本分、不加分；脏了必须扣。

### 1.5 权重不敏感，档位线敏感

三组权重变体（25/30/15/15/15、25/35/13/13/14、30/35/12/11/12）下 7 家的**排序完全不变**，只有边界名次换档。结论对权重稳健，不必在权重上过度纠结；真正需要谨慎的是档位线的位置。

## 2. 评分对象与硬约束

1. 只对 `attention_class = worth_attention` 的公司评分。
2. **当前股价、估值、市值、指数权重、流动性、当前行业景气度、当前盈利周期位置，一律不进入任何维度。** 行业只以「这门生意的结构性质量」和「结构性成长空间」的形式进入 Q1/Q3，不以景气度形式进入——§5.7.1 规则 1 的既有立场（行业增长弱只记估值与仓位备注、不降质量档）继续有效。
3. **必须逐票人工评分、证据驱动**：年报/半年报/季报、公司公告、交易所问询与监管文书、投资者关系材料、权威研报。聚合站/F10 简介只作线索不作证据。**禁止关键词脚本自动打分**（`moat-scoring-rubric.md` §11 的 v0.3 校准注记已确认这是 A 股高分人口虚高的机械成因）。
4. 每个维度、每项加成与扣分都必须写出理由与来源；无理由的分数与加减分视为无效。
5. **分数带不是配额**（ADR-0006 决策 3）。§8 的金字塔形状只作校准自检。

## 3. 加权维度（四维，合计 100%）

| 维度 | 权重 | 核心问句 |
| --- | ---: | --- |
| **Q1 生意模式质量** | 28% | 这**本身**是不是一门好生意？需求可否重复、有无定价权、维持竞争地位是否需要持续的高资本开支/价格战/补贴/不断创新求生、现金转化是否天然良好、客户是否分散 |
| **Q2 护城河强度与持久性** | 34% | 门槛有多难越（不可买的要素 + 不可压缩的时间，**载体无关**：品牌/产区/牌照/技术/工艺/认证/网络/切换成本/规模/生态一视同仁）、覆盖公司多大比例的利润、能否被绕过；以及**这条河在变宽变深还是在被填平**（未来 2-3 年侵蚀路径的概率与影响） |
| **Q3 成长空间与资本再配置** | 20% | 长坡厚雪：市场空间、渗透率、份额提升路径、再投资回报率；**若无坡，则看资本能否被高效返还**（回购注销、稳定高分红），而非任其在账上闲置或投向低回报项目 |
| **Q4 管理层与企业文化** | 18% | 资本配置记录（并购成败、扩产纪律、逆周期能力）、诚信与披露质量、股东导向、承诺兑现率、关键人依赖与接班安排 |

设计说明：

- **Q2 权重最高（34%）**且内部已吸收持久性与宽度——§1.1 已证明它们无法独立成维。载体无关是必须的：若单列「技术壁垒」并给高权重，护城河最不可撼动的资源垄断型公司会因「技术含量不高」被系统性降档。
- **Q1 与 Q2 合计 62%**，构成核心。这是段永平「商业模式第一」与巴菲特「持久竞争优势」的合并表达。
- **Q3 双路径**（再投资 OR 资本返还）是关键设计：否则现金牛型公司会因「没有成长」被判低质量，重演 §1 所说的失真。
- **Q4 保留独立权重**是因为样本显示它与 Q1 负相关、携带独立信息；段永平体系中企业文化仅次于商业模式。

### 3.1 周期股、成长股、爆发股的处理

不为它们设单独通道，也不降低标准：

- **成长股/爆发股**的市场空间、渗透率与份额提升在 **Q3** 得到正面表达；但若其增长依赖低门槛扩产、广告投放、渠道铺货或易被复制的产品，**Q1 与 Q2 会诚实地压低**——这正是 CLAUDE.md「不因低门槛高增长而给高质量档」的要求。
- **周期股**在 Q1 上通常得分不高（这是诚实的：商品化生意本身较差），若其真实优势在于不可复制的资源禀赋或成本曲线位置，则由 **Q2** 承担；仍不足以体现的，走 §5 特殊优势。周期定价问题在估值层由策略标签 F 处理，不在质量层补偿。

## 4. 维度分档锚点（四个维度共用）

| 带 | 分数 | 含义 |
| --- | ---: | --- |
| 极致 | 95-100 | 该维度上属于市场中定义级的存在，很难想象更好 |
| 卓越 | 90-94 | 明显优于行业最好的一批，且差距可被证据支撑 |
| 优秀 | 80-89 | 稳居行业前列，但相对最强者有可指出的差距 |
| 良好 | 70-79 | 达标且有可取之处，但不构成竞争优势的来源 |
| 及格 | 60-69 | 勉强达标，该维度是弱项 |
| 不合格 | <60 | 该维度构成实质缺陷 |

Q2 的持久性读法：河在变宽变深 → 取该维度带内上沿；稳定 → 中值；缓慢被填平 → 下沿；有中/高概率的明确侵蚀路径 → 降一带并触发 §6 封顶。

## 5. 非线性调整项

### 5.1 卓越加成（奖励极致长板）

| 条件 | 加分 |
| --- | ---: |
| 每有一个维度 ≥95 | +2 |
| 每有一个维度 90-94 | +1 |
| 上限 | **+6** |

目的是抵消加权平均对极致的稀释（§1.3）。它使「一项定义级优势 + 三项良好」优于「四项优秀」，与价值投资传统一致。

### 5.2 特殊优势加成（补偿通用维度捕捉不到的优势）

**上限 +6。** 用于「通用维度评分一般，但具备特殊的、很难复制的优势」的公司。必须命中下列枚举类别之一，并附证据：

| 类别 | 说明 |
| --- | --- |
| 物理唯一的资源、区位或法定牌照 | 不可再造的坝址/矿权/岸线/特许经营权 |
| 不可替代的国家战略角色 | 政策指定、安全自主可控体系中的唯一或极少数承担者 |
| 长期被验证的卓越资本配置 | 十年以上的回购注销、逆周期扩张、极低资本消耗下的高回报记录 |
| 特殊治理结构或企业文化 | 股权结构、长期激励或文化机制带来的跨周期一致性与低代理成本 |
| 事实标准或生态位 | 行业标准制定者、被写入客户设计规范或认证体系 |
| 极端客户切换成本 | 更换供应商需重新认证数年、或涉及安全/合规不可逆风险 |

**反双重计分（硬规则）**：必须书面说明**为什么这条优势没有被 Q1-Q4 计入**。若该优势已在任一维度得分中体现（例如品牌、产区、份额、专利），**不得再加**。

> 校准判例：初版试算给 7 家中的 5 家都加了特殊优势分，其中茅台的产区、宁德的份额与事实标准地位**本已计入 Q2**，属重复计分。加此规则后，同一样本中特殊优势应大多为 0。缺少该规则时，本项会退化为万能上调理由，摧毁可比性。

### 5.3 财务真实性与脆弱性扣分（单向）

**0 ~ −15，只扣不加。** 干净的报表是本分，不产生加分（§1.4）。

| 情形 | 扣分参考 |
| --- | ---: |
| 盈利质量差：经营现金流长期显著低于净利润 | −3 ~ −8 |
| 应收账款、存货、商誉相对收入异常膨胀 | −2 ~ −6 |
| 有息负债或短债压力与现金流不匹配 | −2 ~ −6 |
| 资本开支失控、投入产出长期不兑现 | −2 ~ −5 |
| 存在报表粉饰迹象（会计政策变更、非经常性损益占比高、关联交易复杂） | −5 ~ −10 |

坐实的造假、资金占用、审计异常不在此列——按 §5.4.7 判 `garbage`，不进分层。

## 6. 封顶与一票否决（只压不抬）

按顺序施加：

| 触发条件 | 封顶 | 依据 |
| --- | ---: | --- |
| **资本复制测试不通过**（资金充足者可较快复制并侵蚀回报） | 总分 ≤59，**出 `worth_attention`** | ADR-0006 决策 3；D-6 |
| **短板封顶**：Q1 或 Q2 <60 | ≤69（最高 L5） | 核心维度存在实质缺陷者不得靠其余维度平均上来 |
| **短板封顶**：Q1 或 Q2 在 60-69 | ≤79（最高 L4） | 同上 |
| 被更强同行**全面覆盖**且无独立不可替代利基（Dominance Rejection Test） | ≤69 | `CONTEXT.md`；`moat-scoring-rubric.md` §10.1 |
| Q2 前瞻侵蚀检验发现 2-3 年内**中/高概率**的可见侵蚀路径 | ≤91（不得进 L1） | L1 语义要求「几乎不可颠覆」 |
| 现金流结构性恶化（非周期性）或治理/披露存在未澄清实质问题 | ≤79 | §5.8 步骤 6 |
| 行业本身正在结构性消亡 | ≤69 | 行业只能压档、不得抬档 |
| 财务造假、控股股东资金占用、审计异常等坐实问题 | 不进分层 | §5.4.7 判 `garbage` |

## 7. 分数 → 档位

总分 = 四维加权分 + 卓越加成 + 特殊优势加成 − 财务脆弱性扣分，再施加 §6 封顶。区间**左闭右开**，分数保留两位小数。

| 档 | 区间 | 语义（按优质程度重述） |
| --- | --- | --- |
| L1 | [92, 100] | **极优**：生意模式、护城河、成长/资本配置与管理层全面卓越，且至少一项达到定义级；几乎不可颠覆 |
| L2 | [84, 92) | **优秀**：核心维度很强、很难颠覆，个别维度有明确但不致命的短板 |
| L3 | [76, 84) | **良好**：整体扎实、护城河比较牢固，但某个核心维度存在实质缺陷 |
| L4 | [68, 76) | **及格偏上**：有可取之处、护城河比较稳固，但多个维度平庸 |
| L5 | [60, 68) | **及格**：有一定护城河，勉强达到值得关注的底线 |
| — | <60 | 不保留在 `worth_attention`，降为 `boundary_pending` |

> **档位定义已由护城河语义改为优质程度语义。** 用户原始定义（L1「极强、几乎不可颠覆的护城河」等）是纯护城河表述；既然定档分改为优质程度综合分，档位定义必须同步改写，否则会出现「按分数是 L1、按定义不是几乎不可颠覆」的自相矛盾。护城河仍是权重最高的单一维度（34%），语义上的主导地位不变。

### 7.1 为什么改等宽 8 分

原定 95/90/80/70/60 的带宽为 5/5/10/10/10。改为等宽 8 分的理由：

1. **稀缺性应来自打分尺度的难度（锚点、封顶、定性闸门），而非档位几何。** 窄顶档只是在已经很难的尺子上再加一道任意门槛。
2. **窄顶档在风险最高处放大噪声。** 顶档决定「较高估还能不能持有」这类授权，噪声代价最高；等宽让每档有相同的噪声容忍度。
3. **校准证据**：按本细则的分数量级，原档位线会把全池最强锚点茅台判到 L2。

### 7.2 定性闸门（算术达标不等于定档）

- **L1 三条缺一不可**：①资本复制测试**完全通过**（行业公认级）②未来 2-3 年**无中/高概率的可见侵蚀路径** ③与现有 L1 锚点双重对照不落下风。任一不满足，算术达标也定 L2。
- **L2 两条**：①资本复制测试通过 ②侵蚀路径存在但概率低或影响可控。
- **特殊优势加成使总分跨档时**，必须附锚点双重对照并写入 `tier_reason`。

### 7.3 边界规则

总分落在任一档界 **±1 分**以内时，必须执行 §5.7.1 规则 6 的锚点双重对照，结论写入 `tier_reason`。

### 7.4 分数变更纪律

质量分**只在 §7.2 质量复核时变更，且必须有新证据**。与估值档位（按 §6.2.1.6 每日随价格自动重定）性质不同，质量分不得随价格或买入意愿变动。「无新证据的分数调整」应纳入 §15.1 拦截清单。

## 10. 待校准项

1. **四维权重 28/34/20/18 需用户确认。** §1.5 已证排序对权重稳健，但边界名次会变。
2. **卓越加成上限 +6、特殊优势上限 +6、财务扣分下限 −15** 三个幅度是初始校准值。三者合计可使总分移动 −15 ~ +12，足以跨两档，是本细则弹性最大的部分。
3. **特殊优势能否直接把公司送进 L1**：现行草案允许（只要求附锚点对照）。若认为顶档必须由通用维度硬达标，需加一条「加成后不得进入 L1」。
4. **锚点公司名单**：正式定尺需要 10-15 家，覆盖不同护城河载体（品牌型、资源型、牌照型、技术型、网络型、认证型）与不同策略类型（现金流复利、成长、爆发、周期、股东回报）。由用户确认后先打分定尺，再批量。
5. **L1 是否允许为空**：若某轮评分下无人达 92，是否可接受空档。
