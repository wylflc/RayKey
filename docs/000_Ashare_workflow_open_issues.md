### OI-204｜模型假设｜超额回报衰减只作用于新增资本（P1）

### OI-202｜文档｜§6.5.1 未写明增速腿权重为 0（P3）

证据：§6.5.1 写“g0 取资本腿与利润增速腿之大者”，但生产命令 `--roic-trail-weight 0` 使利润腿恒为 0（`build_historical_valuation_bands.py:2156`）。§6.5.2.4 的 `trend` 模式乘同一权重，生产中与 `none` 等价。`roic_g_source` 在 g0 = 0 时标为 `trailing`（如美的）；五粮液 README 写“两腿皆不可算”。影响：按文档理解估值会误判增长来源。动作及完成条件：§6.5.1 与 §6.5.2.4 写明现行权重及 `trend` 的实际效果；标签与 README 措辞改为如实反映；文档审计通过。

### OI-201｜缺陷｜超额现金口径与 NOPAT 中的利息收入不一致（P2）

证据：超额现金 = 货币资金 + 交易性金融资产 − 2% 营收（`roic_inputs.py:225`）；拆出资金、买入返售、债权投资、其他债权投资，以及列在其他流动资产、一年内到期非流动资产、其他非流动资产中的定期存款和大额存单都不计入。EBIT 含利息收入（`roic_inputs.py:213`）。茅台未计入的确定项净额约 945 亿（77.7 元/股，V 的 13%）；美的、金山办公的存款类三行约 29.5、31.5 元/股（V 的 50%、70%，构成待核）。利息收入占 EBIT：五粮液 22%、格力 16%、美的 15%、伊利 15%。影响：已计入的现金经利息资本化被重复计价；未计入的存款只按约 20% 面值计价；现金厚的优质公司 V 被系统性压低。动作及完成条件：先按附注核实主要公司的存款构成；定义现金类科目及财务公司吸收存款的扣减；EBIT 剔除利息收入；按 §12.1 轨道 A 验证。

### OI-200｜缺陷｜类金融公司按一般企业估值，东方财富客户资金计入超额现金（P1）

证据：东方财富使用一般企业报表模板，因此走 ROIC 路径。2025 年报超额现金 2,334.7 亿（货币资金 + 交易性金融资产），是归母权益的 2.5 倍；代理买卖证券款、卖出回购、应付短期融资款、拆入资金合计 2,298.8 亿，未计入有息负债。投入资本为负，退回零增长；券商负债使 WACC 降到 7.15%。现 V 25.96 = 经营价值 13.04 + 净现金 12.93，P/V 0.72；把上述负债计入后约 1.79，按权益口径约 1.32–1.48。影响：该股每天在 P/V 前十，走势一旦达标就进入买入清单（09-23 收盘 18.65 < MA20 18.81 < MA60 19.51）。动作及完成条件：以代理买卖证券款、结算备付金、融出资金等科目识别类金融公司并路由权益口径，或把上述负债计入有息负债；修复前该股若进入买入清单，由用户决定是否执行（§1 第 4 条）；复核全市场同类公司；按 §12.1 轨道 A 验证。
