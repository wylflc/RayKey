## 1. 核心原则

本体系的定位是：

```text
价值投资底层 + 产业趋势增强 + 右侧交易执行 + 仓位风险预算。
```

基本执行原则：

```text
研究决定买什么。
右侧信号决定何时买。
风险预算决定买多少。
thesis 是否变化决定加仓、减仓或清仓。
成本价不能决定任何持仓动作。
```

目标不是永远满仓，也不是永远长期持有，而是在控制永久性亏损和杠杆风险的前提下，集中持有少数高质量、高景气、高赔率或深度低估资产。

最高优先级规则：

```text
如果买入 thesis 被证伪，或者财务质量、治理结构、行业逻辑出现重大破坏，可以并且必须清仓。
```

观察池最高优先级规则：

```text
观察池必须严进宽出。
宁可错过普通机会，也不要把低壁垒、低确定性、估值不够便宜的公司放进长期观察池。
```

“值得研究一次”和“值得长期观察”必须分开。很多公司可以被分析、理解、排除，但不应因为业务有增长、股价下跌、题材顺眼或短期有反弹可能，就进入观察池。

## 2. 账户结构

### 2.1 建仓口径（v1.21 由「重仓/轻仓二档」改为定投档）

**单次买入 = 当日净资产 N × 0.5%**，每日重算，同一标的每个合格日买一档，直至不再合格。

- **不存在「建仓金额」这个量**，也不存在重仓/轻仓定档动作——**仓位大小是合格日次数的结果，不是事先的判断项**。
- 500 万本金下一档 = 2.5 万元。一手金额超过一档的标的按工作流 §9.7.3 每次买一手、间隔 5 个自然日。
- **单票上限 = 净资产 20%**（工作流 §9.7.1，v4.00 由 15% 改，用户 2026-08-16 裁定；口径与下方结构上限的「主动/被动」一致，只挡加仓）。**持仓只数无上限**。分散度由相关性 ≤0.85 与本条共同承担。
- 依据：定投档 vs 一次性建仓五起点全正 +7.5pp；放大到 1%/2% 收益无改善而回撤 33.7%→47.5%。

**总仓位口径**：总仓位 = 持仓市值 ÷ 净资产 = 杠杆 × 100%；**常态中枢 130%，浮动带 100%-160%**——高于 160% 必须减仓/去杠杆，低于 100% 由 §9.7 的合格集自然回补。行业/产业链结构占比按持仓市值计（杠杆中性）。

**结构上限（按持仓市值，仍为硬约束）**：

| 规则 | 上限 |
| --- | ---: |
| **单只股票·机械买入线** | **20%**（工作流 §9.7.1，v4.00 由 15% 改；回测落点 `--position-cap 0.20`） |
| 单只股票绝对红线 | 30%（账户级外层约束，**买入侧已被上一行 20% 先挡住**，故只可能被上涨被动突破） |
| 同一产业链合计暴露 | 40% |
| 同一大行业合计暴露 | 60% |
| 总仓位（=杠杆×100%） | 中枢 130%，带 100%-160% |

**主动/被动口径**：上限约束的是**主动增加的暴露**。新建仓或加仓后将越过任一上限 → 不得买；既有持仓**因股价上涨被动越限** → 不预警、不建议减仓，只保留"禁止再加仓"。**这一条与 §9.7 的机械买入相容**：机械规则本身不看结构占比，故结构上限是叠加在其上的账户级否决项，命中即跳过该标的、顺位补下一名。

单票接近 30% 红线时的持有资格复核（每越过一个 10 个百分点台阶复核一次）：

1. 公司财务健康。
2. 行业景气度向上。
3. thesis 有财报、订单、公告、产业数据支持。
4. bear case 已明确写出。
5. 下跌 30% 不会导致被动爆仓或心理崩溃。

### 2.2 观察池层级

| 层级 | 数量 | 含义 |
| --- | ---: | --- |
| 全量观察池 | 30-80 只 | 值得长期跟踪 |
| 重点观察池 | 10-20 只 | 近一个月最值得关注 |
| 准买入池 | 3-8 只 | 研究完成，等待触发 |
| 实际持仓 | 8-15 只 | 当前账户持仓 |
| 核心持仓 | 2-3 只 | 账户主要驱动 |

不要为了观察而买很多 1% 小仓位。观察主要通过观察池完成；战术持仓只用于已经出现触发信号的公司。

观察池入选必须至少满足以下条件之一：

1. 公司具有强护城河，资金充足的新进入者也难以在短期内复制、替代或战胜。
2. 公司处于关键产业瓶颈，供给稀缺、认证周期长、扩产难、客户替换成本高。
3. 公司拥有稀缺资源、牌照、成本曲线优势、网络效应、强品牌心智或不可轻易复制的渠道能力。
4. 公司估值进入深度低估，并且资产真实、现金流可验证、存在明确催化剂。
5. 公司是落难白马，但核心业务和护城河未被永久破坏，且已有右侧修复迹象。

以下情况默认不进入观察池：

1. 行业进入门槛低，新玩家只要有资金就可以较容易复制产品、渠道或产能。
2. 高利润会迅速吸引新玩家进入，导致利润率和增长难以长期维持。
3. 增长主要靠营销投放、渠道铺货、价格周期、出口景气或短期费用资本化，而不是长期竞争优势。
4. 公司只是“还不错”，但没有明显强于同业的不可替代优势。
5. PE 约 20-25 倍，但公司没有强护城河、强现金流、强复利能力或明确低估催化。
6. 只是股价跌多了、技术面可能反弹、短期业绩不错，但长期竞争力不足。

如果入选理由需要用很多假设才能成立，默认不入选。

## 3. 市场状态与总仓位

### 3.1 市场状态判断

按主要投资市场分别判断，例如 A 股看沪深 300，港股看恒生指数，美股看标普 500 或纳斯达克 100。

| 状态 | 判断标准 |
| --- | --- |
| 强势市 | 指数在 250 日线上方，250 日线向上，市场宽度改善，成交额放大，有清晰主线 |
| 弱势市 | 指数在 250 日线下方，250 日线向下，市场宽度弱，无持续主线 |
| 震荡市 | 既不满足强势市，也不满足弱势市 |

市场状态至少维持约 20 个交易日后再确认。市场状态只控制总仓位和进攻性，不直接强制清掉优秀个股。

### 3.2 总仓位区间

**「股票总仓位」一列自 v1.6（2026-07-14）起失效**，由 §2.1/§4.1 的杠杆包络取代（口径、中枢与带宽唯一见 §2.1，本节不重复）。原表是无杠杆口径，与现行包络的下沿直接冲突——现行体系下"降仓"指向向带内下沿收敛，不指向清仓到原表的弱势市区间。市场状态改为**收敛方向的触发条件之一**，判定与阈值见 §4.1 的杠杆风险提醒。

**「优先策略」一列仍然有效**：市场状态决定优先找哪一类标的。

| 市场状态 | 股票总仓位（**已失效，见上**） | 优先策略 |
| --- | ---: | --- |
| 强势市 | ~~75%-100%~~ | 产业链爆发、成长龙头、高景气核心 |
| 震荡市 | ~~45%-75%~~ | GARP、低估催化、股东回报、局部突破 |
| 弱势市 | ~~15%-45%~~ | 现金流复利、资源 NAV、稳态现金分配、深度低估 |

## 4. 杠杆规则

体系运行第一年禁用杠杆。满一年后，只有在真实记录证明回撤和纪律可控时，才允许使用。

### 4.1 杠杆包络（v1.00，与 000 工作流 §13 同步）

**本节为常设防护层。** 2026-08-03 曾提出删除杠杆包络、担保比例预警与融资棘轮并入 R7 冷静期，**同日经实测验算后用户撤销提案**（原话「取消删除，保留这些指标作为账户的安全防护机制」），冷静期终止、无待决事项。验算与撤销记录见 §17.10。**显示口径**：每日照常计算，常态不进每日报告，触及阈值当日提示一行。

常态中枢 1.3x（总仓位 130% 净资产），浮动带 1.0x-1.6x；**1.6x 为绝对上限，触及必须减仓/去杠杆**。弱势市禁用融资买入并向带内下沿收敛。杠杆 >=1.3x 期间 §17.3 R1 常态在线：一切买入必须有右侧信号或已核实催化剂——中枢以上不存在"无信号买入"。棘轮规则：融资买入的仓位止损/退出后，回笼资金必须先偿还融资，不得循环滚入下一笔买入。**杠杆风险提醒（v1.11，2026-07-27 起，取代原止损网格动态天花板）**：总仓位 >160% 发布警告并量化回带内缺口；出现 ①市场状态转震荡/弱势、②政策性风险事件（流动性收紧、股市降杠杆/两融规则收紧等，公告或官方文件级）、③持仓性价比下降（可买域收缩或持仓趋势走坏只数上升）中任一项，提醒收敛至中枢 130%；两项及以上同时成立、或自峰值回撤触及 -8%，提醒收敛至下沿 100%。阈值与判定口径唯一见 000 工作流 §13 第 5 条，本节不重复。原"实际杠杆天花板由止损网格预算动态决定"一句随网格撤销删除。

### 4.2 可加杠杆资产

只有以下资产可以考虑杠杆：

1. 流动性高。
2. 财务稳健。
3. 估值有安全边际。
4. 不依赖单一订单、单一客户、单一政策或传闻。
5. 没有明显财务红旗。
6. 压力测试显示组合下跌 25%-30% 也不会被迫平仓。

禁止对以下资产加杠杆：

1. 纯题材股。
2. 单一订单、单一客户、单一验证驱动的公司。
3. 还没有验证的高估值成长股。
4. 财务复杂的烟蒂股。
5. 周期顶部的周期股。
6. 短期已经暴涨数倍的股票。
7. 小盘低流动性股票。

## 5. 选股策略分类

每只股票买入前必须有一个主要策略标签。卖出规则跟随原标签，除非完成完整重估。

**分类轴（v1.16，与工作流 §6.5.0 同步）**：标签的唯一职能是**选出建带公式**，分类轴统一为「这家公司的价值主要由哪一个可计量的锚定量决定」。判定顺序与建带公式以工作流 §6.5 为唯一口径，本节只写入选标准、卖出/降级信号与判断要点。

| 代码 | 策略 | 最高层级 | 核心问题 |
| --- | --- | --- | --- |
| A | 现金流复利型 | 核心 | 不依赖乐观假设，能否长期复利？ |
| C | GARP 成长型 | 核心 | 增长是否真实、可持续、未被充分定价？ |
| D | 产业链爆发型 | 核心 | 是否处在真实瓶颈，并能转化为利润？ |
| E | 落难白马型 | 核心 | 困境是暂时的，还是护城河永久受损？ |
| F | 资源 NAV 型 | 核心 | 是可计量的储量优势 + 供给约束，还是普通周期 beta？ |
| H | 成本曲线周期型 | 核心 | 成本优势是否足以穿越整轮下行并在中枢价差下赚钱？ |
| J | 金融资本型 | 准核心 | 高 ROE 是真实定价能力，还是放松认定口径与加杠杆换来的？ |
| K | 稳态现金分配型 | 核心 | 分配现金是否可持续，且相对折现率仍有溢价？ |
| M | 管线/研发资产型 | 准核心 | 管线价值是否可按概率折算，且现金能撑到兑现？ |
| N | 订阅/递延收入型 | 核心 | 归一化盈利能力是否可达，续费是否证明粘性？ |
| P | 在手订单兑现型 | 准核心 | 订单价格与数量是否真锁定，成本能否转嫁？ |

**B（烟蒂/清算价值）与 G（股东回报）自 v1.16 起不再是主标签，改为对全部十一类通用的校验方法**（§5.2、§5.7）。原因：两者的入选标准与其所用估值模型自相矛盾——B 用清算口径入选却按催化剂兑现卖出，G 要求「净现金、负债低」却被用于银行与高杠杆基础设施；作为标签时 B 已是空集、G 的绝大多数持仓退化为无模型的反推带。降为校验方法后，其约束力反而扩展到全部类型。

### 5.1 A: 现金流复利型（DCF）

入选标准：

1. 商业模式简单且持久。
2. 自由现金流稳定。
3. 长期 ROE / ROIC 高于行业平均。
4. 资本开支可控。
5. 有提价权或成本转嫁能力。
6. 毛利率、净利率稳定或提升。
7. 管理层资本配置理性。
8. 未来 5-10 年被技术替代的概率低。
9. base case 下预期收益有吸引力，不依赖估值扩张。

卖出或降级：

1. ROIC 结构性下降。
2. 行业需求进入结构性下行。
3. 管理层开始低效扩张。
4. 分红或回购纪律恶化。
5. 估值已透支未来多年增长。
6. 预期收益明显低于其他机会。

### 5.2 B: 清算价值地板（通用校验一，非主标签）

**用法（v1.16）**：不再作为主标签建带，改为对全部十一类的**带下沿硬地板**——某票按其类型算出的带下沿低于每股保守清算价值时，以清算价值为带下沿并留痕（工作流 §6.5.3）。**不适用于 J**（金融机构的资产负债表口径不同）。下列入选标准与催化剂清单继续有效，用于判断清算价值是否**可信、可兑现**；仅当清算地板真正托住带下沿时才需完整走这套检查。

以清算价值托底为主要买入理由的持仓，仍计入 §2.1「烟蒂 / 困境类持仓合计 15% 净资产」上限。

清算价值可信的条件：

1. 市值低于保守清算价值或资产价值。
2. 资产大概率真实。
3. 主业不会持续大量烧钱。
4. 负债结构清晰。
5. 没有重大关联交易或治理风险。
6. 有明确催化剂。

保守清算价值：

```text
现金 + 0.8 * 应收账款 + 0.5 * 存货 + 0.3 * 固定资产 - 总负债
```

可接受催化剂：

1. 回购。
2. 特别分红。
3. 控股股东或管理层增持。
4. 资产出售。
5. 业务剥离。
6. 私有化。
7. 行业周期触底。
8. 债务重组。
9. 管理层更换。
10. 政策变化。

仓位限制：

| 情况 | 仓位 |
| --- | ---: |
| 财务透明、净现金、回购或分红明确 | 5%-10% |
| 财务一般、存在一定低估 | 3%-5% |
| 困境严重、主要靠反转 | 1%-3% |
| 报表复杂或治理风险高 | 不买 |

时间止损：18-24 个月没有催化进展，退出。

### 5.3 C: GARP 成长型

入选标准：

1. 收入增长来自真实需求和市占率提升，而不是单纯涨价周期。
2. 市占率提升。
3. 毛利率稳定或提升。
4. 现金流随利润改善。
5. 竞争格局没有快速恶化。
6. 增长不依赖持续融资。
7. 估值没有完全定价完美未来。
8. 至少一个核心财务指标超预期。

更严格的定义：

```text
GARP = 可防守增长 + 合理估值。
只有增长，没有护城河，不是 GARP。
只有估值不贵，但增长容易被竞争复制，也不是 GARP。
```

GARP 公司必须证明其增长不容易被资金复制：

1. 新进入者即使有资金，也难以快速复制品牌心智、渠道深度、客户验证、技术积累、供应链效率或规模成本。
2. 高利润不会轻易引来大量竞争者并迅速压低回报率。
3. 公司增长能够转化为经营现金流，而不是长期依赖营销费用、补贴或融资。
4. 公司相对同业有明确优势，而不是只处于行业整体增长 beta 中。
5. 稳定期 ROIC / ROE 应能高于行业平均，并且不是由短期价格周期或费用压缩造成。

以下公司不能归为 GARP：

1. 低壁垒消费品、普通零售、普通食品、简单制造、OEM/ODM、代工出口或流量型品牌。
2. 只靠投放、铺渠道、抢份额获得增长，但产品和品牌容易被复制。
3. 毛利率或净利率一旦较高，就会迅速吸引新玩家进入。
4. PE 约 20-25 倍，但护城河弱、增长可复制、现金流质量一般。
5. 与更强同业相比没有差异化优势，只是跟随行业增长。

PEG 只能作为粗筛。增长率必须自己拆：

```text
行业空间 * 市占率 * 价格趋势 * 利润率趋势
```

卖出信号：

1. 收入增速明显下台阶。
2. 毛利率连续恶化。
3. 销售费用率上升但收入不增长。
4. 应收账款或存货异常增长。
5. 价格战出现。
6. 市场空间被证伪。
7. 估值已经要求持续完美执行。

### 5.4 D: 产业链爆发型

这是主要进攻策略。

必须同时具备三张票：

| 票据 | 要求 |
| --- | --- |
| 需求票 | 下游需求真实且有预算 |
| 瓶颈票 | 公司所在环节供给稀缺、扩产困难或认证严格 |
| 利润票 | 瓶颈能明显转化为上市公司收入和利润 |

证据等级：

| 等级 | 证据 | 动作 |
| ---: | --- | --- |
| 0 | 论坛、传闻、概念 | 仅记录 |
| 1 | 行业趋势明确，公司受益未验证 | 观察池 |
| 2 | 公告、送样、合作、产能建设 | 可建战术仓 |
| 3 | 客户验证、订单、收入开始体现 | 可进准核心 |
| 4 | 财报确认收入、毛利率、利润 | 可升核心 |
| 5 | 持续超预期，护城河强化 | 可核心持有 |

可以追高的条件：

1. 下游需求仍在上修。
2. 订单、客户或产品价格继续改善。
3. 未来利润预期上修速度快于股价上涨速度。
4. 当前估值相对 2-3 年正常化利润并不极端。
5. 供需仍紧。
6. 竞争对手没有快速追上。

不能追高的情况：

1. 只有题材，没有订单。
2. 只有送样，没有收入路径。
3. 股价涨幅远大于盈利上修。
4. 同行业无差别乱涨。
5. 管理层高位融资或减持。
6. 估值已计入极端 bull case。

### 5.5 E: 落难白马型

先判断下跌类型：

| 类型 | 含义 | 动作 |
| --- | --- | --- |
| 杀估值 | 公司没坏，只是以前太贵 | 观察，等右侧 |
| 杀业绩 | 公司短期受损，但商业模式未坏 | 等业绩企稳 |
| 杀逻辑 | 护城河或商业模式永久受损 | 放弃 |

买入标准：

1. 估值处于历史低位。
2. 现金流仍健康。
3. 核心业务没有结构性破坏。
4. 利润预期停止下修。
5. 管理层改善资本配置。
6. 股价不再创新低。
7. 出现右侧放量和趋势确认。
8. 政策或行业环境边际改善。

不能因为好公司跌很多就买。

### 5.6 F: 资源 NAV 型

**与 H 的划分判据（v1.16，唯一）**：是否存在**可独立计量的储量/资源资产、能算出 NAV**。有 → F；没有储量、价值由成本曲线位置与中枢价差决定 → **H 成本曲线周期型**（§5.8）。煤化工、氯碱、氟化工、玻纤、电解铝加工、面板、生猪养殖等成本优势型公司**不属于 F**——它们没有可计量储量，F 的 NAV 模型对其不可算。

入选标准：

1. 储量大且质量高，且储量口径可查证（储量报告、可采年限、品位）。
2. 成本处于行业低位。
3. 矿山寿命长。
4. 有产能增长或储量替代能力。
5. 供给受资源、政策、环保、资本纪律约束。
6. 资产负债表可控。
7. 管理层并购和开发能力强。
8. 分红或回购有意义。

周期测试：

```text
上一轮行业低谷中，公司是否仍能盈利并产生现金流？
```

卖出或降级：

1. 商品价格进入极端乐观区间。
2. 行业大规模扩产。
3. 公司在周期顶部高价并购。
4. 政策限制利润。
5. 分红纪律恶化。
6. 股价已经完全反映 bull case。

### 5.7 G: 股东回报上限（通用校验二，非主标签）

**用法（v1.16）**：不再作为主标签建带，改为对 A/H/J/K 四类的**带上沿封顶校验**——若在带上沿价格处 `股息率 + 回购注销率` 低于该类要求回报（工作流 §6.5.4 的 r），则以「总回报率 = 要求回报」对应的价格封顶带上沿并留痕（工作流 §6.5.3）。真正的净现金/资产重估型公司（市值低于现金加保守主业价值）按 §5.2 的清算地板处理。下列标准继续用于判断股东回报是否**可持续、可兑现**。

股东回报可兑现的条件：

1. 净现金有意义。
2. 主业不大量烧钱。
3. 市值低于现金加保守主业价值。
4. 负债低。
5. 经营现金流为正。
6. 回购、分红或特别分红有持续性或较大概率。
7. 治理结构足够清晰。
8. 没有持续融资摊薄。
9. 没有明显关联交易风险。

仓位参考：

| 情况 | 仓位 |
| --- | ---: |
| 现金真实、回购分红明确、主业稳定 | 5%-10% |
| 主业弱但不烧钱 | 3%-5% |
| 现金多但治理弱 | 0%-3% |
| 现金真实性存疑 | 不买 |

### 5.8 H: 成本曲线周期型（v1.16 新增）

周期性商品生产但**没有可计量储量**的公司：价值由穿越周期的中枢盈利能力决定，核心变量是**成本曲线分位**而非资源禀赋。典型：煤化工、氯碱/氟化工、玻纤、电解铝加工、面板、生猪养殖。

入选标准：

1. 单位成本处于行业成本曲线**前 25%**，且可用同业单位成本或同期毛利率对照查证。
2. **上一轮行业低谷中仍能盈利或经营现金流为正**（穿越测试，与 F 同）。
3. 产品有公开、可比的价格中枢，能算出中枢价差。
4. 资产负债率可控，下行期失血速度明显慢于同业。
5. 产能与折旧阶段清晰，无高位大规模扩产承诺。
6. 成本优势来自结构（资源禀赋位置、一体化、规模、工艺），不是来自一次性低价原料库存或补贴。

卖出或降级：

1. 成本优势被同业新产能或新工艺追平。
2. 行业进入大规模扩产周期，中枢价差被结构性压缩。
3. 公司在周期顶部高价并购或高位扩产。
4. 需求永久性下移（不是周期性回落）。
5. 资产负债率恶化至难以穿越下一轮下行。
6. 价格已按周期顶部利润定价。

**判断禁区**：不得把周期顶部单年利润当作中枢；不得因当期 PE 低就认定便宜（周期股 PE 最低点通常在利润顶部）。

### 5.9 J: 金融资本型（v1.16 新增）

银行、保险、券商——资产负债表本身即经营主体，受资本充足与拨备约束。

入选标准：

1. 可持续 ROE 高于同业中位，且不依赖一次性因素或拨备反哺。
2. 不良认定口径严格（逾期 90 天以上全部计入不良，逾期与不良剪刀差不扩大），拨备覆盖率显著高于监管线。
3. 净息差或非息收入结构有**可解释的竞争来源**：低成本负债、客群结构、渠道深度、财富管理能力。
4. 核心一级资本充足率能支撑内生增长，**无持续股权融资摊薄**。
5. 治理清晰，无重大关联交易、表外风险或监管处罚。
6. 分红率稳定或提升。

卖出或降级：

1. 不良生成率持续上行，或拨备覆盖率持续下行。
2. 净息差结构性收窄且无非息补偿。
3. 需要股权融资维持增长。
4. 认定口径放松（剪刀差扩大、关注类占比上升）。
5. 治理事件或重大监管处罚。
6. PB 已超过隐含 PB 上沿而 ROE 未同步提升。

**判断禁区**：不得对 J 使用 PEG、自由现金流收益率或清算价值口径——银行的「负债」是经营输入而非风险度量，「净现金」概念不成立。

### 5.10 K: 稳态现金分配型（v1.16 新增）

受监管资产、长久期基础设施与稳态高分红成熟公司：水电、核电、高速、管网、水务，以及增长已进入稳态、价值主要由分红决定的成熟消费公司。

入选标准：

1. 可持续每股分配现金清晰，分红率稳定或有明文分红承诺。
2. 资产久期长、剩余运营年限明确，需求波动小。
3. 定价机制可预期（监管定价、长协、特许经营）。
4. 资本开支周期已过峰值，或新增项目回报率可测算。
5. 负债成本可控，再融资渠道稳定。
6. 永续增长假设 ≤ 3.5%。

卖出或降级：

1. 分配现金不可持续（一次性特别分红、举债分红、分红率被迫下调）。
2. 监管定价机制变化压缩回报。
3. 无风险利率显著上行使折现率抬升而 DPS 未同步增长。
4. 大额低回报资本开支重启。
5. 负债成本上行侵蚀可分配现金。

**判断要点**：**高杠杆不是否决项**——长久期受监管资产的杠杆是结构性的，与经营性高负债不同性质，不得据此降档或改判。

### 5.11 M: 管线/研发资产型（v1.16 新增）

在研管线或研发资产构成价值主体、现有商业化利润不足以解释市值的公司：创新药、生物制品、部分高研发医疗器械。

入选标准：

1. 已有至少一个商业化品种能贡献可归一化的经常性利润，或现金能撑到首个品种上市。
2. 管线阶段分布清晰，关键品种的适应症、竞争格局与市场空间可查证。
3. 研发效率有历史证据（推进速度、临床数据质量、过往获批率）。
4. **现金消耗年限 ≥ 2 年**，或已有确定融资安排。
5. BD 授权条款透明，首付款与里程碑款可拆分。
6. 无靠一次性 BD 收入粉饰经常性盈利的行为。

卖出或降级：

1. 关键管线临床失败或被竞品抢先。
2. 核心商业化品种被集采或医保谈判大幅压价且无量补偿。
3. 现金消耗年限跌破 2 年且融资不确定。
4. 研发投入产出比持续恶化。
5. 市值已按管线全部成功定价。

**判断禁区**：不得对未盈利或利润主要来自 BD 一次性收入的公司使用 PEG；BD 首付款按工作流 §6.4 剔出经常性利润，里程碑款按兑现概率单列、不并入经常性利润。

### 5.12 N: 订阅/递延收入型（v1.16 新增）

订阅制或合同负债占比高的软件与平台公司：当期利润被递延收入与费用化获客成本结构性压低。

入选标准：

1. 合同负债 + 递延收入 ≥ 年收入 25%，且余额持续增长。
2. 订阅收入占比 ≥ 30% 且趋势向上。
3. 续费率可查证且稳定（金额续费率优先于客户数续费率）。
4. 归一化经营利润率有**可验证的可达路径**：同业成熟期中位可比，或公司自身历史峰值可复现。
5. 获客成本回收期合理，增长不靠持续加大投放。
6. 产品有切换成本或数据/工作流粘性。

卖出或降级：

1. 续费率下行。
2. 合同负债增速掉队于收入增速（预收在萎缩）。
3. 归一化利润率路径被证伪（多年转型后仍无利润率改善）。
4. 竞品以更低价格提供同等能力，切换成本被证明不高。
5. 增长重新依赖一次性license或项目制收入。

**判断禁区**：不得用被递延收入压低的当期利润计算 PEG——那是把转型代价当成长性折价，双重计数。

### 5.13 P: 在手订单兑现型（v1.16 新增）

在手订单锁定未来 ≥ 2 年收入的公司：造船、大型工程承包、军工总装、长周期设备。

入选标准：

1. 在手订单金额与交付排期有公告或定期报告披露，**已签约、价格与数量确定**。
2. 排期覆盖未来 ≥ 2 年。
3. 原材料成本有转嫁条款或已锁价，毛利率不随大宗价格裸奔。
4. 产能与交付能力能匹配排期，无长期延期记录。
5. 新签订单价格趋势可查证。
6. 客户信用与回款条件清晰，无大额应收堆积。

卖出或降级：

1. 订单价格未锁定或成本转嫁失效。
2. 新签订单价格明显低于在手订单均价（周期终局临近）。
3. 交付延期或产能受限导致排期无法兑现。
4. 大额订单取消或客户违约。
5. 应收账款与合同资产异常增长。
6. 市值已按排期结束后仍维持同等接单价定价。

**判断要点**：意向订单、框架协议、战略合作**不计入**在手订单；排期 < 2 年时本类不适用，按 D 或 H 重贴标签。

## 8. 估值与情景分析

核心和准核心必须有 bear/base/bull case。

| 情景 | 必须回答 |
| --- | --- |
| Bear | 需求、订单、利润率、估值或政策不及预期时，可能亏多少 |
| Base | 正常兑现下，合理利润和估值是多少 |
| Bull | 需求、利润率和估值超预期时，可能到什么位置 |

最低赔率要求：

```text
base case 上涨空间 / bear case 下跌空间 > 2
```

高波动产业链股最好大于 3。稳定现金流公司可以接受 1.5-2。

### 8.1 已兑现价值 vs 未兑现空间（v1.17）

财务数据只记录已发生的事。渗透率早期的公司，价值主要在尚未发生的事情上——2019 年前的宁德时代 PE 常在 100 以上、比亚迪一度亏损，任何以历史或近三年财务为锚的模型都会把它们机械判为高估。反过来，把"未来空间"无约束地计入，估值可以被撑到任何价格。

**本体系的立场**：两条路线不是二选一。买入端（工作流 §9.7 的 `收盘 > MA20 > MA60`）要求价格已经确认，估值端（§5.4-D 证据等级 0-5）按证据强度定带——**若估值层只认已兑现利润，高成长公司会在估值层被判贵、在走势层却满足买入条件，两层互相打架**。故做法是**把同一套证据等级接进估值带**，而不是在"只买已兑现"和"为未来付钱"之间选边。

具体机制见工作流 **§6.5.7 逐票估值档案**：成长、管线与在手订单价值**直接进入档案的锚定量与倍数**，并由 `implied_growth_years`（现价隐含的兑现年数）反解出一个可证伪的数——「市场在为几年后的兑现付钱」是能被下一份财报打脸的，「故事很好」不是。

**（2026-08-03 修正）** 本节原写的机制是工作流 §6.5.6「成长期权价值」（期权 = 成熟期可达归母 × 成熟期合理 PE × 实现概率 ÷ (1+r)^n，五条硬约束）。**该机制自成文起执行 0 次、已于工作流 v2.00 退役并禁止再用**，本节删除其条文。退役理由不是「期权算法不好」，而是全池 261 家改逐票建档后**已无 base 带可加**——期权是加在通用 base 带上的，而通用路径产出的带现在是零。

**为什么仍然坚持要能被证伪**：原机制靠「期权衰减 → 带收缩 → 滑向高估」自动纠偏；现机制靠 `implied_growth_years` + 档案的 `review_triggers`（指标越界／定期报告／一致预期修正）承担同一职能——兑现不了，下一次复核就得改锚，带跟着收。纠偏仍由规则完成，不依赖事后认错。这与 §17 行为守则的方向一致：**能被证伪的乐观是可以承受的，不能被证伪的乐观不行。**

市场空间数据来源限于研报市场空间测算、行业协会、政策规划、行业前瞻，**单一来源不采信**，取 ≥2 个独立来源的较低者；可达份额不得高于当前份额 ×2、且不得高于行业第一名份额；成熟期净利率取行业成熟期水平，不得用当前爆发期净利率。

反向预期检验：

核心与准核心在写三情景之前，先从当前市值反推市场隐含的增速或利润假设，明确"市场已定价什么、预期差在哪"。如果自己的 base case 与市场隐含假设几乎相同，说明没有预期差，买入理由不成立；如果差距来自自己更乐观的假设，必须写明证据。

## 9. 买入、加仓与卖出（v1.21 整体机械化）

**本章不再规定买卖条件——全部由工作流 §9.7 决定。** 保留在这里的只有账户级否决项与研究义务。

### 9.1 买卖规则的唯一出处

| 动作 | 条件 | 出处 |
| --- | --- | --- |
| **买入** | `P/V ≤ 0.90` 且 `收盘 > MA20 > MA60` 且与在手标的 252 日相关性 ≤ 0.7，按 `P/V` 升序取前 10，每次一档 | 工作流 §9.7.1-9.7.2 |
| **加仓** | 与买入同一条规则——**同一标的每个合格日买一档**，无独立的加仓条件 | 同上 |
| **卖出** | 只有三条：①`P/V ≥ 1.10` 每日减一档；②已移出 §5 名单的按同速清仓；③想买而无钱无槽位时换仓卖出 `P/V` 最高的持仓 | 工作流 §9.7.2 第 4 步 |
| **止损/止盈** | **无** | 工作流 §9.7.1 |

**"下跌途中加仓"在本体系里是正常形态，不是违纪。** 买入要求 `收盘>MA20>MA60`，下跌趋势里两条都不成立，故实际形态是「每次反弹重新站上 MA20 时加仓」。实测按建仓次数分组，加仓 31 次以上的 26 笔持仓期内回撤中位 38.4%、胜率 88%，贡献了 89% 的利润。

**§17.3 R2（无证据摊平）因此需要按新口径理解**：它禁止的是**绕过 §9.7 的临时加码**，不是机械规则算出来的合格日买入。

### 9.2 账户级否决项（叠加在机械规则之上）

机械规则算出合格集后，以下情形**跳过该标的、顺位补下一名**：

1. 买入后将越过 §2.1 任一结构上限。
2. 命中 §16 一票否决。
3. 与现有持仓共享同一个隐藏 beta 且相关性检验未覆盖（如同一产业链的上下游）。
4. 20 日均成交额低于 5,000 万元（工作流 §10.1）。

### 9.3 研究义务（不产生买卖授权）

**买入不需要研究卡片作为前置**——机械规则不消费研究结论。但持仓与合格集内的标的仍须维持研究：

1. **持仓逐日跟踪公告、新闻、重大事项**（工作流 §11.4）。
2. **24 小时异动响应**：观察池股票突然放量上涨后 24 小时内回答——为什么涨？个股还是行业事件？事件真实吗？有无公告/财报/客户侧证据？公司是否在瓶颈环节？该业务能贡献多少利润？**结论只影响 §6 的估值带与 §5 的名单，不构成买入授权。**
3. **thesis 证伪时的处理**：证据表明业务逻辑破坏的，**改由 §5 把它移出 `worth_attention` 名单**，机械规则随即按"已出名单"逐日清仓。**不在持仓侧单独发起卖出。**

## 13. 组合级风险规则

**本章是回测覆盖不到的部分，全部保留。** 工作流的机械策略是**无杠杆纯多头**回测的产物，其结论只在 100% 敞口下成立；杠杆放大的组合级风险只能由本章承担。

### 13.1 回撤预算

| 账户从高点回撤 | 动作 |
| ---: | --- |
| −8% | 移除杠杆 |
| −12% | 黄色预警：禁止升级、禁止新增杠杆 |
| −20% | 红色预警：总仓位降至 ≤50%，暂停新买入 10 个交易日，完成复盘 |

**为什么组合级风险必须由组合级工具管**：杠杆 1.57x 下持仓每跌 1%、净资产跌 1.57%。实测（2026-08-03）−8% 线触及时，16 只持仓中仅 **1 只**触及其逐票价格线——**逐票约束加总起来管不住组合级回撤**。这正是 §17.1 迈瑞病历（担保率一度约 128%）的机制。

**显示口径**：每日照常计算，常态不进报告，触及阈值当日提示一行。

### 13.2 融资棘轮

融资买入的仓位退出后，回笼资金**必须先偿还融资**，不得循环滚入下一笔买入。

### 13.3 担保比例预警

口径见 §4.1；`portfolio_account_snapshot.csv` 为输入，每日维护。

### 13.4 核心仓的深度浮亏处理

核心仓不设价格止损。**浮亏本身不触发任何动作**——机械策略已证明深度回撤是利润来源。但浮亏 30% 以上时须做一次**证据复核**（不是卖出决策）：最新财报、订单、产业数据是否仍支持该公司留在 `worth_attention` 名单。**结论落到 §5 的名单判定上，不落到卖出指令上。**

## 15. 禁止事项

1. 禁止用杠杆买题材股。
2. 禁止绕过 §9.7 的机械规则临时加码或临时不卖。
3. 禁止因为错过而报复性追高。
4. 禁止在亏损当周修改体系规则。
5. 禁止在没有公告、财报或客户验证时把传闻当证据改带。

## 16. 一票否决

以下情况严重时不买，已持有则退出：

1. 财务造假嫌疑。
2. 控股股东资金占用。
3. 复杂关联交易。
4. 应收账款增速远高于收入。
5. 存货大增但收入不增长。
6. 经营现金流长期落后于利润。
7. 审计机构异常更换或非标意见。
8. 重要股东持续减持。
9. 高位融资。
10. 频繁并购导致高商誉。
11. 核心业务持续亏损且无可信改善。
12. 故事多，财报验证少。
13. 只有传闻，没有公告或客户验证。
14. 公司历史上多次蹭热点失败。

## 17. 行为守则：既往病历与重蹈覆辙拦截

本节把真实亏损案例和 2026-07-11 策略路线决议固化为红线。执行代理（大模型）收到命中红线的指令时，必须先纠正劝阻、再按协议留痕，不得直接照办，也不得假装合规。

### 17.1 既往病历

**病历一：迈瑞医疗 2025-09（左侧 + 杠杆 + 摊平的完整失败样本）**

事实经过：2025 年 9 月以约 240 元全仓买入，融资杠杆约 1.75x、担保率约 200%；下跌途中在约 200 元和约 180 元两次以场外资金加仓，无任何新增证据，持有依据是管理层"业绩企稳"的口头承诺；2026 年春年报与一季报相继不及预期，约 154 元清仓，单票 -36%。-36% 时若无场外输血，担保率约 128%，已进入 130% 强平区——退出时点几乎交给了券商。

错误分解（每条对应现行规则）：

| # | 错误 | 对应规则 |
| --- | --- | --- |
| 1 | 全仓单票、无仓位上限 | §2.1 持仓层级 |
| 2 | 杠杆做左侧等待，无压力测试 | §4 杠杆规则 |
| 3 | 无新增证据两次摊平 | §9.1 加仓行 |
| 4 | 管理层口头承诺当证据 | §16 第 12/13 项 |
| 5 | 无退出机制，纠错只能等财报 | §9.1 卖出行（三条机械路径） |

结构性教训：左侧模式在财报落地之前没有任何机制提示论点已错，市场连续拒绝确认本身就是信息；杠杆账户没有"长期"，杠杆账户的长期等于每一个短期都活着。

### 17.2 策略路线决议（2026-07-11）

背景：净资产约 282 万、融资负债约 218 万（1.77x）、年化收益底线 20%、年新增储蓄约 20 万；比较"估值底座 + 右侧触发"（现行）与"纯左侧买入等待回归"两条路线，两者均无已验证战绩。

决议：**维持现行右侧体系为唯一操作系统；杠杆 ≥1.3x 期间，禁止无信号、无催化剂的左侧买入。**

依据：

1. 生存数学：担保率 229.66% 距 130% 强平区约 -43% 组合跌幅，届时净资产约 -77%；左侧定义上买入下跌中的股票并延长浮亏期，与 1.77x 杠杆互斥。融资利息约为净资产 3.5-4%/年，是左侧等待的负 carry。§13.1 的 -8% 去杠杆线在 1.77x 下对应组合仅约 -4.5%，正常左侧建仓期即会击穿：左侧路线与本体系风控规则数学互斥。
2. 收益钳形：无杠杆左侧优质价值的全周期底数约 10-15% 年化，低于 20% 底线；带杠杆则回到第 1 条。该路线在自身收益要求下自我否决。
3. 行为证据：8/8 持仓体系外建仓、业绩预告后 +31% 追入、自设锁定期防过度交易，均为高行动倾向证据。左侧没有行动配给机制，行动能量会以"价值加仓"名义泄洪（迈瑞 200/180 两笔即是）；右侧把行动配给到信号日。小资金唯一的结构性优势（进出速度）只有右侧能变现。
4. 语录还原：巴菲特"小资金可做 50% 年化"指微型股与特殊情况套利，且其终生反对 margin（"聪明人破产三途：酒、女人和杠杆"）；该语录不构成杠杆左侧的依据。

左侧重启条件（全部满足后，可再议一个无杠杆左侧底仓 sleeve，在此之前本决议持续有效）：

1. 总杠杆 ≤1.1x。
2. 连续两个季度体系内执行——按可核验事实判定：**无绕过 §9.7 的临时买卖、无超包络加杠杆**，即 §17.3 的 R1/R2/R4 三条红线在该期间零命中。
3. 接受该 sleeve 预期年化 12-15%。
4. 以股息型低估优质为主，单票 ≤10%、不摊平、保留年报级 thesis 复核。

**本决议否决的不是价值投资，是"杠杆下不等确认就买"。** 现行的合法买点由工作流 §9.7 给出：`P/V ≤ 0.90` 且 `收盘 > MA20 > MA60`——**便宜是必要条件，价格已站上均线是另一个必要条件**，两者同时成立才买。
