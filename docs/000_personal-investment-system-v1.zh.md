# 个人投资体系 v1.18

> 本文是个人投资规则手册，不构成投资建议。所有数值阈值都是初始规则，应通过交易记录和复盘持续迭代。
>
> 分工：本文件是账户级总规则（组合结构、策略分类、买卖纪律，覆盖 A 股/港股/美股）；A 股市场的操作化执行（全市场质量筛选、估值排雷、每日量价扫描、持仓卖出扫描）由 `docs/000_Ashare_workflow.md` 承担。该工作流中复用的组合暴露与回撤阈值以本文件 §2/§13 为源，修改任一处必须同步另一处。

## 1. 核心原则

本体系的定位是：

```text
价值投资底层 + 产业趋势增强 + 右侧交易执行 + 仓位风险预算。
```

基本执行原则：

```text
研究决定买什么。
右侧信号决定何时买。
风险预算决定买多少。
thesis 是否变化决定加仓、减仓或清仓。
成本价不能决定任何持仓动作。
```

目标不是永远满仓，也不是永远长期持有，而是在控制永久性亏损和杠杆风险的前提下，集中持有少数高质量、高景气、高赔率或深度低估资产。

最高优先级规则：

```text
如果买入 thesis 被证伪，或者财务质量、治理结构、行业逻辑出现重大破坏，可以并且必须清仓。
```

观察池最高优先级规则：

```text
观察池必须严进宽出。
宁可错过普通机会，也不要把低壁垒、低确定性、估值不够便宜的公司放进长期观察池。
```

“值得研究一次”和“值得长期观察”必须分开。很多公司可以被分析、理解、排除，但不应因为业务有增长、股价下跌、题材顺眼或短期有反弹可能，就进入观察池。

## 2. 账户结构

### 2.1 持仓层级

| 档（v1.8，与 000 工作流 §13 v1.02 同步） | 单票建仓金额 | 定档依据 |
| --- | ---: | --- |
| 重仓 | 50 万元 | 低估深度、量价动能强度、未来上行空间、业绩增速、赔率等综合更优（由用户逐票决定） |
| 轻仓 | 25 万元 | 其余通过筛选且达到工作流 §8.13 入场阶段的标的 |

**仓位口径（v1.8）**：单票建仓金额只有重仓/轻仓两档（2026-07-17 设定，净资产约 288 万口径；净资产达 500 万前统一沿用，届时重新设定），原四袖/席位架构（v1.5-v1.7）退役，定档由用户逐票决定。总仓位=持仓市值/净资产=杠杆率×100%；**常态中枢 130%，浮动带 100%-160%**——高于 160% 必须减仓/去杠杆，低于 100% 寻找合格标的回补；总仓位 >=130% 期间 §17.3 R1 常态在线（买入必须有信号或已核实催化剂）。行业/产业链等结构占比按持仓市值计（杠杆中性）。风险预算（单笔 1.5%、回撤梯）按净资产口径；原止损网格 6%/8% 预算已于 2026-07-27 撤销（见 §17.4 R7 冷静期执行记录），改为 000 工作流 §13 第 5 条的杠杆风险提醒。一笔建仓即可，前置为 §9.1 清单+割肉价+1.5% 单笔风险校验（重仓 50 万在净资产约 288 万下隐含止损距离 <=8.6%，止损需更宽则降轻仓或放弃）。

硬性限制：

| 规则 | 上限 |
| --- | ---: |
| 单只股票建仓金额 | 重仓 50 万 / 轻仓 25 万 |
| 单只股票极限上限（存量绝对红线） | 30% 持仓市值 |
| 同一产业链合计暴露 | 40% 持仓市值 |
| 同一大行业合计暴露 | 60% 持仓市值 |
| 烟蒂 / 困境类持仓合计 | 15% 净资产 |
| 总仓位（=杠杆×100%） | 中枢 130%，带 100%-160% |

**主动/被动口径（v1.12，2026-07-29，与工作流 §13 第 8 条同步）**：上表结构上限约束的是**主动增加的暴露**。新建仓或加仓后将越过任一上限 → 硬拦不得买（口径不放宽）；既有持仓**因股价上涨被动越限** → 不预警、不建议减仓，只保留"禁止再加仓"与下列六项持有资格复核（每越过一个 10 个百分点台阶复核一次）。持仓市值随上涨偏离建仓档位金额同样不构成超限——档位金额是建仓投入口径，不是持有期目标市值。理由见 §12：机械的"涨多了就减到上限内"与十倍股保护直接冲突，逐日警告大赢家会制造恐慌并促成过早卖出。

单票接近 30% 绝对红线必须同时满足（被动漂移越限时的持有资格复核清单）：

1. 公司财务健康。
2. 行业景气度向上。
3. thesis 有财报、订单、公告、产业数据支持。
4. bear case 已明确写出。
5. 下跌 30% 不会导致被动爆仓或心理崩溃。
6. 最新财报、订单或产业证据仍支持 thesis。

### 2.2 观察池层级

| 层级 | 数量 | 含义 |
| --- | ---: | --- |
| 全量观察池 | 30-80 只 | 值得长期跟踪 |
| 重点观察池 | 10-20 只 | 近一个月最值得关注 |
| 准买入池 | 3-8 只 | 研究完成，等待触发 |
| 实际持仓 | 8-15 只 | 当前账户持仓 |
| 核心持仓 | 2-3 只 | 账户主要驱动 |

不要为了观察而买很多 1% 小仓位。观察主要通过观察池完成；战术持仓只用于已经出现触发信号的公司。

观察池入选必须至少满足以下条件之一：

1. 公司具有强护城河，资金充足的新进入者也难以在短期内复制、替代或战胜。
2. 公司处于关键产业瓶颈，供给稀缺、认证周期长、扩产难、客户替换成本高。
3. 公司拥有稀缺资源、牌照、成本曲线优势、网络效应、强品牌心智或不可轻易复制的渠道能力。
4. 公司估值进入深度低估，并且资产真实、现金流可验证、存在明确催化剂。
5. 公司是落难白马，但核心业务和护城河未被永久破坏，且已有右侧修复迹象。

以下情况默认不进入观察池：

1. 行业进入门槛低，新玩家只要有资金就可以较容易复制产品、渠道或产能。
2. 高利润会迅速吸引新玩家进入，导致利润率和增长难以长期维持。
3. 增长主要靠营销投放、渠道铺货、价格周期、出口景气或短期费用资本化，而不是长期竞争优势。
4. 公司只是“还不错”，但没有明显强于同业的不可替代优势。
5. PE 约 20-25 倍，但公司没有强护城河、强现金流、强复利能力或明确低估催化。
6. 只是股价跌多了、技术面可能反弹、短期业绩不错，但长期竞争力不足。

如果入选理由需要用很多假设才能成立，默认不入选。

## 3. 市场状态与总仓位

### 3.1 市场状态判断

按主要投资市场分别判断，例如 A 股看沪深 300，港股看恒生指数，美股看标普 500 或纳斯达克 100。

| 状态 | 判断标准 |
| --- | --- |
| 强势市 | 指数在 250 日线上方，250 日线向上，市场宽度改善，成交额放大，有清晰主线 |
| 弱势市 | 指数在 250 日线下方，250 日线向下，市场宽度弱，无持续主线 |
| 震荡市 | 既不满足强势市，也不满足弱势市 |

市场状态至少维持约 20 个交易日后再确认。市场状态只控制总仓位和进攻性，不直接强制清掉优秀个股。

### 3.2 总仓位区间

**「股票总仓位」一列自 v1.6（2026-07-14）起失效**，由 §2.1/§4.1 的杠杆包络取代（口径、中枢与带宽唯一见 §2.1，本节不重复）。原表是无杠杆口径，与现行包络的下沿直接冲突——现行体系下"降仓"指向向带内下沿收敛，不指向清仓到原表的弱势市区间。市场状态改为**收敛方向的触发条件之一**，判定与阈值见 §4.1 的杠杆风险提醒。

**「优先策略」一列仍然有效**：市场状态决定优先找哪一类标的。

| 市场状态 | 股票总仓位（**已失效，见上**） | 优先策略 |
| --- | ---: | --- |
| 强势市 | ~~75%-100%~~ | 产业链爆发、成长龙头、高景气核心 |
| 震荡市 | ~~45%-75%~~ | GARP、低估催化、股东回报、局部突破 |
| 弱势市 | ~~15%-45%~~ | 现金流复利、资源 NAV、稳态现金分配、深度低估 |

## 4. 杠杆规则

体系运行第一年禁用杠杆。满一年后，只有在真实记录证明回撤和纪律可控时，才允许使用。

### 4.1 杠杆包络（v1.00，与 000 工作流 §13 同步）

**⚠ 2026-08-03：本节处于 §17.3 R7 冷静期（→ 2026-08-10）**——用户提出删除杠杆包络、担保比例预警与融资棘轮，评估与实测依据见 §17.10。冷静期内照常计算，但已移出每日报告。

常态中枢 1.3x（总仓位 130% 净资产），浮动带 1.0x-1.6x；**1.6x 为绝对上限，触及必须减仓/去杠杆**。弱势市禁用融资买入并向带内下沿收敛。杠杆 >=1.3x 期间 §17.3 R1 常态在线：一切买入必须有右侧信号或已核实催化剂——中枢以上不存在"无信号买入"。棘轮规则：融资买入的仓位止损/退出后，回笼资金必须先偿还融资，不得循环滚入下一笔买入。**杠杆风险提醒（v1.11，2026-07-27 起，取代原止损网格动态天花板）**：总仓位 >160% 发布警告并量化回带内缺口；出现 ①市场状态转震荡/弱势、②政策性风险事件（流动性收紧、股市降杠杆/两融规则收紧等，公告或官方文件级）、③持仓性价比下降（可买域收缩或持仓趋势走坏只数上升）中任一项，提醒收敛至中枢 130%；两项及以上同时成立、或自峰值回撤触及 -8%，提醒收敛至下沿 100%。阈值与判定口径唯一见 000 工作流 §13 第 5 条，本节不重复。原"实际杠杆天花板由止损网格预算动态决定"一句随网格撤销删除。

### 4.2 可加杠杆资产

只有以下资产可以考虑杠杆：

1. 流动性高。
2. 财务稳健。
3. 估值有安全边际。
4. 不依赖单一订单、单一客户、单一政策或传闻。
5. 没有明显财务红旗。
6. 压力测试显示组合下跌 25%-30% 也不会被迫平仓。

禁止对以下资产加杠杆：

1. 纯题材股。
2. 单一订单、单一客户、单一验证驱动的公司。
3. 还没有验证的高估值成长股。
4. 财务复杂的烟蒂股。
5. 周期顶部的周期股。
6. 短期已经暴涨数倍的股票。
7. 小盘低流动性股票。

## 5. 选股策略分类

每只股票买入前必须有一个主要策略标签。卖出规则跟随原标签，除非完成完整重估。

**分类轴（v1.16，与工作流 §6.5.0 同步）**：标签的唯一职能是**选出建带公式**，分类轴统一为「这家公司的价值主要由哪一个可计量的锚定量决定」。判定顺序与建带公式以工作流 §6.5 为唯一口径，本节只写入选标准、卖出/降级信号与判断要点。

| 代码 | 策略 | 最高层级 | 核心问题 |
| --- | --- | --- | --- |
| A | 现金流复利型 | 核心 | 不依赖乐观假设，能否长期复利？ |
| C | GARP 成长型 | 核心 | 增长是否真实、可持续、未被充分定价？ |
| D | 产业链爆发型 | 核心 | 是否处在真实瓶颈，并能转化为利润？ |
| E | 落难白马型 | 核心 | 困境是暂时的，还是护城河永久受损？ |
| F | 资源 NAV 型 | 核心 | 是可计量的储量优势 + 供给约束，还是普通周期 beta？ |
| H | 成本曲线周期型 | 核心 | 成本优势是否足以穿越整轮下行并在中枢价差下赚钱？ |
| J | 金融资本型 | 准核心 | 高 ROE 是真实定价能力，还是放松认定口径与加杠杆换来的？ |
| K | 稳态现金分配型 | 核心 | 分配现金是否可持续，且相对折现率仍有溢价？ |
| M | 管线/研发资产型 | 准核心 | 管线价值是否可按概率折算，且现金能撑到兑现？ |
| N | 订阅/递延收入型 | 核心 | 归一化盈利能力是否可达，续费是否证明粘性？ |
| P | 在手订单兑现型 | 准核心 | 订单价格与数量是否真锁定，成本能否转嫁？ |

**B（烟蒂/清算价值）与 G（股东回报）自 v1.16 起不再是主标签，改为对全部十一类通用的校验方法**（§5.2、§5.7）。原因：两者的入选标准与其所用估值模型自相矛盾——B 用清算口径入选却按催化剂兑现卖出，G 要求「净现金、负债低」却被用于银行与高杠杆基础设施；作为标签时 B 已是空集、G 的绝大多数持仓退化为无模型的反推带。降为校验方法后，其约束力反而扩展到全部类型。

### 5.1 A: 现金流复利型（DCF）

入选标准：

1. 商业模式简单且持久。
2. 自由现金流稳定。
3. 长期 ROE / ROIC 高于行业平均。
4. 资本开支可控。
5. 有提价权或成本转嫁能力。
6. 毛利率、净利率稳定或提升。
7. 管理层资本配置理性。
8. 未来 5-10 年被技术替代的概率低。
9. base case 下预期收益有吸引力，不依赖估值扩张。

卖出或降级：

1. ROIC 结构性下降。
2. 行业需求进入结构性下行。
3. 管理层开始低效扩张。
4. 分红或回购纪律恶化。
5. 估值已透支未来多年增长。
6. 预期收益明显低于其他机会。

### 5.2 B: 清算价值地板（通用校验一，非主标签）

**用法（v1.16）**：不再作为主标签建带，改为对全部十一类的**带下沿硬地板**——某票按其类型算出的带下沿低于每股保守清算价值时，以清算价值为带下沿并留痕（工作流 §6.5.3）。**不适用于 J**（金融机构的资产负债表口径不同）。下列入选标准与催化剂清单继续有效，用于判断清算价值是否**可信、可兑现**；仅当清算地板真正托住带下沿时才需完整走这套检查。

以清算价值托底为主要买入理由的持仓，仍计入 §2.1「烟蒂 / 困境类持仓合计 15% 净资产」上限。

清算价值可信的条件：

1. 市值低于保守清算价值或资产价值。
2. 资产大概率真实。
3. 主业不会持续大量烧钱。
4. 负债结构清晰。
5. 没有重大关联交易或治理风险。
6. 有明确催化剂。

保守清算价值：

```text
现金 + 0.8 * 应收账款 + 0.5 * 存货 + 0.3 * 固定资产 - 总负债
```

可接受催化剂：

1. 回购。
2. 特别分红。
3. 控股股东或管理层增持。
4. 资产出售。
5. 业务剥离。
6. 私有化。
7. 行业周期触底。
8. 债务重组。
9. 管理层更换。
10. 政策变化。

仓位限制：

| 情况 | 仓位 |
| --- | ---: |
| 财务透明、净现金、回购或分红明确 | 5%-10% |
| 财务一般、存在一定低估 | 3%-5% |
| 困境严重、主要靠反转 | 1%-3% |
| 报表复杂或治理风险高 | 不买 |

时间止损：18-24 个月没有催化进展，退出。

### 5.3 C: GARP 成长型

入选标准：

1. 收入增长来自真实需求和市占率提升，而不是单纯涨价周期。
2. 市占率提升。
3. 毛利率稳定或提升。
4. 现金流随利润改善。
5. 竞争格局没有快速恶化。
6. 增长不依赖持续融资。
7. 估值没有完全定价完美未来。
8. 至少一个核心财务指标超预期。

更严格的定义：

```text
GARP = 可防守增长 + 合理估值。
只有增长，没有护城河，不是 GARP。
只有估值不贵，但增长容易被竞争复制，也不是 GARP。
```

GARP 公司必须证明其增长不容易被资金复制：

1. 新进入者即使有资金，也难以快速复制品牌心智、渠道深度、客户验证、技术积累、供应链效率或规模成本。
2. 高利润不会轻易引来大量竞争者并迅速压低回报率。
3. 公司增长能够转化为经营现金流，而不是长期依赖营销费用、补贴或融资。
4. 公司相对同业有明确优势，而不是只处于行业整体增长 beta 中。
5. 稳定期 ROIC / ROE 应能高于行业平均，并且不是由短期价格周期或费用压缩造成。

以下公司不能归为 GARP：

1. 低壁垒消费品、普通零售、普通食品、简单制造、OEM/ODM、代工出口或流量型品牌。
2. 只靠投放、铺渠道、抢份额获得增长，但产品和品牌容易被复制。
3. 毛利率或净利率一旦较高，就会迅速吸引新玩家进入。
4. PE 约 20-25 倍，但护城河弱、增长可复制、现金流质量一般。
5. 与更强同业相比没有差异化优势，只是跟随行业增长。

PEG 只能作为粗筛。增长率必须自己拆：

```text
行业空间 * 市占率 * 价格趋势 * 利润率趋势
```

卖出信号：

1. 收入增速明显下台阶。
2. 毛利率连续恶化。
3. 销售费用率上升但收入不增长。
4. 应收账款或存货异常增长。
5. 价格战出现。
6. 市场空间被证伪。
7. 估值已经要求持续完美执行。

### 5.4 D: 产业链爆发型

这是主要进攻策略。

必须同时具备三张票：

| 票据 | 要求 |
| --- | --- |
| 需求票 | 下游需求真实且有预算 |
| 瓶颈票 | 公司所在环节供给稀缺、扩产困难或认证严格 |
| 利润票 | 瓶颈能明显转化为上市公司收入和利润 |

证据等级：

| 等级 | 证据 | 动作 |
| ---: | --- | --- |
| 0 | 论坛、传闻、概念 | 仅记录 |
| 1 | 行业趋势明确，公司受益未验证 | 观察池 |
| 2 | 公告、送样、合作、产能建设 | 可建战术仓 |
| 3 | 客户验证、订单、收入开始体现 | 可进准核心 |
| 4 | 财报确认收入、毛利率、利润 | 可升核心 |
| 5 | 持续超预期，护城河强化 | 可核心持有 |

可以追高的条件：

1. 下游需求仍在上修。
2. 订单、客户或产品价格继续改善。
3. 未来利润预期上修速度快于股价上涨速度。
4. 当前估值相对 2-3 年正常化利润并不极端。
5. 供需仍紧。
6. 竞争对手没有快速追上。

不能追高的情况：

1. 只有题材，没有订单。
2. 只有送样，没有收入路径。
3. 股价涨幅远大于盈利上修。
4. 同行业无差别乱涨。
5. 管理层高位融资或减持。
6. 估值已计入极端 bull case。

### 5.5 E: 落难白马型

先判断下跌类型：

| 类型 | 含义 | 动作 |
| --- | --- | --- |
| 杀估值 | 公司没坏，只是以前太贵 | 观察，等右侧 |
| 杀业绩 | 公司短期受损，但商业模式未坏 | 等业绩企稳 |
| 杀逻辑 | 护城河或商业模式永久受损 | 放弃 |

买入标准：

1. 估值处于历史低位。
2. 现金流仍健康。
3. 核心业务没有结构性破坏。
4. 利润预期停止下修。
5. 管理层改善资本配置。
6. 股价不再创新低。
7. 出现右侧放量和趋势确认。
8. 政策或行业环境边际改善。

不能因为好公司跌很多就买。

### 5.6 F: 资源 NAV 型

**与 H 的划分判据（v1.16，唯一）**：是否存在**可独立计量的储量/资源资产、能算出 NAV**。有 → F；没有储量、价值由成本曲线位置与中枢价差决定 → **H 成本曲线周期型**（§5.8）。煤化工、氯碱、氟化工、玻纤、电解铝加工、面板、生猪养殖等成本优势型公司**不属于 F**——它们没有可计量储量，F 的 NAV 模型对其不可算。

入选标准：

1. 储量大且质量高，且储量口径可查证（储量报告、可采年限、品位）。
2. 成本处于行业低位。
3. 矿山寿命长。
4. 有产能增长或储量替代能力。
5. 供给受资源、政策、环保、资本纪律约束。
6. 资产负债表可控。
7. 管理层并购和开发能力强。
8. 分红或回购有意义。

周期测试：

```text
上一轮行业低谷中，公司是否仍能盈利并产生现金流？
```

卖出或降级：

1. 商品价格进入极端乐观区间。
2. 行业大规模扩产。
3. 公司在周期顶部高价并购。
4. 政策限制利润。
5. 分红纪律恶化。
6. 股价已经完全反映 bull case。

### 5.7 G: 股东回报上限（通用校验二，非主标签）

**用法（v1.16）**：不再作为主标签建带，改为对 A/H/J/K 四类的**带上沿封顶校验**——若在带上沿价格处 `股息率 + 回购注销率` 低于该类要求回报（工作流 §6.5.4 的 r），则以「总回报率 = 要求回报」对应的价格封顶带上沿并留痕（工作流 §6.5.3）。真正的净现金/资产重估型公司（市值低于现金加保守主业价值）按 §5.2 的清算地板处理。下列标准继续用于判断股东回报是否**可持续、可兑现**。

股东回报可兑现的条件：

1. 净现金有意义。
2. 主业不大量烧钱。
3. 市值低于现金加保守主业价值。
4. 负债低。
5. 经营现金流为正。
6. 回购、分红或特别分红有持续性或较大概率。
7. 治理结构足够清晰。
8. 没有持续融资摊薄。
9. 没有明显关联交易风险。

仓位参考：

| 情况 | 仓位 |
| --- | ---: |
| 现金真实、回购分红明确、主业稳定 | 5%-10% |
| 主业弱但不烧钱 | 3%-5% |
| 现金多但治理弱 | 0%-3% |
| 现金真实性存疑 | 不买 |

### 5.8 H: 成本曲线周期型（v1.16 新增）

周期性商品生产但**没有可计量储量**的公司：价值由穿越周期的中枢盈利能力决定，核心变量是**成本曲线分位**而非资源禀赋。典型：煤化工、氯碱/氟化工、玻纤、电解铝加工、面板、生猪养殖。

入选标准：

1. 单位成本处于行业成本曲线**前 25%**，且可用同业单位成本或同期毛利率对照查证。
2. **上一轮行业低谷中仍能盈利或经营现金流为正**（穿越测试，与 F 同）。
3. 产品有公开、可比的价格中枢，能算出中枢价差。
4. 资产负债率可控，下行期失血速度明显慢于同业。
5. 产能与折旧阶段清晰，无高位大规模扩产承诺。
6. 成本优势来自结构（资源禀赋位置、一体化、规模、工艺），不是来自一次性低价原料库存或补贴。

卖出或降级：

1. 成本优势被同业新产能或新工艺追平。
2. 行业进入大规模扩产周期，中枢价差被结构性压缩。
3. 公司在周期顶部高价并购或高位扩产。
4. 需求永久性下移（不是周期性回落）。
5. 资产负债率恶化至难以穿越下一轮下行。
6. 价格已按周期顶部利润定价。

**判断禁区**：不得把周期顶部单年利润当作中枢；不得因当期 PE 低就认定便宜（周期股 PE 最低点通常在利润顶部）。

### 5.9 J: 金融资本型（v1.16 新增）

银行、保险、券商——资产负债表本身即经营主体，受资本充足与拨备约束。

入选标准：

1. 可持续 ROE 高于同业中位，且不依赖一次性因素或拨备反哺。
2. 不良认定口径严格（逾期 90 天以上全部计入不良，逾期与不良剪刀差不扩大），拨备覆盖率显著高于监管线。
3. 净息差或非息收入结构有**可解释的竞争来源**：低成本负债、客群结构、渠道深度、财富管理能力。
4. 核心一级资本充足率能支撑内生增长，**无持续股权融资摊薄**。
5. 治理清晰，无重大关联交易、表外风险或监管处罚。
6. 分红率稳定或提升。

卖出或降级：

1. 不良生成率持续上行，或拨备覆盖率持续下行。
2. 净息差结构性收窄且无非息补偿。
3. 需要股权融资维持增长。
4. 认定口径放松（剪刀差扩大、关注类占比上升）。
5. 治理事件或重大监管处罚。
6. PB 已超过隐含 PB 上沿而 ROE 未同步提升。

**判断禁区**：不得对 J 使用 PEG、自由现金流收益率或清算价值口径——银行的「负债」是经营输入而非风险度量，「净现金」概念不成立。

### 5.10 K: 稳态现金分配型（v1.16 新增）

受监管资产、长久期基础设施与稳态高分红成熟公司：水电、核电、高速、管网、水务，以及增长已进入稳态、价值主要由分红决定的成熟消费公司。

入选标准：

1. 可持续每股分配现金清晰，分红率稳定或有明文分红承诺。
2. 资产久期长、剩余运营年限明确，需求波动小。
3. 定价机制可预期（监管定价、长协、特许经营）。
4. 资本开支周期已过峰值，或新增项目回报率可测算。
5. 负债成本可控，再融资渠道稳定。
6. 永续增长假设 ≤ 3.5%。

卖出或降级：

1. 分配现金不可持续（一次性特别分红、举债分红、分红率被迫下调）。
2. 监管定价机制变化压缩回报。
3. 无风险利率显著上行使折现率抬升而 DPS 未同步增长。
4. 大额低回报资本开支重启。
5. 负债成本上行侵蚀可分配现金。

**判断要点**：**高杠杆不是否决项**——长久期受监管资产的杠杆是结构性的，与经营性高负债不同性质，不得据此降档或改判。

### 5.11 M: 管线/研发资产型（v1.16 新增）

在研管线或研发资产构成价值主体、现有商业化利润不足以解释市值的公司：创新药、生物制品、部分高研发医疗器械。

入选标准：

1. 已有至少一个商业化品种能贡献可归一化的经常性利润，或现金能撑到首个品种上市。
2. 管线阶段分布清晰，关键品种的适应症、竞争格局与市场空间可查证。
3. 研发效率有历史证据（推进速度、临床数据质量、过往获批率）。
4. **现金消耗年限 ≥ 2 年**，或已有确定融资安排。
5. BD 授权条款透明，首付款与里程碑款可拆分。
6. 无靠一次性 BD 收入粉饰经常性盈利的行为。

卖出或降级：

1. 关键管线临床失败或被竞品抢先。
2. 核心商业化品种被集采或医保谈判大幅压价且无量补偿。
3. 现金消耗年限跌破 2 年且融资不确定。
4. 研发投入产出比持续恶化。
5. 市值已按管线全部成功定价。

**判断禁区**：不得对未盈利或利润主要来自 BD 一次性收入的公司使用 PEG；BD 首付款按工作流 §6.4 剔出经常性利润，里程碑款按兑现概率单列、不并入经常性利润。

### 5.12 N: 订阅/递延收入型（v1.16 新增）

订阅制或合同负债占比高的软件与平台公司：当期利润被递延收入与费用化获客成本结构性压低。

入选标准：

1. 合同负债 + 递延收入 ≥ 年收入 25%，且余额持续增长。
2. 订阅收入占比 ≥ 30% 且趋势向上。
3. 续费率可查证且稳定（金额续费率优先于客户数续费率）。
4. 归一化经营利润率有**可验证的可达路径**：同业成熟期中位可比，或公司自身历史峰值可复现。
5. 获客成本回收期合理，增长不靠持续加大投放。
6. 产品有切换成本或数据/工作流粘性。

卖出或降级：

1. 续费率下行。
2. 合同负债增速掉队于收入增速（预收在萎缩）。
3. 归一化利润率路径被证伪（多年转型后仍无利润率改善）。
4. 竞品以更低价格提供同等能力，切换成本被证明不高。
5. 增长重新依赖一次性license或项目制收入。

**判断禁区**：不得用被递延收入压低的当期利润计算 PEG——那是把转型代价当成长性折价，双重计数。

### 5.13 P: 在手订单兑现型（v1.16 新增）

在手订单锁定未来 ≥ 2 年收入的公司：造船、大型工程承包、军工总装、长周期设备。

入选标准：

1. 在手订单金额与交付排期有公告或定期报告披露，**已签约、价格与数量确定**。
2. 排期覆盖未来 ≥ 2 年。
3. 原材料成本有转嫁条款或已锁价，毛利率不随大宗价格裸奔。
4. 产能与交付能力能匹配排期，无长期延期记录。
5. 新签订单价格趋势可查证。
6. 客户信用与回款条件清晰，无大额应收堆积。

卖出或降级：

1. 订单价格未锁定或成本转嫁失效。
2. 新签订单价格明显低于在手订单均价（周期终局临近）。
3. 交付延期或产能受限导致排期无法兑现。
4. 大额订单取消或客户违约。
5. 应收账款与合同资产异常增长。
6. 市值已按排期结束后仍维持同等接单价定价。

**判断要点**：意向订单、框架协议、战略合作**不计入**在手订单；排期 < 2 年时本类不适用，按 D 或 H 重贴标签。

## 8. 估值与情景分析

核心和准核心必须有 bear/base/bull case。

| 情景 | 必须回答 |
| --- | --- |
| Bear | 需求、订单、利润率、估值或政策不及预期时，可能亏多少 |
| Base | 正常兑现下，合理利润和估值是多少 |
| Bull | 需求、利润率和估值超预期时，可能到什么位置 |

最低赔率要求：

```text
base case 上涨空间 / bear case 下跌空间 > 2
```

高波动产业链股最好大于 3。稳定现金流公司可以接受 1.5-2。

### 8.1 已兑现价值 vs 未兑现空间（v1.17）

财务数据只记录已发生的事。渗透率早期的公司，价值主要在尚未发生的事情上——2019 年前的宁德时代 PE 常在 100 以上、比亚迪一度亏损，任何以历史或近三年财务为锚的模型都会把它们机械判为高估。反过来，把"未来空间"无约束地计入，估值可以被撑到任何价格。

**本体系的立场**：两条路线不是二选一，因为**这个体系本来就不是纯后视的**——买入端（工作流 §8.13 右侧入场阶段）要求价格已经确认，仓位端（§5.4-D 证据等级 0-5）按证据强度分配仓位，两者都已经是前瞻且分级的。唯一纯后视的是估值层，于是高成长公司在估值层被判死、在信号层却被允许买入，两层互相打架。所以做法是**把同一套证据等级接进估值带**，而不是在"只买已兑现"和"为未来付钱"之间选边。

具体机制见工作流 **§6.5.6 成长期权价值**：期权 = 成熟期可达归母 × 成熟期合理 PE × 实现概率 ÷ (1+r)^n，实现概率由 §5.4-D 证据等级查表（0 级传闻一律 0%，5 级上限 60%）。五条硬约束——仅 L1/L2、期权 ≤ base 带中值 50%、base 带必须并列展示、必须写 12 个月内可核查的里程碑（未兑现降一档、连续两次归零）、买卖两端用同一条带。

**为什么用「衰减」而不是「不许算」**：故事不兑现 → 期权衰减 → 带收缩 → 价格机械地滑向高估 → 自动触发提醒卖出。纠偏由规则完成，不依赖事后认错。这与 §17 行为守则的方向一致：**能被证伪的乐观是可以承受的，不能被证伪的乐观不行。**

市场空间数据来源限于研报市场空间测算、行业协会、政策规划、行业前瞻，**单一来源不采信**，取 ≥2 个独立来源的较低者；可达份额不得高于当前份额 ×2、且不得高于行业第一名份额；成熟期净利率取行业成熟期水平，不得用当前爆发期净利率。

反向预期检验：

核心与准核心在写三情景之前，先从当前市值反推市场隐含的增速或利润假设，明确"市场已定价什么、预期差在哪"。如果自己的 base case 与市场隐含假设几乎相同，说明没有预期差，买入理由不成立；如果差距来自自己更乐观的假设，必须写明证据。

## 9. 买入规则

### 9.1 通用买入清单

只有全部满足时才能买：

1. 已进入观察池。
2. 已完成研究卡片。
3. thesis 清晰。
4. 已写 bear/base/bull case，并完成反向预期拆解（赔率自 v1.8 起不再作为买入闸门项，仅作重仓/轻仓定档参考——估值约束由估值档位与工作流 §6.2.1 在池层承担）。
5. 有右侧信号，且达到工作流 §8.13 该组合的入场阶段（v1.8 起拒绝左侧买入，原"极度低估且有催化剂"通道关闭；§8.13 一段=底部首根有效放量大阳线，已是最早合法买点）。
6. 已写明什么情况证明自己错了。
7. 已设定目标仓位。
8. 已设定加仓、减仓、清仓条件。
9. 已完成催化剂地图，每条催化剂可追踪、可验证、有预计时点。
10. 已对前 2-3 个高概率高影响风险写好预设应对。
11. 已核对买入后组合暴露：单票、产业链、大行业上限，以及与现有持仓共享的隐藏 beta。

### 9.2 底部反转买入

适用于落难白马、低估反转、周期底部。

以下条件满足至少 4 条才可以买：

1. 3-6 周不创新低。
2. 股价形成更高低点。
3. 放量站上 60 日线。
4. 回踩不破突破平台。
5. 板块同步改善。
6. 最新财报没有继续恶化。
7. 出现回购、订单、政策、价格、利润率等催化剂。
8. 股价强于指数和行业。

三批建仓：

| 批次 | 触发条件 | 仓位 |
| --- | --- | ---: |
| 第一批 | 底部反转条件成立 | 目标仓位 1/3 |
| 第二批 | 回踩平台不破且缩量 | 目标仓位 1/3 |
| 第三批 | 创新高或出现第二个基本面验证 | 目标仓位 1/3 |

如果股价连续两个交易日跌回平台，或跌破前低，退出战术部分。

### 9.3 突破 / 产业链买入

适用于产业链爆发和强成长。

触发条件：

1. 成交量至少为 20 日均量 2 倍。
2. 突破至少 3 个月平台，或创 52 周新高。
3. 板块和龙头同向确认。
4. 24 小时研究确认需求、瓶颈和利润转化。

仓位路径：

| 阶段 | 证据 | 仓位 |
| --- | --- | ---: |
| 初步异动 | 板块启动，公司强于同业 | 1%-3% |
| 初步验证 | 公告、送样、合作、产能证据 | 3%-5% |
| 强验证 | 客户、订单、收入开始体现 | 5%-10% |
| 财报兑现 | 利润、毛利率、订单持续超预期 | 10%-20% |
| 长期确认 | 瓶颈持续，护城河强化 | 核心仓位 |

不要等完美回调，也不要在验证前一次买满。

### 9.4 24 小时异动响应

观察池股票突然放量上涨后，24 小时内回答：

1. 为什么涨？
2. 是个股事件，还是行业事件？
3. 事件真实吗？
4. 是否有公告、财报、客户侧证据？
5. 公司是否在瓶颈环节？
6. 该业务能贡献多少利润？
7. 市场此前是否低估了利润弹性？
8. 产业链中谁最受益？
9. 龙头是谁？
10. 当前估值相对未来利润是否仍可接受？

结论只能三选一：

1. 买入——**须独立满足买入条件，异动本身不构成买入授权**：标的处于工作流 §6.2.1 可买档位、已达 §8.13 入场阶段、过 §9.1 通用买入清单且已设割肉价。未过矩阵的组合是「可见不可买」，无当日直买例外（v1.02 事件通道关闭）。
2. 等待——必须登记具体的 §8.13 触发条件与复核日期，但不预设买入价位与仓位（见下）。
3. 放弃。

**原「参数化等待」条文自 2026-07-17 废止**（左侧通道随工作流 v1.02 关闭）：原文要求写明「回调到 X 价格买 Y 仓位，N 个交易日内有效」——这是在下跌途中预先承诺买入，正是 §17.3 R1 所定义的左侧买入，与本体系「拒绝左侧买入」的最低门槛冲突；其后半句「按突破规则买第一批」所指的 §9.5 买入触发亦已同期废止。

替代路径按 §17.3 拦截协议第 2 条：等工作流 §8.13 一段（底部/平台首根有效放量大阳线），那已是最早的合法右侧买点。

真实触发后，不允许用“继续观察”作为结论——结论 2 的登记必须落到可核验的触发条件上。

### 9.5 观察池事件动量（**买入条文废止，2026-07-17 随工作流 v1.02 事件通道关闭**）

**本节的买入通道自 2026-07-17 废止**：观察池放量异动不再构成独立的买入理由，买点统一走 §9.1 通用买入清单 + 工作流 §8.13 分阶段右侧建仓；未过工作流 §6.2.1 矩阵的组合一律可见不可买，评级改变只经工作流 §7.4 复核。依据见 §17.2 策略路线决议与 §19 的 v1.8 修订记录。

废止范围为下方「适用场景」「买入触发」「仓位路径」「持有条件」四段，仅供追溯，**不得作为买入依据**。

**仍然有效**：下方「卖出规则」6 条与「禁止事项」5 条——它们约束的是存量战术仓的退出纪律而非新开仓，其中禁止事项 1 是 §17.3 R6 的锚点，不随本节废止。

以下为原文保留。

这是用于捕捉“高质量股票突然被市场重新定价”的战术策略，典型形态是：

```text
高质量观察池公司 -> 某日放量大涨 -> 快速确认催化剂 -> 追入战术仓 -> 延续则加仓 -> 动量衰竭或逻辑证伪则卖出。
```

该策略只允许用于已经进入观察池、重点观察池或准买入池的公司。陌生股票突然大涨，不适用本策略。

适用场景：

1. 落难白马出现底部放量修复。
2. GARP 公司业绩、订单、利润率或行业景气突然超预期。
3. 产业链瓶颈公司出现需求、订单、价格、客户认证或政策催化。
4. 以股东回报或清算价值托底为主要买入理由的持仓，出现回购、增持、特别分红、资产重估或价值兑现催化。

买入触发必须同时满足：

1. 公司此前已经通过观察池质量筛选。
2. 单日成交量至少为 20 日均量的 2 倍。
3. 股价突破关键平台、重要均线或阶段新高。
4. 买入后 24 小时内能核实真实催化剂（公告、订单、行业数据、板块级联动或权威研报之一），而不是只有市场传闻；催化剂尚未公开先行买入的（须满足条件 2/3 的强信号形态），核实不到→禁止加仓并收紧割肉价，驱动被证伪或仅题材→立即退出（v1.3：催化剂由买入前置改为 24 小时验证义务，公告常滞后于股价）。
5. 当日或次日仍有足够成交承接，不是一字板、脉冲板或无量拉升。

仓位路径：

| 阶段 | 触发 | 仓位 |
| --- | --- | ---: |
| 第一笔 | 放量突破且催化剂初步真实 | 目标仓位 1/3，通常 1%-3% |
| 第二笔 | 继续放量上涨，或横盘 2-5 个交易日不跌回启动平台 | 目标仓位 1/3 |
| 第三笔 | 第二次突破、研报/公告/财报进一步验证，或板块龙头同步加强 | 目标仓位 1/3 |

事件动量仓默认按轻仓档执行（25 万，见 §2.1/工作流 §13，允许一笔建满，前置买入清单+割肉价+1.5%净资产单笔风险校验）；且标的必须处于工作流 §6.2.1 常备可买档位并达到 §8.13 入场阶段——watch_only 组合不适用本策略（v1.8：事件通道已关闭，评级改变只经工作流 §7.4 复核）。只有当催化剂进入订单或财报级验证、并完成完整重估后，才允许升级重仓档（须过闸门与加仓条件）。

持有条件：

1. 股价不跌回启动平台。
2. 回调缩量，上涨放量。
3. 板块或同类高质量公司同步确认。
4. 催化剂没有被证伪。
5. 盈利预期或估值修复空间仍未被完全定价。

卖出规则：

1. 跌破启动日低点，退出。
2. 连续两个交易日跌回突破平台，退出。
3. 放量滞涨、长上影后次日不能修复，减仓。
4. 5 日线和 10 日线同时失守，且没有新增基本面证据，减仓或退出。
5. 催化剂被证伪，立即退出。
6. 阶段涨幅已经反映 bull case，且后续没有盈利上修，分批止盈。

禁止事项：

1. 禁止把失败的事件动量仓转成长期仓。
2. 禁止因为“公司质量不错”而忽视短线失败信号。
3. 禁止在既无强信号形态支撑、又无真实催化剂时只凭大涨追入；催化剂未公开先行买入的，必须履行买入触发条件 4 的 24 小时验证义务。
4. 禁止在第一笔买入后无验证地补仓摊平。
5. 禁止把启动价当作绝对底部；启动价跌破时必须重新评估。

该策略的目标是吃到预期差被市场连续定价的主升早段，而不是预测完整顶部。买入靠异动和催化剂，持有靠延续，卖出靠动量衰竭和 thesis 证伪。

## 10. 加仓规则

只有 thesis 变强时才能加仓，不能因为股价下跌而加仓。

允许加仓：

1. 财报超预期。
2. 订单或客户验证改善。
3. 毛利率改善。
4. 行业景气度上修。
5. 突破后回踩不破。
6. 竞争格局改善。
7. 估值仍有空间。

限制：

1. 没有新增证据，不摊平亏损。
2. 每次加仓原则上不大于上一笔，除非重新完整评估。
3. 加仓后不得违反组合集中度限制。

## 11. 减仓与卖出规则

减仓和卖出依据 thesis、估值、风险、机会成本、催化剂状态和右侧失败，不依据浮盈浮亏。

### 11.1 Thesis 证伪卖出

以下情况卖出或降级：

1. 订单没有兑现。
2. 客户验证失败。
3. 利润率没有改善。
4. 行业需求被证伪。
5. 竞争对手进入速度超预期。
6. 技术路线变化。
7. 政策逻辑变化。
8. 管理层表述与财务数据矛盾。

### 11.2 估值过高卖出

以下情况减仓：

1. 当前价格已经反映 bull case。
2. 未来 2-3 年利润已被充分定价。
3. 股价上涨远快于盈利上修。
4. 板块进入普遍泡沫。
5. 利好不断出现但股价不再上涨。

### 11.3 机会成本卖出

只有新机会评分至少比旧持仓高 15 分，或旧持仓 thesis 明显变弱，才允许大幅切换。

目的是避免频繁追逐短期热点。

### 11.4 风险控制卖出

以下情况减仓：

1. 单只股票超过 30%。
2. 同一产业链超过 40%。
3. 同一大行业超过 60%。
4. 杠杆超过安全区间。
5. 多个持仓共享同一个隐藏 beta。

### 11.5 催化剂兑现卖出

催化剂兑现后必须重新评估。如果没有下一轮催化或盈利上修，减仓。

催化剂包括：

1. 政策落地。
2. 订单公告。
3. 产品发布。
4. 财报兑现。
5. 指数纳入。
6. 并购重组完成。
7. 分红或回购执行。

### 11.6 技术破位卖出

适用于战术持仓和产业链突破：

1. 跌破突破平台。
2. 跌破 60 日线后无法收回。
3. 放量下跌。
4. 反弹无量。
5. 板块龙头开始破位。
6. 公司没有新的基本面证据。

### 11.7 治理 / 财务红旗卖出

严重时卖出或排除：

1. 控股股东资金占用。
2. 复杂关联交易。
3. 应收账款异常。
4. 存货异常。
5. 经营现金流长期低于利润。
6. 审计机构异常更换或非标意见。
7. CFO 频繁更换。
8. 大股东高质押。
9. 高位融资。
10. 重要股东持续减持。
11. 管理层解释与数据矛盾。

## 12. 盈利后减仓与十倍股保护（**整节废止，2026-08-01 用户决定**）

**本节全部条文自 2026-08-01 废止**，由工作流 §14「估值卖出」的**按档分级减仓梯**取代。

废止清单：

| 原条文 | 状态 |
| --- | --- |
| §12.1 底仓原则 | 废止。底仓改由「按剩余股数递减、永不清仓」结构性保证，不再依赖 thesis 判断 |
| §12.2 开始减仓的 7 项条件 | 废止。由估值偏离度单一口径替代 |
| §12.3 慢减仓表（含 **>+500% 停止机械卖出**、**10 倍保留永久底仓**） | 废止。这是本次改动的核心——十倍股保护不再存在 |
| §12.4 底仓比例表（按策略类型） | 废止 |
| §12.5 大盈利后的趋势保护（周/月线三档） | 废止（工作流层早于 v1.9 已退役，此次删除条文） |

**取代它的规则**（工作流 §14 第 3 项）：触发点按质量档分级——L1 高估 / L2 较高估 / L3 中性；台阶 {中轴 M, 带顶 H, 1.2H, 1.44H}，每上跨一阶提醒减持**剩余股数**的 20%，1.44H 起 40%；盈利预测持续上修时步进减半；连续 3 个交易日收盘定型才提醒。**不设收益前提**——到档即提醒，与浮盈浮亏无关。

**方向评估**：本次废止使系统**卖得更多、更早**，属降风险方向，按 §17.3 第 5 条方向豁免不构成 R7 拆除、不适用 5 个交易日冷静期。评估表见 §17.9。

**须如实留痕的立场变更**：v1.21（2026-07-29）去除上涨型机械警告时，用户顾虑是「错过大牛股」；本次改判为「对十倍股的贪婪、忽略了风险」。**形式上不冲突**——v1.21 原话明确把「触发估值水平变化」的提醒排除在去除范围外，本减仓梯正是估值触发；但**实质立场确已反转**，不得表述为「一直如此」。

| # | 错误 | 对应规则 |
| --- | --- | --- |

### 17.2 策略路线决议（2026-07-11）

背景：净资产约 282 万、融资负债约 218 万（1.77x）、年化收益底线 20%、年新增储蓄约 20 万；比较"估值底座 + 右侧触发"（现行）与"纯左侧买入等待回归"两条路线，两者均无已验证战绩。

决议：**维持现行右侧体系为唯一操作系统；杠杆 ≥1.3x 期间，禁止无信号、无催化剂的左侧买入。**

依据：

1. 生存数学：担保率 229.66% 距 130% 强平区约 -43% 组合跌幅，届时净资产约 -77%；左侧定义上买入下跌中的股票并延长浮亏期，与 1.77x 杠杆互斥。融资利息约为净资产 3.5-4%/年，是左侧等待的负 carry。§13.1 的 -8% 去杠杆线在 1.77x 下对应组合仅约 -4.5%，正常左侧建仓期即会击穿：左侧路线与本体系风控规则数学互斥。
2. 收益钳形：无杠杆左侧优质价值的全周期底数约 10-15% 年化，低于 20% 底线；带杠杆则回到第 1 条。该路线在自身收益要求下自我否决。
3. 行为证据：8/8 持仓体系外建仓、业绩预告后 +31% 追入、自设锁定期防过度交易，均为高行动倾向证据。左侧没有行动配给机制，行动能量会以"价值加仓"名义泄洪（迈瑞 200/180 两笔即是）；右侧把行动配给到信号日。小资金唯一的结构性优势（进出速度）只有右侧能变现。
4. 语录还原：巴菲特"小资金可做 50% 年化"指微型股与特殊情况套利，且其终生反对 margin（"聪明人破产三途：酒、女人和杠杆"）；该语录不构成杠杆左侧的依据。

左侧重启条件（全部满足后，可再议一个无杠杆左侧底仓 sleeve，在此之前本决议持续有效）：

1. 总杠杆 ≤1.1x。
2. 连续两个季度体系内执行（无 off_system 买入）。
3. 接受该 sleeve 预期年化 12-15%。
4. 以股息型低估优质为主，单票 ≤10%、不摊平、保留年报级 thesis 复核。

注意：买入低估好公司的合法通道现已存在——§9.1 第 5 条"极度低估且有催化剂"+ 工作流 §13 纯左侧首笔限 5%。本决议否决的不是价值投资，是"杠杆下不等确认就买、买了不设止损"。（2026-07-17 更新：上述左侧通道随工作流 v1.02 关闭，用户同日明确"整个工作流程仍然拒绝左侧买入"；低估好公司的最早合法买点改为工作流 §8.13 一段——底部/平台首根有效放量大阳线，L1×低估适用。本决议与左侧重启条件本身不变。）

### 17.5 2026-07-29 上涨型警告去除的 R5/R7 评估（工作流 v1.21）

用户指令原述：**"如果没有触发估值水平变化，或者趋势走坏，不应当提出类似超限这种的警告……如果我持有的股票涨了十倍直接变成第一大重仓，我不希望走势如此之好的股票期间一直被警告，给我增加恐慌心态，然后错过大牛股。"** 提出当日账户净值创新高（回撤 0%），形式上落在 R7「盈利期/净值新高期提出拆除体系防护层」的适用场景，故按 §17.3 第 6 条逐项评估，结论与依据如下（如实留痕，供用户复核）：

| 被改动项 | 是否防护层 | 评估 |
| --- | --- | --- |
| 单笔风险**持仓监控版**预警 | 否（纯提示，从不阻断任何操作） | 该指标 = 持股数×(现价−割肉价)÷净资产，在股数与割肉价固定时是现价的**单调增函数**——只可能因上涨触发、下跌反而收敛，与 §17.4 已撤销的止损网格同构。**新开仓 1.5% 校验（§13.2 原文"战术和右侧新开仓必须满足"）完整保留**，故未删除任何买入前置条件 |
| 结构上限的**被动漂移**预警 | 部分（上限数值本身是硬约束） | **数值与主动口径硬拦全部保留**：新建仓/加仓越限仍不得买（R5「单票超上限、全仓集中」的拦截路径原样有效）。改变的只是"既有持仓因上涨被动越限"的处理——由逐日预警+减仓建议改为禁止加仓+每 10 个百分点台阶的六项持有资格复核（§2.1）。此项本身在解决体系内既有冲突：§12「盈利后减仓与十倍股保护」明确 >+500% 停止机械卖出、10 倍保留永久底仓，与逐日"超限→减仓"警告直接矛盾 |

| **R7 盈利期拆除防护层** | **命中** | 这是**结构性拆除防护层**的教科书形态：删除的是账户级下行保护本身，且是 §17.1 迈瑞病历唯一直接对应的机制。适用 §17.3 第 6 条 **5 个交易日冷静期**（前例：止损网格 6%/8%N 于 2026-07-20 提出、2026-07-27 满 5 个交易日经用户书面确认后撤销，见 §17.4） |

**用户理由经实测验算不成立，如实记录**（工作流 §14.7 存完整表）。以 2026-08-03 实际组合验算：净资产 2,996,560.39、持仓市值 4,695,028、**杠杆 1.57x**、峰值 3,078,731.02、16 只割肉价市值加权平均距现价 **−9.18%**：

| 触发的线 | 净资产阈值 | 持仓需下跌 | 届时已触及割肉价的只数 |
| --- | ---: | ---: | ---: |
| −8% 去杠杆 | 2,832,433 | **−3.50%** | **1/16** |
| −12% 黄色 | 2,709,283 | −6.12% | 2/16 |
| −20% 红色 | 2,462,985 | −11.36% | 14/16 |

机制是杠杆：**持仓每跌 1%，净资产跌 1.57%**，而逐票割肉价设在现价下方约 9%。反向验算同样成立——16 只**全部**触及割肉价时净资产仅回撤 **−16.7%**，连红线都没到。故「回撤一定不会先触发」在 −20% 一条上成立，在 −8%/−12% 两条上不成立，而这两条正是设计来早触发的。**这与 §17.1 迈瑞 2025-09 病历（担保率一度约 128% 逼近强平线）是同一机制**：杠杆放大组合波动，逐票止损管不住组合级回撤。

**这不构成拒绝执行。** 是否删除是用户的决定；本节的作用有二：①保证该决定建立在正确的算术上；②按用户自己在 §17.3 第 6 条设立的程序留出复核窗口。冷静期内的处理：照常计算，但**移出每日报告**，仅在实际触及阈值当日提示一行——用户想要的"报告里别再堆这些数字"的实际效果已经达成。2026-08-10 起用户书面确认即执行删除，届时按工作流 §15 修订并在 §16 与本节记录。
