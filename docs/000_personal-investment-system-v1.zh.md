# 个人投资体系 v1.30

执行流程、名单分类、质量分层、生产估值及买卖规则读取 [工作流程](000_Ashare_workflow.md)。本文件定义账户约束、研究标签与研究义务。

## 1. 研究与执行边界

1. 以持久竞争优势判断研究名单；以财务和经营证据复核优势及估值。
2. 业务逻辑被证伪或出现重大财务、治理事件时，按工作流程 §5、§7 复核名单与估值。
3. 买入、加仓、减持、换仓、止损及交易金额统一按工作流程 §9.3 执行。
4. 研究评分、市场状态、情景赔率和催化剂只作研究信息，不额外产生交易门槛或仓位动作。
5. 如实记录用户确认的成交、账户事实及其与执行清单的差异。

## 2. 账户与观察范围

- 观察名单及其迁移按工作流程 §5 维护；不按行业或公司数量配额筛选。
- 持仓、成本与止损锚按工作流程 §11 维护。
- 总仓位 = 持仓市值 ÷ 净资产；账户杠杆 = 总资产 ÷ 净资产。两者分别报告。
- 行业与产业链暴露按持仓市值计算，作为研究信息列示。
- 单次交易、单票上限、持仓只数和比例冷却读取工作流程 §9.3。

## 3. 市场研究

按主要投资市场跟踪代表指数、市场宽度、成交额及行业景气。市场状态仅安排研究优先级：

| 状态 | 优先研究方向 |
| --- | --- |
| 强势 | 产业链瓶颈、成长龙头、订单兑现 |
| 震荡 | 可防守增长、现金分配、公司催化剂 |
| 弱势 | 现金流、资产负债表、资源与成本优势的持续性 |

## 4. 账户硬约束

| 约束 | 口径 | 处理 |
| --- | --- | --- |
| 券商授信额度 | 可用资金与缺省估算统一读取工作流程 §10.2 | 超额融资时停止新增买入，卖出款先偿还超额部分 |
| 强平线 | 担保比例 = 总资产 ÷ 融资负债；阈值 130%；无融资负债时不适用 | 每日报告距离强平线的余量，触及时显式提示券商强平风险 |

融资基准、资金顺序与交易限制按工作流程执行。

## 5. 研究策略标签

每份研究档案指定一个主要标签，按价值驱动与可验证的经营特征分类。标签不决定质量档、估值模型或交易资格。

| 代码 | 策略 | 核心研究问题 |
| --- | --- | --- |
| A | 现金流复利型 | 赚钱方式、现金转化与再投资回报能否长期持续？ |
| C | GARP 成长型 | 增长能否防守，市场已计入多少增长？ |
| D | 产业链爆发型 | 供给瓶颈能否转化为公司的订单和利润？ |
| E | 落难白马型 | 困境是否暂时，核心优势是否完整？ |
| F | 资源 NAV 型 | 可计量储量、资源质量与成本位置如何？ |
| H | 成本曲线周期型 | 结构性成本优势能否穿越完整周期？ |
| J | 金融资本型 | 负债来源、资产质量与资本约束是否支持持续回报？ |
| K | 稳态现金分配型 | 现金分配、资产寿命与定价机制是否可持续？ |
| M | 管线/研发资产型 | 管线、研发效率与现金储备是否支持兑现？ |
| N | 订阅/递延收入型 | 续费、获客成本和现金流是否支持盈利路径？ |
| P | 在手订单兑现型 | 合同、排期、成本和回款是否锁定？ |

### 5.1 A：现金流复利型

核验重复需求、自由现金流、长期 ROE/ROIC、维持性资本开支、提价或成本转嫁能力、利润率与资本配置。跟踪回报结构性下降、低效扩张、分配纪律恶化和替代技术。

### 5.2 C：GARP 成长型

分别拆解行业空间、市占率、价格与利润率；核验增长的不可复制来源、跨周期回报和现金转化。跟踪费用投放、应收与库存、价格战及增长对融资的依赖。估值读取工作流程 §6，不用 PEG 代替生产模型。

### 5.3 D：产业链爆发型

分别确认真实需求、供给瓶颈及上市公司利润归属。记录证据阶段与下一可验证里程碑：

| 阶段 | 证据 |
| --- | --- |
| 线索 | 行业趋势、传闻或概念，尚无公司受益证据 |
| 产品 | 公告、送样、合作、产能建设 |
| 客户 | 客户验证、订单及收入路径 |
| 财报 | 收入、毛利率、利润与现金流兑现 |
| 持续性 | 多期兑现及竞争优势强化 |

阶段只用于跟踪研究进展；买卖执行读取工作流程 §9.3。

### 5.4 E：落难白马型

区分估值回落、暂时业绩受损与商业逻辑破坏。核验核心业务、现金流、盈利预期、资本配置及困境修复证据。商业逻辑破坏时按工作流程 §5 复核名单。

### 5.5 F：资源 NAV 型

存在可独立计量、来源可核实的储量或资源资产时使用 F；无可计量储量而依靠成本曲线优势的归 H。核验储量口径、品位、可采年限、成本、储量替代、供给约束、负债、并购及分配；检查上一轮低谷的盈利和现金流。

### 5.6 H：成本曲线周期型

核验单位成本处于行业前 25% 的证据、上轮低谷盈利或正经营现金流、可比产品价格中枢与价差、负债及扩产计划。成本优势须来自结构、规模或工艺。跟踪同业工艺追平、行业扩产、需求永久下降和高位资本开支；不得把周期顶部利润当作中枢。

### 5.7 J：金融资本型

银行、保险和券商按各自业务核验长期同业回报、资本约束、治理与分配。银行另核验低成本负债来源、净息差、非息收入、不良生成与认定、拨备、逾期和不良的差异及股权融资摊薄。名单准入按工作流程 §5；不得用普通工商企业的净现金或自由现金流口径代替金融企业分析。

### 5.8 K：稳态现金分配型

核验可持续分配现金、分红承诺、剩余资产或经营年限、监管或合同定价、资本开支和融资成本。研究情景的永续增长假设不超过 3.5%；生产模型参数读取工作流程 §6。跟踪举债分红、监管回报变化和低回报投资；结合资产性质分析杠杆。

### 5.9 M：管线/研发资产型

核验商业化品种或现金支撑路径、管线阶段、适应症、竞争格局、研发效率、授权条款及现金消耗年限。现金须能支撑至少两年或有确定融资安排。一次性授权首付款与概率性里程碑款单列为研究证据，不当作持续盈利；生产输入按工作流程 §6 处理。

### 5.10 N：订阅/递延收入型

核验合同负债与递延收入合计占年收入至少 25%、订阅收入占比至少 30% 及其变化；跟踪金额续费率、获客成本回收、盈利路径与切换成本。区分费用化获客投入、一次性许可收入及项目收入。

### 5.11 P：在手订单兑现型

核验已签合同的价格、数量与至少两年的交付排期，以及成本转嫁或锁价、产能、客户信用和回款。意向订单、框架协议和战略合作不计入；排期不足两年时按 D 或 H 核验分类。跟踪取消、延期、新签价格下降与应收、合同资产异常。

## 7. 评分

质量评分、对象、层级及字段以工作流程 §5.7 和其引用的评分细则为准。参考分只用于同层排序，不混入估值、催化剂和右侧信号。

## 8. 情景研究

对需求、订单、利润率、资本开支、政策与竞争建立 Bear/Base/Bull 情景，写明假设、证据与失效条件。报告 Base 上涨空间与 Bear 下跌空间的比值；不将情景赔率作为额外买入门槛。

先反推市场隐含的增长或盈利假设，再写情景差异。市场空间至少取两个独立来源的较低值；可达份额不高于当前份额两倍及行业第一名份额；成熟期利润率取可比成熟水平。研究情景不覆盖生产估值。

## 9. 研究响应

1. 按工作流程 §7、§11 跟踪持仓与当日合格标的。
2. 观察池公司突然放量上涨后 24 小时内核验事件真实性、个股与行业归因、公告或客户证据、瓶颈位置与利润贡献。
3. 新证据影响名单或估值时进入相应复核流程；交易清单由工作流程 §9.3 生成。

## 13. 组合研究

浮亏超过 30% 时复核最新财报、订单和产业证据是否仍支持名单判断，结论按工作流程 §5 处理。组合集中度、行业暴露和杠杆作为事实报告，不增加独立交易动作。

## 14. 复盘

| 频率 | 内容 |
| --- | --- |
| 每日 | 工作流程要求的持仓、合格标的、披露、重大事项与行业指标 |
| 每周 | 投资逻辑、质量变化、兑现里程碑、账户硬约束余量及下周重点跟踪名单 |
| 每季度 | 收入、利润率、利润、现金流、应收、存货、资本开支、管理层指引与订单偏差 |
| 每年 | 相对基准收益、回撤、胜率、盈亏比、执行差异及可避免亏损 |

连续四个季度累计跑输基准超过 10 个百分点时做书面复盘；规则修订按工作流程 §12 执行。
