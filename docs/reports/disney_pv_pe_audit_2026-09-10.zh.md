# 迪士尼 P/V 与 PE 差异核验（2026-09-10）

> 后续处置：两项缺陷已在 v4.180 修复并重建全海外估值，见[修复核验](overseas_valuation_fix_2026-09-10.zh.md)。海外利息缺陷原编号 OI-175 因重号改为 OI-177，薄权益为 OI-176。下文保留修复前审计记录及当时编号，当前生产值以修复报告和清单为准。

**结论：约 20 倍 PE 可以复现；P/V 3.96 则同时含取数错误和强烈的历史归一化假设，不能直接解释为可靠的“高估近三倍”。** 本次完成单公司原因核验和隔离复算，没有修改生产引擎、估值带、质量评级或交易规则。两项实现缺陷登记为 OI-175／OI-176。

统一采用当天[核心池阅读版](../000_a_share_core_valuation_pool.md)中的价格 **104.81 USD**，不将它称为另行获取的美国当日收盘价。原模型带 23.81～29.11，中值 26.46；底层未舍入值 26.460258，对应 P/V 3.961035。财务观察点为截至 2026-06-27 的 TTM，公开证据日 2026-08-05。

**PE 的分母是什么。** FY2025 稀释 EPS 为 6.85、FY2025 前九月为 6.12、FY2026 前九月为 4.12，因此滚动 EPS ≈ 6.85 − 6.12 + 4.12 = **4.85**，同价 PE = **21.61**。季度 EPS 的加总使用各期加权股数，故与供应商按滚动利润／股数计算的 PE 可以略有差别。[FY2025 年报](https://investors.thewaltdisneycompany.com/files/doc_financials/2025/ar/2025-Annual-Report.pdf)、[FY2026Q3 财报](https://www.sec.gov/Archives/edgar/data/1744489/000174448926000056/fy2026_q3xerxex991.htm)

调整后口径则是 5.93 − 4.82 + 5.25 = **6.36**，PE **16.48**。它剔除了部分重组、减值、并购摊销及税务项目，不等于 GAAP 盈利，也不等于股东自由现金流。约 20 倍的观察本身不需要用“预测 PE”才能解释。[FY2025 全年业绩](https://investors.thewaltdisneycompany.com/files/doc_events/2025/11/q4-fy25-earnings.pdf)、[FY2026Q3 调整后指标调节表](https://www.sec.gov/Archives/edgar/data/1744489/000174448926000056/fy2026_q3xerxex991.htm)

**已确认的取数错误：利息费用符号未统一，且污染 TTM。** 原始 SEC companyfacts 中，FY2023／2024／2025 的 `InterestExpense` 分别为 −1.973／−2.070／−1.812 billion USD；FY2026Q3 申报中的本期和上年同期累计值却为正的 1.379／1.396 billion。报表附注确认这些都是利息费用，不是利息收入。[FY2025 年报第 98 页（PDF 第 102 页）](https://investors.thewaltdisneycompany.com/files/doc_financials/2025/ar/2025-Annual-Report.pdf)、[FY2026Q3 10-Q 利息附注](https://www.sec.gov/Archives/edgar/data/1744489/000174448926000057/dis-20260627.htm)

当前 `fetch_overseas_statements.sec_current_extract` 原样计算 `−1.812 + 1.379 − 1.396 = −1.829`，随后 `_build_row` 按 `EBIT = pretax + interest_expense` 又把费用减了一次。正确流程必须先把三个费用金额统一到正值，再计算 **1.812 + 1.379 − 1.396 = 1.795**。不能只对最终 −1.829 取绝对值。

以上是保持其他输入与规则不变的因果复算，校正不止作用于 TTM，也作用于历史 ROIC、归一化比率及债务成本。当前已落库美股行中，负利息费用只检出 DIS 的三条年报及一条 TTM；未据此推断其他公司的所有字段均正确。初步仅对合成 TTM 取绝对值的 37.68 是错误修法的中间读数，正式结论采用 **37.83**。

**为何纠正后仍显得贵：五年历史中位数把它送入零增长。** 修正后 FY2021～FY2025 的 ROIC 序列约为 3.06%、3.40%、3.48%、5.16%、9.21%，中位数 **3.48%**，仍低于引擎增长路径要求的 **3% 终值增长＋2 个百分点利差＝5%**。于是即使近期利润恢复，路径仍是 `zero_growth`。这是现行模型规则的结果，不是公司明确没有增长机会的财报结论。

历史投入资本按总权益＋有息负债−超额现金计算，保留并购形成的资产和商誉。Q3 商誉为 74.682 billion USD；其规模说明应区分历史并购资本回报与今后的增量投资回报，但不能直接据此将商誉剔除或抬高估值。[FY2026Q3 10-Q 商誉附注](https://www.sec.gov/Archives/edgar/data/1744489/000174448926000057/dis-20260627.htm)

**还有第二次盈利压缩。** 校正利息后，当前 NOPAT／经营账面比率为 9.664%，历史长窗中位为 6.135%；峰值守卫权重 45.88%，将未做峰值压缩的每股锚 **6.3748** 降到 **4.9300**。模型无法仅靠这个比率判断上升来自周期高点还是流媒体、乐园等业务的持续修复。因此，如何看待修复持续性是需要业务证据判断的问题，不能由低 PE 或高 P/V 任一指标代替。

分解依赖操作顺序，不能把不同情景的价差当作互相独立、可任意相加的因素贡献。

**负债使相同的经营价值折价放大为更大的股权折价。** 原模型 `V = 4.1518 / 7.5568% − 28.4815 = 26.4603`。扣减中，净金融负债约 24.5744／股、少数股东账面下界约 3.9071／股。这里的 NOPAT 是付利息前的利润，PE 的 EPS 是付利息后归母利润；修正费用符号后，企业价值再减债务本身并非重复扣债。原 V 对应 GAAP TTM 隐含 PE 仅 **5.46 倍**，所以市场 21.61 倍会变成 P/V 3.96。

同时，原固定扣减／企业价值 = **28.4815 / 54.9417 = 51.84%**。按工作流 §6.5.1／§6.5.2.4 的薄权益守卫，这一原始输入应判“无法估值”，不输出 P/V；`build_overseas_roic_bands.value_company` 的零增长与增长路径均未实现该守卫。校正利息后该比率为 **42.95%**，迪士尼本次不再触发；漏检本身仍需单独修复，不能因个案恢复而视为结案。

**判断限度与复现。** 当前约 20 倍 PE 是真实可对账的读数，却不能独自证明便宜；P/V 3.96 也不是稳健的“严重高估”证据。需要先修复取数及守卫，再评估历史低盈利、并购资本和盈利修复是否适合沿用当前归一化规则。FY2025 特殊税收收益令模型税率被夹到 0，和 TTM 的 27.56% 不同，因此年报到 TTM 的 NOPAT 下滑还含税务基数变化，不能直接视为主营衰退；本次未另做税率或利润调整。[FY2025 年报](https://investors.thewaltdisneycompany.com/files/doc_financials/2025/ar/2025-Annual-Report.pdf)
