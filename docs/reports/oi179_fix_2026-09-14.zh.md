# OI-179 修复、基线重登与信号复核（2026-09-14）

OI-179的报价日匹配遗漏已修复。历史均线、复权价格和量比现在纳入停牌期间的全部除权事件；相关性收益序列与常设前向回报工具的同源遗漏也已修复。机制修复通过轨道A护栏，正式BASE重登为`ca2`版本，原生产择时和资金参数未变。

**修复与实际影响范围**

原`exright_affine`只取`events.get(股票报价日)`，因此除权日股票停牌时，事件不会进入折算。新实现独立遍历完整事件日历：历史价到T日只处理`(历史报价日,T]`内的事件；同一停牌区间多次现金分红、送转、配股按日期顺序复合；当天报价已经除权，首日及范围外事件不重复应用。均线窗口仍只数有报价日，不能因停牌补造均线样本。

收益序列共用`quote_action_factors`承接两次报价间的股数倍数及净现金。先按事件发生时的股数派息、送配和扣认购款，现金在下一可得收盘价再投。`moat_param_lab.total_return_index`补齐此口径，其调用者包括排序、面板前向收益及换仓对照工具。持仓公司行动按市场日历处理，使用相同日期取事件并不意味着会漏掉某只股票的停牌日；逐路径审计范围见[源码审计](../../data/experiments/exp_oi179_20260914/source_audit.md)。

296只缓存股票中，58只存在73次无报价日事件；修复改变1355个MA20值、4170个MA60值、285个严格趋势判定和72个相邻报价收益点。这是缓存全集的覆盖审计，不是实际交易笔数。
