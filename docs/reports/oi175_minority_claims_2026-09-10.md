# OI-175：少数股权请求权与股权桥修复

核验截止2026-09-10，北京时间。用户要求登记并解决；登记提交为 `a445503d`，规则落地为工作流程v4.179、§6.5.1。本项解决模型去重、持股变化后的口径失效与旧带回退；紫光当前合同请求权未能完整计量，结果为**无法估值**，不填入替代目标价。两家公司维持 `boundary_pending`。

## 证据与判断

1. [2024-09-05交割公告](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=10468964&stockid=000938)披露30%收购已付款交割，持股将由51%变为81%、股东名册手续在办。该日足以认定旧股权桥需要复核，不能等待2025年年报才标记持股变化。事件登记只使用当时公开的事实；未将2026年合同金额回填到该日。[2024年报](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=11044954&stockid=000938)另登记2025-04-29版本。
2. [2025审计报告](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12088791&stockid=000938)披露19%新华三股权期权远期负债95.4016亿元，列一年内到期的其他长期负债；结构化债务字段 `NONCURRENT_LIAB_1YEAR` 已包含它。旧模型同时使用2021—2025年少数盈利份额中位42.326%，存在权利覆盖重叠及历史份额滞后。2025集团少数损益4.8556亿元，小于新华三少数损益5.9878亿元，不能拿新华三19%或当前12.02%直接替换集团盈利占比。
3. [2026中报](https://money.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12565854&stockid=000938)披露旧19%远期终止，新10.06%回购远期44.4610亿元、少数股东分红远期7.9178亿元；两项列**其他非流动负债**，没有进入现有 `DEBT_FIELDS`。因此Fable所说下一年必然原样双扣不够准确：还存在漏计及转入流动科目时跳变的风险。
4. [2025-11-18投资协议公告](https://disc.static.szse.cn/download/disc/disk03/finalpage/2025-11-18/008e5307-2a50-4cba-b8c2-e25de01082bd.PDF)第1.1—1.5条包含通过上市公司发行股份／可转债等收购少数权益的“上翻交易”：价格参考届时评估及可比估值协商，未完成或发生约定事项时才有现金回购安排。[11月29日配套公告](https://disc.static.szse.cn/download/disc/disk03/finalpage/2025-11-29/d43837cd-6faa-41d1-8f84-6678ef0a4f72.PDF)提供后续权利安排。固定回购负债不能当然替代全部存续权益，当前不能把44.46亿元直接当作取得10.06%全部经济权益的终局对价。

据此同意Fable的核心缺陷判断，修正其“下一年必然双扣”的断言；其替代价格不能升级为合理价。

## 原模型偏差诊断

原2026H1模型每股EV29.8956元、净金融负债9.0004元、外生权益0.3995元；少数扣减约8.8442元/股，合252.95亿元。这是全部少数权益扣减，**不是已证明的双扣金额**；也不能用它与新华三少数账面22.47亿元的差额定义估值误差。

| 固定原EV的诊断口径 | 每股IV（元） |
| --- | ---: |
| 原模型 | 12.4505 |
| 仅改用2025实际集团少数盈利占比22.365% | 16.6215 |
| 再移出旧19%远期负债 | 19.3515 |
| 移出旧远期、直接使用12.02%子公司持股缺口 | 21.8769 |

后两行沿用原模型账面缩放：95.40亿元在模型中约为3.5165元/股，直接除实际股数则为3.3356元/股。说明股权桥之外也有账面缩放与交割现金时点问题，不能只调整 `m`。最后一行混用集团与子公司分母，专用于说明敏感度，不能采纳。旧权益退路19.76—24.15元也不因此自动恢复有效。

## 实现与恢复条件

规则只在[工作流程§6.5.1](../000_Ashare_workflow.md)定义；[事件表](../../data/reference/minority_claim_events.json)登记证券、权利事实、报告期、`known_from`及原始来源，不接受目标价或手填盈利份额。核清固定退出、存续权益、同期期末债务现金与合并利润后，由[scripts/minority_claims.py](../../scripts/minority_claims.py)生成不重叠扣减；科目迁移不改变经济结果。已登记公司每份新报告须有对应完整快照，旧快照不能永久沿用。

紫光四个已核验版本均为 `unresolved`。模型会明确拒绝，档案及阅读页清空原合理价；候选、B2、持仓、逐日状态和预告叠加均阻断旧带回退。即使事实后来补齐，同报告期旧缓存也必须按相应事件版本重建后才能恢复。固定退出完整路径以**合成会计案例**验证，不把这些案例当作紫光估值。

后续公司研究任务：逐项核清投资者上翻／现金退出的条件、可变对价与分红覆盖；配齐交割后同一报告期股数、合并权益、债务、现金、各主体少数权益，以及可比合并利润。达到标准后从事实重算，不以当前股价倒推。该待核验项写入紫光档案复核条件；模型缺陷结案不等于公司已可估值。
