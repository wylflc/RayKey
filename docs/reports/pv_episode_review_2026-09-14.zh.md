# P/V 收益、排名第1与重复触发核验（2026-09-14）

用户记忆对应的是旧表中 **P/V 第1名随后750个交易日的累计总回报中位数94.44%**；随后250日为28.08%。旧样本包含趋势筛选，按股票×日期重复记录。冻结原候选日志后，两项原始样本数与四舍五入中位数已完整复现。

## 1. P/V 差值怎样影响收益

设 `q=P/V`。在同一股本口径下，价格回报的恒等式为：

`1 + R价格 = P终 / P初 = (q终 / q初) × (V终 / V初)`。

投资总回报还含期间股息，融资账户还扣融资成本和交易成本。P/V 低只表示每单位**模型估值**的买入成本低；实际回报取决于价值随后变化、估值比率变化及现金分配。V 下修也能让低P/V消失，并不需要股价上涨。

若V保持不变且价格最终回到V，累计上涨空间为 `1/q − 1`。P/V从0.95换成0.80，两个比率差0.15；对应空间为5.26%与25%，相差19.74个百分点。需要多久达到并未由该差值给出，V是否可靠也未由该差值证明。

当前换仓边际0.15是**两个P/V的绝对差**，不是换入股票便宜15%、也不是预期多赚15%。阈值提高会要求更大的估值差才触发换仓；降低会放行较小差值，但实际收益同时受交易频次、资金流向和持仓路径影响，不存在“每增加0.01就固定提高多少年化”的换算。历史剂量扫描也非单调；旧实验不能当作今日因果系数（回测日志§12.149～12.152、§12.217）。

9月14日电投持仓侧P/V0.9826、成都银行候选侧0.8424，差0.1402，未达到0.15。若各自V不变且均回到P/V=1，空间分别1.77%与18.71%；这只是条件算例，不是两者未来一年的收益预测。

## 3. 冻结同一份旧排名：去重结果

下表只改变计数，保留原估值版本、候选日志和旧收益计算，以隔离重复权重；固定期回报均不因MA60破位截断。

| 计数方法 | 约一年中位 | 完整窗口 / 公司 | 约三年累计中位 | 完整窗口 / 公司 |
| --- | ---: | ---: | ---: | ---: |
| 旧表：每天记录第1名 | 28.08% | 2,833 / 66 | 94.44% | 2,322 / 45 |
| 首次第1名至跌破MA60计一次 | 28.39% | 362 / 66 | 84.13% | 282 / 45 |
| MA60周期＋同股窗口不重叠 | 18.29% | 153 / 66 | 81.11% | 67 / 45 |
| 锚止损周期（辅助对照） | 20.36% | 159 / 66 | 88.45% | 117 / 45 |

**结果支持“重复计数影响权重”，不支持“高回报全部是重复计数造出来的”。** 按MA60周期去重，一年中位几乎不变，三年由94.44%降至84.13%。进一步不重叠后一年为18.29%、三年81.11%，但三年只有67个完整窗口、45只股票，且不同股票共享市场阶段。这些是不同抽样口径的描述，不能把中位数差直接解释为策略收益改善或偏差的精确大小。

一个权重例子：旧一年表中陕西煤业391行，单只占13.80%；原三年表中它305行，占13.14%。每日重复不必然上抬中位数，若反复入选的是持续下跌或横盘股票，也可能下拉。

MA60去重共394个信号周期，一年完整362、缺32；三年完整282、缺112。缺失包括1个周期原执行日无报价，其余为后续行情不足。逐日原表8条执行日无报价仍保留缺失记录。锚止损对照有1次研究锚顺延至下一报价日（电投2012-05-11信号，原2012-05-14停牌），该次原执行日收益仍记缺失，不用顺延价格冒充成交。

再投收益实现敏感性：补入配股认购成本及停牌期间公司行动，原逐日中位改为一年28.32%、三年95.29%；MA60周期中位仍为28.39%/84.13%，严格不重叠仍为18.29%/81.11%。主表使用旧实现，避免把这项收益实现差异混入去重影响。

## 5. 计数具体实现及限制

1. 每股处于“可计数”状态，首次满足指定信号就记录一次并锁定；研究不要求当日账户真能买入。
2. 此后每天检查收盘是否低于当日复权MA60。暂时掉出第1名、P/V变贵、MA20波动、估值缺失或暂离面板均不解除锁定。
3. 跌破MA60结束周期；以后重新满足指定信号才计新的一次。止损日即使满足其他条件，也不能绕过严格趋势条件。
4. “一年/三年后回报”继续量到固定终点，不能只保留未止损的赢家。在rank1一年MA60去重的362个完整窗口中，361个在收益终点前已破MA60，全部保留。
5. 同股窗口不重叠是额外检查：从周期首信号中按时间保留，前一保留窗口结束前的新周期不入该组；到期后不凭空制造新信号。250/750日分别去重，所以两列不是同一批信号。
6. 现行交易止损线为 `min(成交日MA60锚,当日MA60)`，并非单纯跌破当日MA60。锚止损周期只以该线重置，期间普通减仓/换出不另行模拟，因此也不等于真实组合持仓周期。

行情末端不同：133只当前便宜股票中52只至2026-08-28、80只至2026-08-07、深赤湾A至2018-12-20；没有用9月14日实时报价假装更新历史缓存。缺少终点的退出股票未假造回收价，仍有删失偏差。原逐日排名表完整窗口的自然日时长中位约一年377天、三年1133天，不是精确365/1095天。

历史面板构建、估值模型误差/历史财报修订、首段左截断、终点删失及共同市场阶段仍会影响统计。减少同股重复能改善样本权重，但并不自动产生独立样本或证明预测因果；长期重叠回报的推断问题亦见[美联储方法论文](https://www.federalreserve.gov/pubs/ifdp/2006/853/revision/ifdp853r.htm)。本批未作显著性检验，未运行新的组合参数择优；绝对数不作为实盘预期。
