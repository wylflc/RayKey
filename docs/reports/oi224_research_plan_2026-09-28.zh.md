## 二、陷阱识别的结果（第一步已完成）

完整读数见 `data/experiments/exp_oi224_traps_20260928/`：预登记、`results.json`，作业 27290636。

- **样本**：买入区（v4.210 生产状态 `P/V ≤ 1.0670`）的非银行保险在册股票月，共 1,715 个，涉及 61 家公司；其中陷阱 203 个（11.8%）、机会 627 个（36.6%）。
- **判据**：预先定下三条——全样本 AUC 下限 > 0.55、三个时段同向、最差一档陷阱占比 ≥ 1.5 倍且不多砍机会。
- **结果**：15 项特征中只有 E1（近三个财年经营现金流合计 ÷ 归母净利合计）通过。

| E1 分档（主样本） | 月数 | 陷阱占比 | 机会占比 |
| --- | ---: | ---: | ---: |
| 最好（> 1.72） | 343 | 0.6%（0.05 倍） | 46.6% |
| 次好（1.37～1.72） | 348 | 9.8% | 37.1% |
| 中间（1.11～1.37） | 332 | 17.2% | 29.8% |
| 次差（0.84～1.11） | 342 | 10.8% | 42.4% |
| 最差（< 0.84） | 350 | 20.9%（1.76 倍，区间 1.16～2.47） | 26.9%（0.73 倍） |

- AUC 0.66（区间 0.59～0.73）。分时段：2007–12 为 0.55、2013–17 为 0.58、2018 年起为 0.75。
- **局限**：
  - E1 抓不住周期高点陷阱：海螺 2019（E1 1.23）、神华 2012（1.68）、潍柴 2011（1.13）、宇通 2015（1.15）都落在中间档。具名陷阱中只有长春高新 2022（0.74）落在最差档。
  - 放到全部在册月上 E1 没有区分力（AUC 0.52），信号只在买入区内。
  - 只有 61 家公司；15 项同时检验，存在多重比较。
- 其余特征都不达标：
  - 护城河类：十年 ROIC 高的公司在买入区反而更常是陷阱（AUC 0.40），可能是周期高点的高回报所致。
  - 行业增速、合同负债等：不稳或无区分力。
- 15 项合起来的滚动样本外 logistic 模型 AUC 0.46，组合无效。

## 三、候选规则（均为研究开关，生产缺省关闭；逐个单变量对 `BASE`）

| 臂 | 规则 | 预登记的相邻取值 | 实现 |
| --- | --- | --- | --- |
| `RE` 止损后重入 | 建仓止损清仓后 N 个交易日内，候选侧 `P/V` 仍 ≤ 买入线的，再建仓只要求收盘 > MA20（去掉 MA20 > MA60）；此类重入的止损锚取成交日 MA20 | N = 60／120／250 | 新开关 |
| `LS` 左侧分批 | 候选首次进买入区而走势未满足时，若近 5 日未创 20 日新低（现有 `stabilized` 判据），先建半档；走势满足后按常规补足一档。半档止损为较建仓价跌 X%，不用均线锚 | X = 15%／20%／25% | 新开关 |
| `DPs` 深度低估不作换出源 | 持仓侧 `P/V` < D 的持仓不作换仓卖出源 | D = 0.6／0.7／0.8 | 现有 `--swap-out-min-pv` |
| `DPt` 深度低估放宽止损 | 持仓侧 `P/V` < D 时，止损线改为 min(锚, MA120) | D = 0.6／0.7／0.8 | 新开关 |
| `SZ` 仓位挂钩估值深度 | 一档大小乘系数：`P/V` ≤ 0.6 为 1.5 倍，0.6～0.85 为 1.0 倍，0.85～买入线为 0.5 倍 | 断点平移 ±0.05 | 新开关 |

- 相邻取值用于看剂量方向与平台（§12.1 第 5 款），不取单点峰值。
- 杠杆、单票上限 60%、股债总仓位上限、融资与强平照 `BASE`。
