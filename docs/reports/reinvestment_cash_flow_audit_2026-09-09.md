# 净利润、再投资与估值覆盖核对（2026-09-09）

核对对象：工作流 v4.166 的 A 股生产路径、实际估值代码和本地候选侧生产带。结论：已考虑再投资与资本效率，但没有对每家公司独立预测维持性现金需求；不能把“采用 ROIC/FCFF 框架”理解为“已充分识别所有利润与可分配现金的差异”。本次为机制核对，未修改生产模型、参数、估值带或交易规则，未重跑历史回测，也未据此判定具体股票高估。

## 1. 原例需要先区分成本与投资

假定收入全部收现、成本当期付现、无其他调整：期初现金 100，支付经营成本 50，收入 150，期末现金为 `100 − 50 + 150 = 200`；下一年为 `200 − 50 + 150 = 300`。每年增加 100，而不是 50。每年支付 90、收回 190 也一样。保留下一轮经营所需的固定资金会减少一开始可取出的现金，但不能把同一笔周转资金每年重复扣除；需要从现金流扣的是营运资金的**增加额**。

用户关注的差异成立于利润之外仍有净现金占用的情形。无债务且忽略其他非现金调整时：

`自由现金流 = 净利润 + 折旧摊销 − 资本开支 − 非现金经营营运资金增加额`

| 同期示例（亿元） | 公司 A | 公司 B |
| --- | ---: | ---: |
| 净利润（已扣折旧） | 100 | 100 |
| 加回折旧摊销 | 20 | 20 |
| 扣除资本开支 | 70 | 110 |
| 营运资金增加额 | 0 | 0 |
| 自由现金流 | 50 | 10 |

这时当期自由现金流确实相差五倍。只有差异可持续、未来增长、风险与其他权益价值调整相同，才能进一步推导价值也相差五倍。维持性投入与能创造未来回报的扩张性投入要分开分析，不能仅凭某年自由现金流少就认定生意差。

会计口径依据：[SEC 财务报表入门](https://www.sec.gov/about/reports-publications/beginners-guide-financial-statements)；净投资与股权现金流关系：[Damodaran 第 11 章推导](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/AppldCF/derivn/ch11deriv.html)。有债务时 FCFE 还涉及净借款；当前 ROIC 主路径使用的是 NOPAT/FCFF 企业口径，再经净负债与少数股东调整得到股权价值。

## 2. 当前已经覆盖的部分

- [工作流 §6.3、§6.5.1](../000_Ashare_workflow.md)：当前 PE 不作为建带输入；非金融主路径用 NOPAT、投入资本、ROIC、增量 ROIC、再投资率与现金流折现。
- [再投资率实现](../../scripts/roic_inputs.py)：`reinvestment_rate` 按年度窗口合计计算 `(资本开支 − 折旧摊销 + ΔWC) / NOPAT`，并非只读取利润。营运资金取首尾差额，不逐年重复扣存量。
- [折现引擎](../../scripts/intrinsic_value.py)：`_required_retention` 根据下一年增长与回报率变化推导当年留存；每年折现的是 `NOPAT × (1 − 留存率)`。回报率恒定时留存率为 `g / ROIC`；ROIC 衰减时使用相容的变化公式，因此不能简单说显式期“不增长就完全不用投资”。
- [质量评分细则](../Ashare_quality_rubric.md)：Q1 包含维持性资本开支与现金转化，Q3 包含再投资效率，报表可信度核查现金流与利润长期背离。

本地 `a_share_pool_model_bands_adopted.csv` 共 181 行：growth 170、zero_growth 4、bank_divspread 7。此为带文件行数，包含会被后续时点守卫排除的陈旧带，不等于 181 家均可交易。银行与保险按现金分红路径处理，不套用普通工商企业的 FCFF。

## 3. 覆盖的边界

### 历史现金占用与未来现金预测没有逐项衔接

[建带实现](../../scripts/build_historical_valuation_bands.py) 在 `rr = roic_inputs.reinvestment_rate(history)` 读取历史再投资率；资本增长腿为 `min(增量 ROIC, 上限) × min(rr, 1)`。当前生产命令的 `--roic-trail-weight 0` 关闭利润增速腿。随后调用 `intrinsic_value(nopat_ps, roic0, g0, w, ...)`；历史 `rr` 不直接传入折现引擎，未来留存由增长与 ROIC 路径重新推导。

因此模型会通过增长、ROIC 与资产负债结构反映部分差异，但没有将历史实际 FCFF 与未来推导 FCFF 的差额逐项归因，也没有独立的“维持性开支超过折旧”输入约束。不同历史再投资率不保证等比例改变未来可分配现金。

### 维持性资本开支采用折旧代理

`roic_inputs.py` 明示“维持性资本开支 ≈ 折旧摊销”。建带器虽有 `owner_earnings_true_ps` 字段，计算实际是按每股口径缩放的 `CFO − 折旧摊销`，不是独立核验后的真实维持性开支。全仓检索该字段，只发现定义、赋值和写出；它没有进入生产价值计算或现金转化校验。该字段名称与“维持性资本开支全部实算”的代码注释不能代替实际调用证据。

若维持竞争力的实际现金支出长期高于折旧，或者净利润长期没有转化为收款，这种代理可能偏乐观。具体影响仍须核验公司现金流量表、固定资产附注、项目用途与营运资金变化，不能直接拿当年总资本开支当维持性资本开支。

### 零增长路径依赖更强的简化假设

当前零增长企业价值直接为 `NOPAT / WACC`，再扣净负债等调整。这个式子隐含维持性资本开支约等于折旧、无需持续追加净营运资金，且其他会计现金差异可忽略；未另扣独立核验的维持性净现金缺口。它也不能描述“每年利润不增长，却一直需要超出折旧的现金投入”的完整路径。

代码保留研究开关 `--roic-zero-anchor fcff`，但生产缺省为 `nopat`。该开关最多扣 50% 的窗口净再投资率，不能直接代表 90% 的持续现金占用。历史 [§12.103 的 OI-073 核验记录](../archive/Ashare_backtest_log_2026-08-10_to_2026-08-24.md) 曾检查这一变体，指出历史净再投资混含扩张性开支，不能直接作为零增长维持负担。本次未复跑该历史实验；该旧结论也不证明每家公司的真实维持性开支已经被准确估计。

## 4. 本次复核与解释限度

直接调用现有 `reinvestment_rate` 与 `intrinsic_value` 做了三个小型算例（没有修改函数）：

1. 构造年度 NOPAT=100、折旧=20、营运资金恒定，资本开支分别 70/110，历史再投资率输出 0.5/0.9，自由现金流桥为 50/10。
2. 稳态增长率 5%、折现率 10%、当前 NOPAT=100，令 ROIC 分别恒为 10% / 5.5556%，对应留存率 50% / 90%；引擎输出首年 FCFF 52.5 / 10.5、企业价值 1050 / 210，恰好相差五倍。这说明底层公式确实能表达相同利润、不同资本效率的差异。
3. 令 ROIC 恒为 12%、增长率与终值增长率均为 0、折现率 10%、NOPAT=100，引擎输出首年现金 100、企业价值 1000，体现没有额外维持性净现金缺口的假设。

第 2、3 项为公式边界算例，不是按生产的统一终值参数为真实公司重新建带；第 1 项也不构成两套完整资产负债表。它们验证计算与假设，不能量化当前核心池的估值误差。

后续若扩展模型，应先核对“归一化利润 → 实际经营现金流 → 维持性支出后的现金 → 扩张再投资 → 模型未来现金流”的衔接，区分暂时营运资金占用、维持竞争力的支出和创造额外回报的投资，再判断哪些差异应该改变生产参数。PE 可以作为同口径比较指标，但需要结合现金转化、资本效率和盈利持续性理解。
