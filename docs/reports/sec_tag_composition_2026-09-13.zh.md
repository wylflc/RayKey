# SEC 标签按经济含义组合：OI-178 修复核验（2026-09-13）

**结论：合并税前利润、有息负债与折旧摊销三类字段改为按经济含义组合后，18 家 SEC 申报公司逐行核对，15 家的历史输入有变动、11 家的合理估值带变化，除微软（+7.1%）外幅度均在 ±1.8% 以内；甲骨文因最新归母权益与优先股桥未披露齐全继续拒绝估值。** 规则写入工作流程 §6.8，唯一实现为 `fetch_overseas_statements.compose_sum`／`compose_debt`，年报与 10-Q TTM 两条路径同规，`tags_used` 逐行记录所用组合。

## 缺陷与组合规则

原提取器按标签清单顺序「先到者优先」取值，甲骨文 FY2026 暴露三处缺口（[甲骨文核验](oracle_review_2026-09-10.zh.md)）：境内税前利润 8.693b 被当作合并额（正确 19.554b）；只取流动债务 7.199b，漏掉非流动票据 122.342b；折旧 7.623b 未加无形资产摊销 1.671b。

| 字段 | 组合规则（按顺序取第一条分量齐全者） |
| --- | --- |
| 合并税前利润 | 合并标签 → 境内＋境外 → 持续经营净利（含少数股东）＋所得税 → 含少数股东净利＋所得税；境内单项永不单独使用，全部不齐则税前为空、EBIT 退回经营利润 |
| 有息负债 | 非流动：`LongTermDebtNoncurrent` → `LongTermNotesPayable` → `LongTermDebtAndCapitalLeaseObligations`（已含租赁）→ `LongTermDebt`（同期另有流动债务行时视为非流动行，否则视为含到期部分的合计）；流动：`DebtCurrent` 存在即整体取用（非流动层含租赁时视其同样含当期租赁），否则一年内到期长债＋短期借款（与到期长债金额相同视为同一行）；融资租赁非流动＋流动，缺拆分取合计；经营租赁不计 |
| 折旧摊销 | 合计标签 → 折旧＋无形资产摊销 → 仅折旧（记标签） |

`LongTermDebt` 的两种口径来自申报实践：Adobe、特斯拉用它标注资产负债表的非流动行（Adobe FY2024：4,129 + 流动 1,499 = 5,628），微软用它标注含到期部分的合计（FY2026：40,294 = 31,067 + 9,227）；只有非流动标签缺失时才会用到该判定。`DebtCurrent` 是否含当期融资租赁按报表两行同口径推断（美光「Current debt」560 与当期融资租赁 560 相同）。这两条启发式无法从标签本身证明，`tags_used` 保留组合以便逐行复核。
