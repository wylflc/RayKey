# 滚五配对差中位数：指标含义与股债约束复核

分析日期：2026-09-09。对象为 EBDS03（股债利差低于 3pp 去融资、其余恢复 BASE）对 BASE；全样本与剔除赢家 A 各 14 个起点。本次只诊断汇总方式，不改变策略、计量版本、采纳门槛或既有实验判定。

**结论：现行指标有明确的描述含义，但不能代表“同一五年窗口通常多赚多少”，也不能代表长期财富增益。对于用户明确的“顶部去融资、减少回撤、持续复利”目标，建议保留它作为持有期分布诊断，重新评估其并列硬门槛地位。滚五相对表现宜补充同窗口先相减的读数；不能因为新读数在本候选上为正，就直接换门槛或采纳候选。**

本次重新导出 28 条 BASE 净值、逐字段复核原摘要，并复现 BASE/候选共 56 条路径的滚五摘要；完成 2,856 个同日历窗口配对。全部读数仍沿用原 m2 记账，继承 OI-169/170，不能认定为已修复后的业绩。

## 1. 三个容易混淆的量

记 `r(s,t,C)` 为候选在账户起点 s、五年日历窗口 t 的年化收益，B 为 BASE。

| 量 | 算法 | 回答的问题 |
| --- | --- | --- |
| 现行 M | `median_s[median_t(r_C) − median_t(r_B)]` | 多个账户起点中，两臂各自典型五年收益的差，居中是多少？ |
| 同窗口 P | `median_s[median_t(r_C − r_B)]` | 同一账户起点、同一五年窗口，收益差居中是多少，再跨起点汇总？ |
| 水平差 L | `median_s[median_t(r_C)] − median_s[median_t(r_B)]` | 两臂的汇总分布中心相差多少？不保持起点配对。 |

M 在**账户起点层**进行了配对，但先在每条路径内分别排序求中位数，丢掉了收益对应的具体日历窗口。P 保留了窗口配对。两者都是定义明确的统计量，回答的问题不同；M 不是代码算错，P 也不是它的代数等价变换。

对自然配对的观测先计算对应差值，是常见的配对分析方法；这支持 P 的比较单位，**不代表这里适用独立样本 t 检验，也不证明 P 能预测未来收益**。[NIST 配对观测定义](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)

一个纯数学例子，三个相同窗口的年化收益分别为：

| 窗口 | BASE | 候选 | 同窗口差 |
| --- | ---: | ---: | ---: |
| 1 | 5% | 9% | +4pp |
| 2 | 10% | 9% | −1pp |
| 3 | 20% | 21% | +1pp |

两臂中位数之差是 `9% − 10% = −1pp`，同窗口差的中位数却是 `median(+4,−1,+1) = +1pp`。候选在两个窗口胜出，但分布中位数下降；它也确实损失了一个窗口。这正说明不能将“中位数之差为负”直接改写为“多数窗口落后”。

## 2. 本批真实数据确实发生反号

收益差的单位均为百分点；除特别注明外，跨起点保持各起点等权。

| 比较方式 | 全样本 | 剔除 A |
| --- | ---: | ---: |
| 现行 M：起点内中位数之差，再取中位 | −0.7806 | −0.1400 |
| 同窗口 P：窗口先相减，再取两层中位 | **+1.5225** | **+0.0163** |
| 起点内同窗口差取均值，再跨起点取均值 | +1.7875 | +0.3579 |
| 日历窗口等权均值：同窗口跨可用起点取均值，再跨日期取均值 | +2.7179 | +1.3060 |
| L：两臂水平中位数之差，仅描述 | +1.4803 | +0.5971 |
| M 为正的起点数 | 6/14 | 7/14 |
| P 为正的起点数 | 9/14 | 7/14 |
| 起点内同窗口胜率的中位数 | 62.30% | 48.12% |

全样本可以说“同窗口比较的典型增益为正”；A 的 +0.0163pp 接近零，不应描述为显著改善。A 的胜率中位数小于 50%而 P 略正，与偶数个起点取中位时平均中间两项的定义并不矛盾；两个量分别汇总幅度和胜率。

全样本 BASE/候选的滚五水平中位数是 52.00%/53.48%。它们相减为 +1.48pp，确实与原 −0.78pp 反号，但 **L 不能替代配对效应**。这次直接配对窗口的 P 也为正，提供了比单独比较水平更直接的依据。

几个逐起点例子说明这不是只在最外层才发生的现象：

| 组别、起点 | M 的起点内差 | 同窗口差中位 | 同窗口胜率 |
| --- | ---: | ---: | ---: |
| 全样本，2010-11 | −0.78pp | +1.78pp | 74.42% |
| 全样本，2012-05 | −2.10pp | +3.50pp | 63.06% |
| 全样本，2013-05 | −1.52pp | +1.26pp | 57.58% |
| A，2011-11 | +1.57pp | **−1.46pp** | 38.46% |

最后一行反方向翻转：同窗口比较也会揭示被原正值遮住的弱点。建议来自比较单位与目标的匹配，而非保证候选得到更有利的数值。

## 3. 真正的五年收益落后，也可以与长跑胜出同时发生

滚五把每个窗口起点净值重新归一化。定义同一天候选与 BASE 的财富比 `Q(t) = NAV_C(t) / NAV_B(t)`，则：

`候选窗口增长倍数 / BASE窗口增长倍数 = Q(窗口末) / Q(窗口初)`。

所以只要 Q 在窗口内下降，候选的该窗口收益就落后；即使 Q 始终远高于 1，候选仍持有更多的钱。这是真实的“已有优势收窄”，不能被当成统计错误，也不能当成已经丧失全部长期优势。

实际例子：2014-11 起点、全样本账户。

| 2016-07-29 至 2021-07-30 | BASE | EBDS03 |
| --- | ---: | ---: |
| 这五年的年化收益 | 70.55% | 67.88% |
| 窗口初的财富，以同期 BASE=100 | 100 | 163.00 |
| 窗口末的财富，以同期 BASE=100 | 100 | 150.62 |

每行财富比均相对该行日期的 BASE 归一化，不是将 BASE 的实际净值保持不变。候选五年年化少 2.67pp，财富优势由约 63%缩小到约 51%，但仍明显领先。到全部回测末端，财富优势为 8.44%，全期 CAGR 52.79%→53.84%，最大回撤 80.23%→64.49%。这条路径后期确有收益代价，不能只展示前期保护本金的好处。

此外，长跑的复利由完整收益链决定，中位数不链乘，也会弱化少数大幅亏损改善的影响。即使完全改成同窗口配对，P 也不能替代全期净 CAGR。GIPS 对年化复合收益采用几何平均和子期收益链乘；这支持复利计量原则，不是在规定本项目的策略选优门槛。[GIPS 资产所有者手册](https://www.gipsstandards.org/standards/gips-standards-for-asset-owners/gips-standards-handbook-for-asset-owners/)

两条预定长跑中，全样本 2009-11 起点 CAGR 31.72%→41.09%，期末财富为 BASE 的 3.18 倍；2011-11 起点 33.24%→35.96%，期末财富为 1.35 倍。A 的 2011-11 长跑则是 43.44%→42.81%，期末财富为 BASE 的 0.937 倍。不能将部分长跑的强优势推广为所有情景优势。

## 4. 收益、较差窗口与尾部应分别解释

下表来自原实验的配对差中位，不因本次新增诊断而改算旧指标。

| 既有指标变化 | 全样本 | 剔除 A |
| --- | ---: | ---: |
| 全期 CAGR | +2.53pp | +1.70pp |
| 最大回撤幅度 | −11.70pp | −10.24pp |
| 滚五年化 P25 | +4.68pp | +0.03pp |
| 起点内最差滚五年化，再取配对差中位 | +4.74pp | +4.68pp |
| 滚五回撤中位 | +0.02pp | −1.42pp |
| 非重叠五年块中位 | +0.80pp | +0.47pp |

跨所有起点的实际最差五年年化，全样本 −5.12%→−0.14%，A −15.43%→−6.50%；两臂最差值未必来自同一窗口，属尾部包络比较。尾部改善与通常窗口回撤几乎不变可以共存，尤其对于只在少数顶部去融资的机制。不能据此声称所有窗口或整个收益分布全面占优。

## 5. 重叠与时间权重仍然存在

每组有 1,428 条“起点×窗口”记录，但只覆盖 **141 个不同的五年日历区间**；每个区间涉及 1～14 条账户路径，相邻窗口重叠约 59 个月。这些路径的持仓可能不同，不能简单删成一条；也不能把它们当 1,428 次独立证据。

较早账户有 141 个滚五窗口，较晚账户只有 63 个。在“各起点等权”的指标里，晚起点的单个窗口获得更高权重；较晚的日历区间又出现在更多起点中。因此，新增起点或推进数据末端，即使不修改旧交易，也可能改变汇总读数。

起点等权和日历等权的均值分别为全样本 +1.79/+2.72pp、A +0.36/+1.31pp，说明时间权重有实质影响；两种权重都不能凭结果较好而被选中。若只保留所有起点都有的共同窗口，又会丢掉较早的危机时期，不适合直接替代顶部防守验证。

同窗口配对解决了匹配单位的问题，**没有解决窗口重叠、账户路径依赖、样本内调参或未来预测能力**。滚动窗口继承该账户当时持仓，并不等于每个窗口都从现金重新开一个五年账户。本次不计算基于独立样本假设的 p 值或置信区间。

## 6. 建议如何定位这个指标

| 决策问题 | 更贴近问题的比较 | 现行 M 的位置 |
| --- | --- | --- |
| 长期同一笔资金复利是否更好？ | 同起终点、同成本的净 CAGR 与期末财富比；14 起点逐项列出，核对两条预定长跑 | 辅助解释收益在持有窗口间的分布 |
| 同一个五年持有窗口通常更好了吗？ | 同窗口先相减，报中位、均值、胜率及损失幅度；P25/最差另报 | 描述两臂各自分布中心的移动，不能代替同窗差 |
| 顶部去融资是否有价值？ | 预先定义的行情区间内杠杆、债务、回撤、恢复时间；完整路径最差损失与融资缓冲 | 中位数可能掩盖低频但关键的保护效果 |
| 结果能否迁移？ | 固定规则后的前向/时间隔离验证、邻近参数、成本、去赢家与事件归因 | 单独一个负号或正号均不足以回答 |

如果目标明确要求“多数账户起点的各自滚五中位收益不得下降超过某额度”，现行 M 可作为与该偏好对应的门槛。当前用户强调的目标则是减少顶部杠杆风险并持续复利；仅因 M 低于 −0.15pp 就拦下候选，会把额外的典型窗口收益偏好置于目标之上。

建议未来统一评估方案：以长期净复利作为收益主比较，单列可接受的回撤和融资风险；滚五补齐同窗口差和下侧分布，保留 M 作诊断，重新讨论其是否应保有单独否决权。任何收益损失容忍度都应从风险取舍事先确定。不能把“换成均值”视为通用修复：均值仍受时间权重影响，也不能链乘重叠窗口。

本建议不等于立即改判 EBDS03。先修复 OI-169/170；若决定修改评价规范，应对既往策略族（含未获选方案）统一复核并冻结后续规则，保留本次原判定和新诊断。3pp 已属于看过历史结果的候选，不能通过改指标获得样本外身份。
