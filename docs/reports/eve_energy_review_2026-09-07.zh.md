# 亿纬锂能：关注资格复核

截至北京时间 2026-09-07。结论：**维持 `boundary_pending`，暂不纳入正式关注池；中等置信。** 亿纬有真实的产品开发、制造和客户验证能力，原档案“宁德已入池，亿纬不应同档”的理由撤回。本轮没有将其判为无护城河或垃圾公司，也不新增质量评分。正式关注池保持 181 家。

## 1. 正面依据要保留，但需分清证明了什么

- **消费电池提供不同于宁德主营业务的观察角度。** 公司锂原电池用于表计、汽车电子等长寿命场景；消费业务还含小型锂离子和圆柱电池，2025 年收入 110.75 亿元、毛利率 25.65%。消费板块整体占收入 18.02%，不能把这整个比例都归给锂原电池。公开分部数据尚不能单独验证锂原电池的利润和投入资本。[2025年报](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12033427)
- **宝马合作有客户方证据。** 宝马在 2022 年公布与宁德、亿纬的圆柱电池采购及建厂安排，说明亿纬已进入核心客户的供应体系；同一公告也显示供应商并非只有亿纬。合作、验证与量产能力构成正面依据，尚不能独自推导跨车型的持续议价权。[宝马公告](https://www.press.bmwgroup.com/global/article/detail/T0403470EN/more-performance-co2-reduced-production-significantly-lower-costs-bmw-group-to-use-innovative-round?forceSitePreference=MOBILE)
- **技术输出得到合作方认可。** 康明斯披露亿纬以 10% 股权参与 Amplify，并提供电芯设计和制造技术。这个事实支持能力可以服务不同客户，不应把亿纬描述为纯粹购买设备扩产的企业。[康明斯公告](https://investor.cummins.com/news/detail/656/accelera-by-cummins-daimler-truck-and-paccar-complete)
- 公司最新中报摘要披露大圆柱进入规模交付、商用车客户覆盖及 628Ah 电芯量产。这些加强了执行能力证据；“率先”“覆盖率”等为公司披露，不能直接等同排他性或长周期超额回报。[2026中报摘要](https://disc.static.szse.cn/download/disc/disk03/finalpage/2026-08-20/d6701530-95fa-45fd-aa14-0a33ebaa6c51.PDF)

## 2. 最新数据约束了入池判断

| 指标 | 2026H1 | 观察 |
| --- | ---: | --- |
| 营收 | 456.91 亿元，+62.20% | 规模快速增长 |
| 归母／扣非归母 | 33.01／24.51 亿元 | 同比 +105.66%／+111.89% |
| 消费／动力／储能毛利率 | 22.64%／16.19%／12.51% | 同比 −4.04／−2.97／−1.36 个百分点 |
| 合并经营现金流 | −3.88 亿元 | 上年同期 +23.73 亿元 |
| 购建长期资产现金支出 | 53.43 亿元 | 经营现金流减该项约 −57.31 亿元 |
| 存货／应收账款 | 154.22／197.06 亿元 | 年末分别为 82.40／148.60 亿元 |

数据及口径来自[中报全文第8、18—20、58页](https://static.cninfo.com.cn/finalpage/2026-08-20/1225483571.PDF)。毛利同比使用中报重列的 2025H1 分产品口径，未拼接旧分类。−57.31 亿元是简化的“经营现金流减资本支出”，不等于净利润，也未区分维持性与扩张性投资。

公司将现金流下降解释为战略库存储备和支付货款；扩张期备货可能在后续转化为销售与现金，不能据此认定造假或永久损失。2025 年经营现金流曾达 74.92 亿元，也不支持“长期完全没有现金创造能力”的说法。[2025年报现金流](https://vip.stock.finance.sina.com.cn/corp/view/vCB_AllBulletinDetail.php?id=12033427)

我的疑点是：出货增长、技术导入和扩产，尚未在当前主要电池业务中清楚体现为可持续的单位利润保护与资本回收。现金和毛利变化是核验这些优势如何变现的证据，不是另设“一期现金流为负即退池”的规则。

同时，归母利润增长不能全部解释为电池制造壁垒增强。中报投资收益 11.83 亿元，占税前利润 31.91%；其中权益法投资收益 6.05 亿元、处置长期股权投资收益 4.47 亿元。不能将投资收益全判一次性，也不能把税前金额直接从归母净利中扣除得到“主营净利润”。[中报第142页](https://static.cninfo.com.cn/finalpage/2026-08-20/1225483571.PDF)

## 3. 同业比较与海外项目的边界

宁德 2026H1 动力／储能电池系统毛利率为 20.63%／23.96%，与亿纬披露的相应板块存在差距。两者产品组合、系统占比、客户与地区不同，不能将毛利差全部归因于同规格电芯成本；宁德两类业务毛利也同比下降，行业性降价压力不能只算亿纬的特有侵蚀路径。[宁德2026中报第16页](https://disc.static.szse.cn/disc/disk03/finalpage/2026-07-25/8e6750da-b178-4be9-a74a-4b1d8fc42c58.PDF)

长期回报也须完整呈现：本地财务序列中，亿纬 2018—2025 年加权 ROE 中位 17.27%，宁德同窗为 22.78%；亿纬 2023—2025 年为 12.48%、11.30%、10.50%。它有较高历史回报，不能只拿最新 10.50% 否认过去；集团 ROE 混有投资收益，亦不等于电池分部 ROIC。这些是辅助比较，不是统一入池门槛。

**Amplify 不能继续按旧投产计划计入确定性。** 戴姆勒 2026Q1 报告确认美国电池项目延迟投产及爬坡，并对其投资确认 1.99 亿欧元减值。该金额属于戴姆勒自身会计记录，不可按持股比例直接推算为亿纬已确认损失。它不否定技术被选中的事实，但降低了用该项目证明已经实现稳定授权收益的力度。[戴姆勒2026Q1第38页](https://www.daimlertruck.com/fileadmin/user_upload/documents/investors/reports/interim-reports/q1/2026/daimler-tuck-ir-interim-report-q1-2026.pdf)

资本复制测试的本轮判断为**存疑**：资金难以立即买到亿纬的全部工艺和交付履历，但目前取得的材料尚不足以确认这些积累在主要增量业务上形成怎样的持久替换成本或成本优势。消费利基值得继续核验；目前不将它放大为整个集团已通过测试。相较“全面被宁德覆盖”的旧判断，这个结论更窄。

## 4. 后续复核与估值档案

优先看三类硬证据：

1. 大圆柱、商用车及储能客户连续复购、续约或替换情况，以及同规格产品费用后利润与良率，验证客户优势是否跨项目延续。
2. 战略库存对应订单、周转和应收账龄，结合后续现金回收判断是否有效投入；不能只看现金流某一期转正。
3. 锂原电池独立利润与资本占用；海外技术授权的实际收入、收款及项目修订安排，区分已兑现能力与计划。

已有档案保留 **40.96—50.06 元，中值约 45.51 元**的模型参考带，采用 2026H1 输入。该带目前走“权益退路”，属于缺少结构化三大报表时的简化估值，未完成本轮 ROIC 模型重建；不能把仓库数据覆盖限制当成公司没有披露，也不作为本次入池理由或买入价。本次更新研究证据与复核条件，不调整模型参数、生产池成员或持仓。
