# 指标审核意见与最终实施建议

2026-09-05。用户要求评估Fable 5.1对[指标优先级报告](backtest_metric_priority.zh.md)的审核，给出最终方案。本文件是审核结论与实施方案。**落地状态（2026-09-05，v4.142）**：第一批次（计量与报表）与第二批次的账户 TWR 已落地——工作流§12.1第2款计量口径 m2、§10.3 单位净值链乘、引擎／扫描器改造、BASE 与 OI-145 候选同批重算与在册重登，见回测日志§12.192；第二批次的 0／10／20／30bp 执行压力已落地（v4.147，回测日志 §12.193，OI-148 结案）；冻结影子组合与执行偏差记录（OI-149）与第三批次跨市场（OI-150）仍登记待办。

**结论：接受主线和大部分改进，保留双门槛；修正「都不影响判定」「强平缓冲公式」「TWR零成本」「每个版本都清零」四类表述。先做计量与报表，再做执行压力与前向记录，跨市场放后续。**

**双门槛的依据与边界**

工作流的收益排序和资格门槛本来就分开：候选按全期CAGR配对增益排序，但滚5中位继续保留并列门槛。TW125这类复利正而滚5不合格的候选，不因「排序靠前」获得采纳资格。原报告对此表述不够明确，现已补正。

不接受「两个指标预测力已测得相同」的强表述。旧实验只是在单一家族、高度重叠的历史窗口上均未测出正向传递，没有完成预测力等价检验。保留现行双门槛是在没有新证据时维持既定约束；双门槛本身不是经过校准的多重检验纠正，也不能证明未来收益更高。

**计量迁移并非完全不影响判定**

日历年化改变`(期末净资产／初始资本)^(1／年数)−1`的指数，即使交易路径不动，水平、配对差以及Calmar都会改变。在一个剔除情景中观察到Δ最多变化0.06pp，不能推广为所有候选的误差上限；接近现行边界的候选可能翻判。

Sharpe不参与现行主采纳双门槛，却仍在去赢家「全面优秀」所用的标准指标集中。改Sharpe可能改变候选登记资格；把它移到附表也不自动消除这一作用。[扫描器STANDARD_SET](../../scripts/sweep_backtest_configs.py)仍保留这些列。因此本次方案保留原筛选项及原阈值的含义，统一重算后报告翻判；任何调整比率阈值的建议另行明示，不借计量修复暗改门槛。百分率用pp，比率用比率单位，显示时不把两者都称为pp。

实施时增加计量版本与字段名校验，BASE、候选、全样本、A、U同版同批计算。保存旧快照、旧判定及新旧差异表，不能只更新BASE而拿旧候选表比较；不追溯抹去当时基于旧口径作出的决策。

日历CAGR从初始资本对应时点到末次净值时点计算，年数为日历天数／365.25；保留首日费用，不能直接把已有首笔交易后的净值当初始资本。全期与滚动Sharpe共用一个函数：逐期简单收益减同期rf收益，取均值／样本标准差，再按明确约定年化。首批固定244交易日年化因子以隔离本次公式修复；它与CAGR的日历持有时长不是同一概念。[Sharpe原始定义](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)

rf使用原有来源的当时已可得利率，换算到相邻净值日之间的持有区间，不用之后数据回填之前。当前rf文件自2010-01-29起，2009锚点前段缺覆盖：先补原有来源历史，未补齐就标缺失／覆盖率，不用全文件均值兜底。Fable的2011锚点约0.82可由「路径rf均值／244」的近似算法复现；最终登记值应以确定后的逐期算法实算，不能直接把约1.12抄成新的14起点标准读数。

**强平缓冲的正确定义**

令S为股票总市值、C为现金、D为融资负债，担保比例R=(S+C)/D；引擎阈值记为k。假设现金、负债、持仓不变，股票统一下跌x，恰好触及阈值时：

`x = (S + C − kD) / S`。

Fable的`1 − k/R`衡量的是总资产整体同比下降，现金为0时才等于股票统一跌幅。其给出的23.9%、14.6%、28.9%按总资产冲击公式核对正确，可先按这个名称展示，不能直接改名为精确股票同跌缓冲。

最终在引擎检查强平的同一时点记录S／C／D和缓冲；可另记日末值，但两者不能拼接。现有summary最低担保比例在日内交易前检查，equity.csv保存日末，因此不能用summary最小R配上日末现金计算。D=0标不适用；S=0或现金足以覆盖阈值时说明没有0～100%股票跌幅内的触线点；已触线保留状态，不把负缓冲静默截为0。跨起点极值附对应路径，强平合计注明「模拟路径次数」，不当作独立市场事件数。

此缓冲是冻结现金、负债、持仓的一次静态冲击，不是预报未来可跌幅；不包括追加利息、主动偿债、无法成交及券商临时调整。

**执行成本压力的范围**

新增每边0／10／20／30bp档位，买价加滑点、卖价减滑点；行情盯市与信号价保持原始价格。实际成交价进入股数、整手、可用现金、成本、佣金税费和后续持仓计算；买卖先净额对冲再对真正成交收滑点，避免为抵消腿重复收费。强平等真实卖出也覆盖；分红、送转、配股认购等公司行动不冒充二级市场滑点交易。

0bp必须复现原交易路径。各档BASE与候选使用同数据、起点和固定的剔除集作配对，不能拿20bp候选去比0bp BASE。成本实验主对照的A／U先按0bp标准锚点确定并固定，以隔离成本效应；如成本使赢家名单变化，再补同档赢家并集敏感性，不以更换剔除集掩盖反转。输出两项收益门槛的Δ、风险变化和成本导致的排序／判定变化。

7.01×0.002≈1.40%只能作为成本数量级提示。当前换手是「全期成交额／年数／平均净资产」，不是逐笔成交额除以当时净资产的时间均值；成本改变后续资本、融资、整手与持仓路径，因此1.40%不能直接认定为CAGR下降1.40pp。实际采用对照重跑，不对原CAGR机械减常数。

初期把这些档位作为必须报告的压力检查；没有实盘成本标定前，不宣称20bp或30bp具有普遍正确性。拟采纳的收益改善若在与实际成交相符的成本范围内反转，应按该真实成本口径复核，而不能仅凭0bp表升级。固定bp测试也不替代涨跌停、停牌、成交量容量和融资资格模型。

**前向记录的具体方案**

核对账户快照为34条数据行（另有1条表头），2026-07-09～09-03；08-28基准日起5条，外部现金流列均显式为0。现有数据足以核对这几天的净值变化，尚不能证明长期收益，也不能从基准日前空白现金流推断一直无出入金。

采用两条并行记录：实际账户的连续TWR净值，以及冻结规则的影子组合。实际账户含继承持仓、用户偏离执行等因素时单独标记，不能把全部账户收益归给某一冻结策略。累计TWR净值和对应高水位、回撤连续保留；实质规则变化只新增纪元分段，不把此前收益清零。分红、佣金、融资借入／偿还均属于组合内部记账，外部现金流只计用户外部资金／资产转入转出。

精确TWR在每次外部流入／流出前后估值，再把各子期收益链乘。新增逐笔外部现金流时点和估值记录；只有每日净流量时，明确期初／期末假设或使用Modified Dietz近似并标识，不能声称精确。现金流没有发生时直接链乘日收益；历史缺数据保留未知，不为凑连续曲线编造现金流。[GIPS关于TWR及现金流估值的说明](https://www.gipsstandards.org/standards/gips-standards-for-firms/gips-standards-handbook-for-firms/)

默认每月固定一次收益动机策略发布窗口，提前冻结待选清单与生效时点；研究可以持续进行，真实性和执行错误及时修复，不为凑冻结月延期。影响估值／选股／下单的实质变动开新纪元；文档、展示、指标算法修复，或冻结规则内正常财报更新，不等于新交易策略。原冻结影子组合能合法继续时保留运转，才能积累长于一个发布周期的前向证据；它仍是模拟记录，应与实际成交区别呈现。

近期同时记录信号生成时点、计划交易日、标的／方向／数量、指定执行基准价、实际成交价／量／时点、费用，以及延迟、未成交、主动偏离。已成交价差、未成交造成的机会损失、规模与交易方向分开分析，避免只看成功成交的价差低估执行损耗。短期展示累计收益与这些偏差，不用几天的年化率作选优依据。

**跨市场与报表组织**

跨市场放第三阶段。先预登记固定估值分档对未来收益的检验，再考虑完整组合。需历史时点股票池、退市、原始财报可得时间、公司行动和本地税费／执行规则；当前少数海外关注公司及当前估值不构成无偏历史样本。港美股与A股也共享宏观风险，不能当完全独立抽样；测试后若据结果改规则，这一市场也进入研究样本。

扫描报告首页仅显示现行五项决策读数、全样本／A各自结果、正式判定和跨起点尾部摘要；U另列待考察资格。Sharpe、Calmar、逐年收益、滚3／滚10、换手、集中度与完整标准集放附表，保留字段、存档和现行资格计算。这样改变阅读负担，不通过删列暗改资格。

**实施顺序与验收**

1. **计量与报表批次**：先在唯一工作流标准明确计量公式及展示角色，再改引擎／扫描器；同快照重算BASE全／A的28条路径及正在评审候选的对应全／A／U。输出新旧CAGR、Sharpe、Calmar、Δ与资格翻判表，校验交易与净值不因指标代码变化；增加极值、正确缓冲和覆盖标识。档案保留旧值，重登新值，生产交易参数维持。
2. **执行与前向批次**：实现0／10／20／30bp压力及零档恒等检查，覆盖买卖、净额对冲、整手、融资、缺价、强平及公司行动；补齐现金流记录和TWR、高水位／回撤一致性测试；启动冻结影子与实际执行偏差记录。验证同日入出金抵消、现金流估值缺失、非连续快照与纪元切换不重置连续历史。
3. **后续可选批次**：具备上述基础后，再做跨市场的预登记验证；不先把海外工程铺开而搁置当前计量和成交真实性。
