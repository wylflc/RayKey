# OI-204／OI-211：超额回报指数整本衰减与投入资本下限

日期：北京 2026-09-24。实验目录：[`exp_oi204_211_20260924`](../../data/experiments/exp_oi204_211_20260924/)，预登记见 [`preregister.md`](../../data/experiments/exp_oi204_211_20260924/preregister.md)。依据：[P/V 估值逻辑审计](pv_valuation_logic_audit_2026-09-23.zh.md) §6 B1／B3；用户 2026-09-24 裁定 OI-204 改测指数整本衰减、OI-211 设投入资本下限并照常计算资本腿。按工作流 §12.1 轨道 A 验证，回测读数只作记录。

## 机制

### OI-204 期末断崖

§6.5.1 的回报路径是「整本线性衰减」：全部账面资本的回报在 10 年内按等差从 ROIC0 降到 ROIC_T（WACC + 2pp，不高于 ROIC0），增速同样线性降到 g_T；每年留存 b = [(1+g)·ROE_t／ROE_{t+1} − 1]／ROE_t，截在 [0, 1]。等差下降的相对跌幅越到期末越大，维持增速所需的账面扩张超过全部利润，留存触顶、派息归零，随后一年利润断崖。茅台 2026 中报（ROIC0 163%、ROIC_T 11.4%）：第 8～9 年派息为 0，第 10 年 NOPAT −51%。

机理检验（`mechanism.py`，生产 v4.199 带、报表名单 345 只）：

- M1：ROIC0 高于终值回报的增长带中，33%（12%～20%）到 85%（> 80%）的估值低于自身零增长企业价值，ROIC0 越高越低。
- M2b：实现的超额回报存续（t+5／t+10 五年中位）为 0.47～0.74／0.24～0.63，线性整本预测 0.70／0.20，审计原方案「只衰减新增资本」预测约 0.98／0.80，后者被否决。
- M4：1～10 年现金转化（ΣFCFF／ΣNOPAT）实现 0.49～0.76，线性整本 0.23～0.43。

指数整本衰减：ROE_t = ROE_T + (ROE0 − ROE_T)·e^(−λt)，路径 50 年（剩余超额 0.25%），增速仍 10 年线性到 g_T、其后保持。λ 按预登记规则（M5）以 M2b 的 t+5／t+10 实现存续拟合：0.115 → 0.12。拟合外检验：1～10 年现金转化 0.45～0.75，与实现 0.49～0.76 相当。

### OI-211 负投入资本

投入资本 = 有息负债 + 总权益 − 超额现金；OI-201 把存款计入现金后，格力、同花顺、金山办公等的投入资本在部分年份 ≤ 0，ROIC0 不可算，带退回零增长（NOPAT／WACC）。零增长锚本是为 ROIC0 距 g_T 不足利差护栏的公司设的，投入资本 ≤ 0 恰是回报无上界的相反情形。M3：投入资本 ≤ 0 的财年其后三年 NOPAT 年化中位 24.1%（78% 为正），其余 19.2%。`--roic-ic-floor 0.1` 令投入资本 ≥ 0.1 × 总权益，ROIC0 与资本腿增量回报（封顶 40%）照常计算。线性衰减下该下限使格力 V 94 → 67（ROIC0 195% 撞上期末断崖），故与 OI-204 同批。

## 局限

- λ 由报表名单（345 只、存活偏差）的实现存续拟合，全市场回落更快（M2a）；ROIC0 20%～30% 档实现存续高于模型，> 80% 档低于模型。
