# OI-209：研究正常化盈利与模型盈利锚的差距复核

日期：北京 2026-09-24。依据：[P/V 估值逻辑审计](pv_valuation_logic_audit_2026-09-23.zh.md) §6 发现「档案研究给出的正常化盈利与模型锚可能相差 50% 以上，流程中没有提示或复核触发」（五粮液 190 亿对 291 亿）。回填、复核脚本与证据：[`exp_oi209_20260924`](../../data/experiments/exp_oi209_20260924/)（`backfill.py`、`review.py`、`forecast_0924.json`）。现行规则见工作流 §6.5.2.2、§7.3、§7.5、§6.6。

## 裁定

用户 2026-09-24 裁定（v4.202）：差距 = 两数较大者 ÷ 较小者 − 1，超过 **30%** 触发；研究数按**模型口径（NOPAT）**登记；触发后**入 §7.3 队列并按 §7.5 冻结新增买入**，复核记录后解除，此后任一数较复核时变动超过 10% 且差距仍超过 30% 重新入队；**从 fundamentals.md 已写明正常化水平的档案回填**，其余在下次复核时填写。研究数不进模型、不改带。

首批复核后用户同日再裁定（v4.203）：① 归母口径研究数改按模型股权桥反解为 NOPAT；② 研究数**低于**模型锚才冻结新增买入，高于模型锚只入队复核；③ 五粮液复核结论为维持模型、解冻。

用户同日改判五粮液（v4.204）：研究数更有说服力，改为**采用研究数**，生产带按研究数估值；采用一直有效到复核改回维持模型，期间任一数较复核时变动超过 10% 或复核后公告新年报即重新入队，冻结改按生产所用锚较高的一侧。

## 实现

- 档案 `a_share_valuation_dossiers.csv` 增八列：`research_nopat_yi`、`research_evidence_date`、`research_falsifier`、`research_source` 与复核记录 `divergence_reviewed_at`、`divergence_review_note`、`divergence_reviewed_model_yi`、`divergence_reviewed_research_yi`。
- 模型盈利锚 = 候选侧生产带每股 NOPAT × `shares_est`（ROIC 路径；权益口径与银行保险不比较）。判定只在 `build_report_update_queue.research_divergence` 实现（`triggered` 入队、`freeze` = 入队且研究数低于模型锚），队列增 `research_nopat_yi`／`model_nopat_yi`／`research_model_gap` 三列与原因 `research_model_divergence`，`buy_blocked` 按方向；档案 README 第二节末写出两数、差距、方向与复核状态。队列的输入戳同时记档案与生产带，任一变动须重建队列。
- 换算（v4.203）：`research_nopat_from_parent` = 归母 ÷ (1 − 生产带 `minority_share`) + (最新年报 NOPAT − 合并净利)，即模型股权桥的反解：少数股东份额取模型分给少数股东的盈利份额，第二项是税后净利息与金融收益，随资产负债表而非经营盈利变化，按额计。v4.202 的近五个年报 NOPAT ÷ 归母中位在归母是余数的公司失真（天齐锂业少数股东分走合并净利 0.20～0.85，比率 1.28～6.27），在金融收益相对压低盈利较大时偏高（五粮液 2025 年比率 0.81，此前 0.98～0.99）。
- 冻结方向（v4.203）：冻结新增买入防的是在偏乐观的锚上买入。研究数高于模型锚时，模型给出的买入在研究口径下更成立，该方向的风险是过早卖出，冻结不涉及卖出，故只入队复核。

- **五粮液**：模型谷底守卫（`trough_weight` 1）取五年 NOPAT／经营账面中位，约为 2021～2024 的回报水平；研究数是渠道重置后约 190 亿归母，较 2024 峰值 318.5 亿低约 40%。中报后 7 家研报（08-29～08-31）归母中位 26E 155.1／27E 172.8／28E 189.3 亿，26-27E 较 07-15 一致预期（178.4／196.7）下调约 13%，190 亿水平推迟到 2028E；中报归母 87.53 亿落在预告下沿。研究口径下现价约为公允（P/V 0.985），模型口径在买入区（0.729）。上一轮白酒下行归母 2012 99.3 → 2014 58.3 → 2017 96.7 亿，三年回到前高。四家中唯一研究数低于模型锚、冻结有实际作用的一家；用户裁定维持模型、解冻。

两数用同一经营账面 1,186.7 亿、同一每股净现金 32.07 元与少数股东扣减，差别只在正常化的 NOPAT ÷ 经营账面：模型 23.2%，研究 15.0%。

- 模型锚 = 2021～2025 五年比率中位 23.2% × 经营账面。最近四季比率 8.9% 为十年中位 23.0% 的 0.39 倍，谷底守卫权重 1，按五年中位完全回归，折归母约 283 亿。守卫不触发时非周期锚 = 三年中位 22.9% + λ 0.5 × (8.9% − 22.9%) = 15.9%，NOPAT 188.5 亿，V 74.07、P/V 0.950，与研究数只差 6%：差距全部来自谷底守卫把渠道重置判为周期谷底。
- 研究数的 190 亿归母取自 07-15 一致预期 26E 178.4／27E 196.7 亿；中报后降到 26E 155.1／27E 172.8／28E 189.3 亿。2025 年经 2026-04-30 更正公告（收入确认）前三季度营收由 609.5 亿改为 306.4 亿、归母由 215.1 亿改为 64.7 亿，全年营收 405.3 亿、归母 89.5 亿；2026H1 归母 87.5 亿（二季度 6.9 亿）。
- 上一轮下行归母三年回到前高，账面回报在 2014～2016 年停在 13.5%～14.1%，2019 年才回到 23%。按中报后一致预期、账面不变推算，2026 年报进入窗口后模型锚仍约 272 亿（五年中位 22.9%、谷底权重 1），2027 年报进入后才降到约 160 亿。
- 估值：模型 经营价值 68.69 + 净现金 32.07 − 少数股东 4.24 = V 96.52；研究 42.49 + 32.07 − 3.15 = 71.41。现价 70.34 扣净现金后经营业务约 38.3 元/股。
- 落地：生产带 V 96.50 → 71.39（叠加脚本按同一引擎比例重算 EV，与复核时直接重算的 71.41 差舍入），P/V 按 09-23 收盘 0.985，在买入线 0.9524 之上；候选侧、B2 与持仓侧带只有五粮液一行变化，队列试算（信号日 2026-09-24）0 行。

## 局限

- 研究数是一次性研究判断：五粮液的正常化水平依赖渠道重置是周期性还是结构性，中报后一致预期只覆盖到 2028E；亚钾国际的重述用半年报单位成本外推到满产，未计产能爬坡期成本。
- 股权桥换算取模型的少数股东份额（盈利中位），在少数股东份额随周期大幅摆动的公司（天齐锂业）只代表窗口中位。
- 研究口径 V／P/V 在结论为维持模型时只作复核参照；采用研究数的行生产与回测不同口径，回测无历史研究数，引用回测读数论证该行生产行为时须先看 `research_overlay`。敏感度列 `v_bear`／`v_bull`／`v_zero_growth` 保留机械值。
