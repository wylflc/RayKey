# OI-209：研究正常化盈利与模型盈利锚的差距复核

日期：北京 2026-09-24。依据：[P/V 估值逻辑审计](pv_valuation_logic_audit_2026-09-23.zh.md) §6 发现「档案研究给出的正常化盈利与模型锚可能相差 50% 以上，流程中没有提示或复核触发」（五粮液 190 亿对 291 亿）。回填脚本与换算记录：[`exp_oi209_20260924`](../../data/experiments/exp_oi209_20260924/)。现行规则见工作流 §6.5.2.2、§7.3、§6.6。

## 裁定

用户 2026-09-24 裁定：差距 = 两数较大者 ÷ 较小者 − 1，超过 **30%** 触发；研究数按**模型口径（NOPAT）**登记；触发后**入 §7.3 队列并按 §7.5 冻结新增买入**，复核记录后解除，此后任一数较复核时变动超过 10% 且差距仍超过 30% 重新入队；**从 fundamentals.md 已写明正常化水平的档案回填**，其余在下次复核时填写。研究数不进模型、不改带。

## 实现

- 档案 `a_share_valuation_dossiers.csv` 增八列：`research_nopat_yi`、`research_evidence_date`、`research_falsifier`、`research_source` 与复核记录 `divergence_reviewed_at`、`divergence_review_note`、`divergence_reviewed_model_yi`、`divergence_reviewed_research_yi`。
- 模型盈利锚 = 候选侧生产带每股 NOPAT × `shares_est`（ROIC 路径；权益口径与银行保险不比较）。判定只在 `build_report_update_queue.research_divergence` 实现，队列增 `research_nopat_yi`／`model_nopat_yi`／`research_model_gap` 三列与原因 `research_model_divergence`；档案 README 第二节末写出两数、差距与复核状态。队列的输入戳同时记档案与生产带，任一变动须重建队列。
