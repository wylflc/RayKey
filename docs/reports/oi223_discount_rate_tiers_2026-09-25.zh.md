# OI-223 折现率按公司风险分档：背景与待办（2026-09-25）

本文给之后单开会话接手 OI-223 用。现行规则以[工作流程](../000_Ashare_workflow.md) §6.5.1 为准，这里只记背景、证据、已定与待定事项和做法。

## 一、用户的提议与裁定

2026-09-25 用户原话：

> 貌似不同公司统一采用同一个 10% 的折现率并不合理，我建议维护一个基于各家公司护城河、业务强度、可持续发展能力的 list，每个公司相互参照着定折现率，也可以参考权威机构或者研报给的折现率，或者行业公允的折现率等参数来定。

用户引用的原则：折现率 = 时间价值 + 机会成本 + 风险补偿。据此：
- 公司越稳定、确定性越高，折现率越低；
- 公司风险越大、未来现金流越不确定，折现率越高；
- 无风险利率上升，合理折现率一般也上升。

同日裁定：
1. **两半都做**：高风险公司提高折现率，稳定且质量明显更高的公司降低折现率。原话：「毕竟还是有茅台这种质量明显高出其他公司的公司存在，如果按照统一的稳定公司标准，那么茅台几乎是永远不可买入的，因为通常不会像正常公司一样低估，只会相对于其自身质量显得低估了。」
2. **定档方式**：用时点可得的数据算基线档，人工可在基线上下调一档，须写明理由。
3. **顺序**：先做 OI-222。OI-222 已于 v4.212 落地，第一份读数见回测日志 §12.267。本轮不与无风险利率挂钩。

## 二、现状：规则与代码落点

- **§6.5.1 统一参数**：`r = 10%`，不逐公司调整。
  - 自 v4.210（OI-217）起 WACC = r，建带参数 `--wacc-weights unlevered`。
  - 终值回报 `ROIC_T = min(WACC + 2pp, ROIC0)`，随 r 变。
  - `g_T = 3%`；回报按指数衰减 λ = 0.12，走满 50 年。
- **建带引擎** `scripts/build_historical_valuation_bands.py`：
  - 已有 `--r-mode tier|market` 两种取 r 的方式。生产用 `--uniform-tier L2`，即全部公司取 L2 的 10%。
  - 旧设计的分档表 `TIER_PARAMS`（L1 8%／L2 10%／L3 13%）、`BETA_BY_TIER`、`TERMINAL_EXCESS_BY_TIER`、`MOS_BY_TIER` 仍在代码里。它们按今日人工质量分档取值，模块说明记有两处问题：把质量惩罚写进 r、与安全边际重复惩罚；实测造成按档位分层的 2.6 倍价差。
  - 新方案不能直接复用旧分档表，理由见第三节。
- **海外**：`scripts/build_overseas_roic_bands.py` 的 `REQUIRED_RETURN` 须与 A 股同口径（用户既有裁定）。
- **银行与保险**：走股利模型（`V = 分红 ÷ (十年国债 + 2%)`），不在本题范围，另见 OI-207。

## 三、证据

1. **分组校准（探索性，`data/experiments/exp_oi223_20260925/`）**：同样 P/V 下比较其后 3 年的年化回报。分组用的是今日的分档和标签，含后视。
   - 按质量分档：L1 比 L2 +2.2%［−0.8, +5.6］，不显著。
   - 以成长型为基准：现金流复利型 −3.0%，稳态分配型 −5.9%，资源型 −4.6%，产业链型 +5.7%（后视最重）。
   - 解读：
     - 对资源、周期类提高折现率，准确性与风险两方面都支持，与 OI-221（净负债公司被高估）同向。
     - 对稳态公司降低折现率，准确性上不支持，是风险偏好上的取舍；用户已裁定要做。
2. **护城河档不等于风险档**：今日 L1 含巨化、金石、神华、北方华创、宁德等周期与技术型公司。
3. **历史**：
   - §12.94（2026-08-20，旧 ROE 模型）：同 P/V 下 L1 ≈ L2，逐票公允点与护城河评分无关。
   - v2.18 在回测里否掉人工分档、统一取 L2，部分依据是回测收益更高。按 v4.211 的原则，回测收益已不构成依据。
4. **敏感度**：按现行引擎，r 每变 1pp，V 约变 10%～14%；8% 与 12% 两档相差约 1.5 倍。档位分得粗，排序就主要由档位决定。
5. **检验基线（§12.267，现行统一 r）**：
   - 买入区陷阱占比为基准率的 1.00 倍，周期高点陷阱海螺 2019–21、神华 2012–13 整个区间都在买入区。
   - 优质复利与产业爆发几乎从未进买入区：海天 0/54、片仔癀 0/76、茅台 2016–19 2/43、宁德 0/18（具名案例 O02、O11～O13）。
   - 现行模型下海天、长江电力从未进过买入区，伊利仅 1 个月。它们其后 3 年年化回报的中位分别是 25.9%、11.5%、16.3%。

## 四、待用户裁定的设计（接手后第一步：起草草案交审，不跑数）

1. **档数与级差**：建议以 10% 为中心、1pp 一档，先 3～5 档。
2. **基线打分项**：只用当时可得的数据，历史上才能检验。候选项：
   - 十年 ROIC 的水平与变异系数；
   - 周期守卫的触发频率（带文件 `peak_weight`／`trough_weight`）；
   - 净负债占企业价值的比例；
   - 盈利的最大回撤；
   - 行业周期属性。
   另外，`data/archive/pit-judgment-2026-08/verdicts_{2010,2015,2020}.csv` 有逐年的时点护城河判定，可考虑作为护城河输入。
3. **每档的对标公司**：每档 2～3 家，供逐家相互参照。
4. **人工调整表**：建议 `data/reference/discount_rate_tiers.csv`，字段为代码、基线档、调整档、理由、证据可得日、复核日。
5. **外部参考**：研报 WACC 与行业资本成本（如 Damodaran 分行业数据，可得性待核实）只记作证据，不机械套用。
6. **与 OI-221 的关系**：提高重资产、周期公司的折现率可能一并缓解 OI-221。

## 五、做法

1. **草案**：起草上节设计交用户审定。
2. **预登记**（§12.1）：
   - 修正依据为估值准确性与风险偏好。
   - 读数：公允性检验（口径同 `data/experiments/exp_oi217f2_20260925/`）、第 13 款机会／陷阱读数（与 BASE 并列、差值按股票整簇配对自助）、第 11 款案例归因、回测参考读数。
   - 买入线用 `scripts/experimental/align_buy_line.py` 对齐到在册合格面。
3. **实现**：先改 §6.5.1，再改建带引擎（按公司取 r，历史只用基线档）、分档表、海外引擎与测试。
4. **跑数**：候选臂的逐日状态通过 SLURM 建。
5. **裁定与落地**：出读数后由用户裁定。落地时重解买入线、重登 BASE、同步 §9.3.1 与参数同步测试，写决策日志与版本记录。

## 六、注意事项

- 历史检验不得用今日分档回填，只用时点可得的基线档。
- 调档只凭基本面证据，不为希望得到的 P/V 调（§1 第 2 条）；每次调档写决策日志。
- r 差 1pp，V 就差 10%～14%。
- 海外清单与 A 股同式。
