# 每日按P/V选前x%公司的买入回测（2026-09-09）

**本轮前16%～24%的9个比例档位均未通过现行筛选条件，没有出现连续更优区间。** 部分档位提高了历史年化，但8档使全样本滚动5年回撤加深超过3pp；唯一未触该回撤门槛的前17%，去赢家年化及滚5表现又明显变差。全部候选的U全面优秀资格均未通过，故不登记该类新候选、不进入采纳流程。保留研究开关，生产仍使用固定1.0454、换仓边际0.15。

本轮测试的机制：每天在**信号日有效股票池**、候选侧价格/价值/PV均有限且为正的公司中，按(P/V,代码)升序选前floor(N×x/100)只，之后再走原走势、资金、持仓上限与成交约束。同估值按代码打破并列，不扩大人数；条件不满足则不从排名外补足。T日排名、T+1成交，排名掉出只影响新买入/加仓资格，不额外卖出。赢家剔除后，按剩余宇宙重新排名。

所有Δ均为14起点逐一配对后取中位，单位pp。A=剔除BASE前五赢家，U=双方前五赢家并集；每个U分别与同集BASE配对，不跨U比较水平值。下表按全期年化配对差排序。

前20%是需要区分收益与风险的例子：全/A年化+0.70/+2.53pp，滚5+1.34/+1.32pp，四项收益读数通过；但全样本滚5回撤+5.70pp未过风险门槛。其U比A多剔除600309万华化学，年化配对差变为−1.92pp。这说明改善对赢家集合敏感；剔除还会重排资金与候选，不能把该差额直接当作万华的独立贡献。

相对上一轮固定1.10的已知对照，前20%的全/A年化配对差为+1.17/+2.12pp，滚5回撤则加深1.97/1.65pp。上述是重新逐起点配对计算，不能用表中两行“相对BASE的中位差”相减代替。各项完整对照见paired_vs_fixed110.csv；前20%的U结论仍按同U的BASE判。

前17%的全样本年化+0.83pp、滚5回撤+2.86pp，但A年化−2.46pp、滚5−7.25pp。前16/18%的A年化接近零，却分别有滚5−4.33/−3.85pp及全样本回撤+4.33/+3.49pp；不能只看全期年化一列。因此没有一个比例档位支持替换生产基准，也没有可挑选的相邻平台。

比例变稳定，并不意味着买入估值门槛稳定。前20%的日度P/V边界第10/50/90百分位为0.8608/1.0913/1.5521，4,088个信号日中2,380日高于当前1.0454；相同区间，固定1.0454每天准入比例在0%～44.44%之间。例如2012年固定线的总体合格比例22.60%、前20%隐含线中位0.9819；2018年则为4.82%和1.4148。固定比例会在整池较贵时放宽准入、整池较便宜时收紧准入。这是代码与门槛分布确认的机制差异，本轮没有完成收益归因，不能据此断言全部回撤变化都由它造成。

人数必须取整，前20%实际加权入选比例19.678%；前16%为15.521%、前24%为23.621%。本轮比例统计使用2009-11-02至2026-08-27的4,088个信号日、488,150个在册可估公司日，所以当前BASE为18.007%，与上一轮包含更早年份的17.928%不是同一观察分母。两个固定线的回测本身已精确复现，差异不是估值或行情更新。

实际风险尾部也一并保留：前20%的全样本最深回撤81.95%（BASE80.23%），A为76.08%（BASE73.49%）；全样本最低担保比例169.23%、股票同跌缓冲23.18%，A分别151.06%、13.94%。前17%的A最深回撤84.94%、最低担保比例134.89%、股票同跌缓冲3.63%，不能因为它通过全样本滚5回撤门槛就称为低风险。两比例臂全/A均无模拟强平；前20%出现5年亏损窗口的起点数全/A为5/14、4/14，BASE为4/14、3/14。日期、区间及其他比例尾部均有记录。
